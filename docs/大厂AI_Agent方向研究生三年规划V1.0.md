### 因「只有笔记本」而必须调整的三件事

**1. 技术路线改成 API-first + 轻量微调**

你没有本地算力，所以**不要走「自己训模型」这条路**——那是给自己挖坑。正确的做法：

- 模型能力**全部走 API**（DeepSeek / 通义 / 智谱 / 硅基流动等，成本可控甚至免费额度够用）
- 本地只做**推理侧**工作：Prompt 设计、工具调用、RAG 索引、Agent 编排、评测
- 需要微调时用 **Colab / Kaggle 免费 GPU** 或 **LoRA + 小模型（如 Qwen 0.5B–3B）**，只为「跑通流程、写进简历」，不追求效果
- 向量库、数据库、服务端全部本地 Docker 跑，这些不吃 GPU

> **这反而是对的**：大厂 Agent 岗位的日常工作 **90% 是工程而非训练**。
> 你没有算力，正好逼你练真正会被面试考的那部分能力。

**2. 论文选题必须避开「大规模训练」**

没有算力做不了「提出新网络结构 + 在百万级数据上刷 SOTA」这类题目。可行的三类选题：

| 类型 | 例子 | 算力需求 | 适合 |
|---|---|---|---|
| **A. 预训练模型的下游应用** | 用现成 VLM / 大模型做建筑多边形化简决策、海岸线形态判别 | 极低（调 API 或跑现成权重） | ★★★ 最推荐 |
| **B. 数据 + 评测类研究** | 构建「空间分析 Agent 评测集」、矢量数据形态模式数据集 | 低 | ★★★ 与简历直接复用 |
| **C. 轻量模型 + 小数据集** | 在公开小数据集上做 LoRA / 蒸馏 / 迁移 | 低（Colab 够） | ★★ |

**绝对不要**接手组里需要多卡训练的题目——你会卡死在算力上，既出不了论文也攒不出项目。

**3. 尽早摸清实验室与云资源**

- 问刘老师：组里有没有服务器 / GPU 集群 / 师兄留下的机器
- 学院是否有算力平台（很多学校有校级 GPU 集群，用学生账号即可申请）
- 申请**阿里云天池 / 百度 AI Studio / 华为 ModelArts** 的免费额度，作为兜底

> ⚠️ 这条待办优先级很高：**算力决定你能不能接组里的活，也决定你的论文上限。**

### 因「读博留口子」而必须调整的两件事

**1. 论文目标从「1 篇 EI/SCI」抬到「1 篇 CCF-B 或 SCI 一区/二区」**

申博（尤其是本校硕博连读或申请 985 博士）看的是**论文层次**，不是数量。1 篇 CCF-B 远胜 3 篇水刊。

**2. 设置明确的决策点：2028 年 1 月**

在那个时点用三个问题自我判断：

- 我的论文投出/接收的层次是什么？（CCF-B 以上 → 申博有戏）
- 我享受做研究本身，还是只享受做出东西的成就感？
- 我拿到大厂暑期实习了吗？如果拿到了，我愿不愿意放弃？

**三条路的组合策略**（并行准备到 2028.01，之后收敛）：

```
        2028.01 决策点
              │
   ┌──────────┼──────────┐
   ▼          ▼          ▼
 读博      大厂就业    大厂研究岗
(论文够硬) (实习够硬)  (两者都要，是最优解)
```

> **注意**：**「大厂研究岗」是这两条路的交集**——它既要论文也要工程能力。
> 如果你研二能同时拥有「1 篇 CCF-B + 1 段大厂核心实习」，你的选择面会比现在宽得多。
> 所以 **2028.01 之前不要提前收敛**，两条路都保持。

## 4. 技术能力清单

### 4.1 必须掌握（面试会问、工作要用）

**编程与工程**
- Python 熟练（含类型注解、异步 `asyncio`、装饰器、上下文管理器）
- FastAPI / Pydantic（做 Agent 服务端）
- SQL（PostgreSQL + PostGIS）、Redis、Docker、Git 协作流程
- Linux 基础命令、部署与日志排查

**算法与计算机基础**
- 数据结构与算法：LeetCode 300 题（Hot100 至少两遍）
- 计算机网络、操作系统、数据库（**八股是刷人的地方，别忽视**）

**大模型 / Agent 技术栈**
- Transformer 原理（Attention、位置编码、KV Cache）—— 要能手推
- Prompt 工程 → Function Calling / Tool Use → RAG（切分、向量库、检索、重排）→
  Agent（ReAct、Plan-and-Execute、多智能体协作、记忆管理）→ **评测与可观测性**
- 框架：LangChain / LangGraph / LlamaIndex 至少精通一个
- **手写一个最小 Agent 框架**（几百行）—— 这是面试的强加分项，也是理解本质的唯一方式
- 模型侧：**API 优先**（DeepSeek / 通义 / 智谱等）；Colab 上跑通一次 LoRA / QLoRA 微调即可（**目的是简历和流程理解，不是效果**）

**地理空间**
- GDAL / Rasterio / GeoPandas / Shapely / PostGIS
- Google Earth Engine（本科毕业设计已验证过）
- 遥感影像处理、地图综合基础理论（课题组的看家本领）

### 4.2 加分项（有则显著领先）
- 会做 **Agent 评测集**（会做 Agent 的人多，会评估 Agent 好坏的人少）
- 多模态 / 视觉语言模型（VLM）用于遥感
- 有真实用户的开源项目（star 数）
- 英文技术写作与口头表达

## 7. 避坑清单（非常重要）

1. **别把「学框架」当目标**
   LangChain 一周就能学会，面试官不关心你会不会调 API。
   关心的是：**你能不能不设计出一个稳定的 Agent 系统**——错误恢复、工具编排、上下文管理、成本控制、评测。

2. **别做「聊天机器人」这种烂大街项目**
   你的项目**必须带地理味道**。你有的别人没有的，就是 GIS 领域知识。做通用 Agent，你竞争不过科班；做空间智能 Agent，你几乎没有对手。

3. **别忽视八股**
   AI 应用岗的面试一样考操作系统、网络、数据库、算法。**刷人大多刷在这里**，不是刷在「你懂不懂 Agent」。

4. **别不做评测**
   会做 Agent 的人多，会评估 Agent 的人少。做一个**「空间分析 Agent 评测集」本身就是简历亮点**，也是论文的天然素材。

5. **别和导师对着干，但要早沟通**
   你想去大厂实习，必须**研一就把话说清楚**（阶段 0 的任务）。刘老师做的是应用型交叉研究，专硕培养方案本身也强调「实践研究不少于 6 个月」，正常情况下不会卡。
   **但一定要早说，绝不能临时请假。** 提前半年沟通 = 尊重；提前一周请假 = 事故。

6. **别只盯「大模型算法岗」**
   那个岗位的竞争者是人手一篇顶会的科班硕博。你的最优解是 **「AI Agent 应用工程 + 领域壁垒」**。

7. **别把科研和求职当两条腿**
   培养方案要求你的论文必须是测绘/地理信息/遥感背景。所以**选题时就把 Agent 缝进去**，一篇论文同时满足毕业和简历。

8. **别信「AI 应届百万」的噪音**
   那是极少数顶尖博士。大厂 AI 应用/Agent 工程校招的现实区间大致在 **25–40 万**，sp/ssp 可更高但需要顶尖实习。
   你的目标应该是：**先拿到 offer，再谈价格**。

9. **别断更 GitHub**
   连续 commit 记录是你「自学能力」的唯一客观证据。断三个月，前面全白做。

## 11. 岗位决策框架 + 案例：字节「数据运营实习生-业务中台」

### 11.1 通用决策框架（以后每个岗位都用它过一遍）

看到任何实习/校招岗位，按顺序问四个问题：

| # | 问题 | 不合格的信号 |
|---|---|---|
| 1 | **专业对口吗？** | JD 明写「计算机相关专业」且不含你的专业 → 有风险 |
| 2 | **方向对口吗？** | 岗位序列 ≠ 你的目标序列（如运营 vs 研发）→ **成长为零** |
| 3 | **时间能兑现吗？** | 到岗要求与课程/学制冲突 → **一票否决** |
| 4 | **做完后简历上多什么？** | 说不出具体一行 → 不值得 |

> **注意第 1 和第 2 是两件事。专业对口 ≠ 方向对口。**
> 一个岗位可以「非常需要你的专业，但让你去做完全不相关的事」。

### 11.2 案例：字节 数据运营实习生-业务中台

- 深圳 · 职位 ID **A107408**
- 上海 · 职位 ID **A168831**
- 类型：日常实习（面向全体在校生）· 运营序列 · 至少 4 个月 · 一周到岗 ≥4 天

**团队**：负责字节多产品的中台能力——**地理位置、行业数据、舆情、众包标注、中间件**，
并「积极利用 AI 等技术做中台能力提效与升级」。

#### ✅ 优势

1. **专业从减分变加分（首次出现）**
   - 深圳岗：「计算机、统计学、**地理信息系统**等相关专业优先」
   - 上海岗：「**测绘**、数据等相关专业优先」「有测绘、数理相关教育背景者优先」
   - → 你的本科（GIS）+ 硕士方向（资源与环境·**测绘工程方向**）**两个都命中**。研发岗不可能给这种待遇。
2. **学历门槛宽松**：「本科及以上在读」，研一可投
3. **是日常实习**：全年可投，契合 §10.5 的路径
4. **字节背书**：公司背景本身就是简历硬通货
5. **地理位置中台 ≈ 空间数据基础设施**（见 11.3 的重估）

#### ⚠️ 风险

1. **序列错配（最核心问题）**：这是**运营序列**，不是研发序列。
   字节内部运营与研发是两条职业阶梯，**这段经历不会给你 Agent 研发岗加分**，
   甚至可能让 HR 把你归类为「运营背景」。
2. **时间一票否决风险**：4 个月 × 每周 4 天 onsite 深圳/上海。
   你在武汉读研一，第 1–3 学期课程为必修（数值分析、地理信息工程与技术、遥感新技术与应用、GNSS…）。
   **为它翘课 = 挂科/低分 + 丢学分，代价远大于一段运营实习。**
3. **技能成长接近零**：指标评估、SQL 打捞、数据清洗、人工生产方案、**人员培训**——
   做 4 个月，你的 Python / Agent 能力不会增长。其中「人员培训」尤其要警惕：
   这通常意味着管理外部标注团队，是纯执行层工作。
4. **两地选择**：深圳岗偏「指标评估/数据分析/策略优化」且明写「有大数据处理、**算法合作项目经验**者优先」
   → 含金量较高，有接触算法侧的机会。
   上海岗偏「POI/地址/AOI 数据建设、SQL 打捞、数据清洗、人工处理」
   → 更偏数据生产执行，含金量较低。
   **若必去，选深圳 A107408。**

### 11.3 重估：如何让它「值回票价」

字节的位置中台本质是 **空间数据基础设施**——POI、AOI、地址、地理编码，
服务抖音本地生活、电商地址、外卖、出行等亿级场景。**这正是「空间智能 Agent」的地基。**

一个真正能干活的「空间分析 Agent」，背后必须依赖可靠的 POI/AOI/地址服务。
**懂数据生产与评估的人，才知道工具什么时候会骗你——这是纯 CS 出身的人学不到的。**

**因此决定价值的不是岗位，是你做的事：**

| 你实际在做 | 判断 |
|---|---|
| 参与 POI 评估指标体系设计、策略优化、与算法团队协作 | ✅ **值** —— 可包装为「亿级空间数据质量体系」，空间智能岗面试权重极高 |
| 纯 SQL 打捞、数据清洗、审核标注结果、培训标注员 | ❌ **不值** —— 与 Agent 工程无关，4 个月机会成本过高 |

**若去了，必须主动做三件事**：
1. 入职第一周就向 leader 表达：想参与**评估体系/策略**层，而非纯执行
2. 团队自己在做「AI 提效」，**主动申请参与 AI 相关子项目**
3. 把产出写成可量化的一句话：如「设计 POI 质量评估指标体系，覆盖 X 亿条数据，误判率下降 Y%」

### 11.4 结论与建议

**判断：可以投，但不要为它牺牲主线。**

- **不建议**：把它当作主攻方向，或为它翘掉研一必修课
- **建议**：
  1. **现在就投** —— 战术价值有三：① 走一遍字节面试流程，是免费演练；
     ② 摸清字节对 GIS 人才的真实需求；③ 拿到一个 Plan B
  2. **面试时必问三个问题**（决定去不去）：
     - 「这个岗位有多少比例是参与评估体系/策略设计，多少是纯执行？」
     - 「团队在做 AI 提效，实习生有机会参与吗？」
     - 「到岗时间能否协商（如压缩到 2–3 个月）？」
  3. **时间点优先级**：
     - **最优**：研一暑假（2027.07）——但须解决「4 个月」与暑假 2 个月的矛盾
     - **次优**：研二下（2028.02 起，第 4 学期实践实习期，制度上合法）
     - **不要**：研一在读期间异地长驻

**一句话总结**：
> 这是「**专业最对口、方向最不对口**」的一类岗位。
> 它能给你**公司的名字**，给不了你**想要的技能**。
> 除非你能挤进评估体系层或 AI 提效项目，否则它的性价比低于「研一暑假做一段研发日常实习」。

## 12. 薪资对比：AI Agent vs 数据运营

> ⚠️ **数据可靠性分级**（务必看清，别把估算当事实）：
> 🟢 有公开来源 ｜ 🟡 网络爆料，可信度中等 ｜ 🔴 我的估算，**无直接来源，仅作量级参考**
> 薪资是高度不透明信息，网传数字普遍存在**幸存者偏差与标题党**。以实际 offer 为准。

### 12.1 实习阶段（你现在真正能拿到的）

| | 日薪 | 折算月薪（×20天） | 可靠性 |
|---|---|---|---|
| 字节 **技术 / 产品岗**实习 | **500 元/天** | ≈ 10,000 元 | 🟢 |
| 字节 实习**整体区间** | 100–400 元/天 | 2,000–8,000 元 | 🟢 |
| 数据运营 / 数据类实习 | 约 150–250 元/天 | ≈ 3,000–5,000 元 | 🔴 估算 |

**来源**：字节 2026 年实习生全面涨薪，技术岗日薪从 417 元提至 **500 元**，整体区间 100–400 元
（[ITHome](https://www.ithome.com/0/910/590.htm)、[PChome](https://article.pchome.net/info/9304.html)、
[新浪](https://k.sina.cn/article_1642088277_61e0475504001wo8o.html)、[163](https://www.163.com/dy/article/KIH610QQ05198R91.html)）。

**实习阶段差距：约 2–3 倍。**
> 💡 运营岗确切日薪我没有查到公开数字，**面试时直接问 HR 即可**——问实习日薪完全正常，也是最快的验证方式。

### 12.2 校招阶段（2029 届，你真正要看的）

| 方向 | 年包区间 | 可靠性 |
|---|---|---|
| **AI 方向（含 Agent 应用开发）** | 白菜价 **40w 起**，sp/ssp 更高 | 🟡 |
| 数据运营 / 数据分析 | 约 **15–25w** | 🔴 估算 |
| 顶尖专项（腾讯青云等） | 100w–300w+ | 🟡 **极少数人，不可作为预期** |

**来源**：
- 「2026 校招技术岗薪资大盘点：**AI 方向白菜价 40w 起**，这个方向却跌破 20w」
  （[掘金](https://juejin.cn/post/7639602273346486272)、[华为云社区](https://bbs.huaweicloud.com/blogs/477737)）
- 「2026 大厂应届生起薪曝光：有人年包 60 万，有人连『白菜价』都摸不到」
  （[知乎](https://zhuanlan.zhihu.com/p/2054972874851606815)）
- 腾讯 2026 校招 AI 岗与青云计划（[知乎](https://zhuanlan.zhihu.com/p/2079681898087969502)）
- 数据岗薪资结构：分析师 10K 起 / 商业分析 20K 起（[知乎](https://zhuanlan.zhihu.com/p/2042704301131355527)）

**校招阶段差距：约 2–3 倍。** 但**天花板差距更大**。

### 12.3 真正的差距不是那 2–3 倍，而是成长曲线

| | 数据运营 | AI Agent |
|---|---|---|
| 起薪 | 15–25w | 40w+ |
| 涨薪速度 | **平坦**（业内公认「数据岗薪资涨不动」） | 快，Agent 方向据传涨幅可达 40% |
| 5 年后 | 30–50w（且需转策略/数据科学才有此数） | 80–150w（视公司/职级） |
| 职业天花板 | 中台/运营负责人 | 技术专家 / 架构 / 创业 |

**参考**：「大厂数据岗薪资为什么涨不动：四条突破路径详解」（[链接](https://ss-data.cc/posts/career-cognition-02-salary-ceiling)）
—— 标题本身就说明了问题：**数据运营是一个需要「刻意突破」才不卡住的岗位。**

### 12.4 ★ 三个必须的提醒

1. **别被标题党污染预期**
   「应届生年薪数百万」「AI 岗年薪百万起」指的是**青云计划一类的顶尖专项**，
   全国每年数百人量级。**普通应届的现实区间是 30–50w，不是百万。**

2. **「运营」是个大类，内部差距极大**
   - 策略运营 / 数据科学方向：可做到 30–50w
   - 数据标注管理 / 内容审核 / 纯执行：只有 10–15w
   → **你贴的那个岗位落在哪里，取决于你实际做什么**（回到 §11.3 的判断）

3. **2029 届的行情现在无法预测**
   以上全部是 2026 届数据，仅供**量级参考**，不是承诺。

### 12.5 结论：薪资差距是「结果」，不是「选择依据」

如果只看钱，答案很清楚：**AI Agent 方向在实习期、校招期、5 年后期都是 2–3 倍以上。**

但真正的账要这么算——**用「时薪 + 复利」而不是「月薪」**：

| | 技术实习 | 数据运营实习 |
|---|---|---|
| 日薪 | 500 元 | ~200 元 |
| 技能增长 | 高（可写进简历的硬技能） | 低（流程性工作） |
| 4 个月后的简历 | +1 个 Agent 项目/工程能力 | +1 段运营经历 |

> **当下的日薪差距是 2–3 倍；两年后的复利差距是能不能进面试的区别。**
>
> 所以选岗位的第一依据永远是 **§11.1 的四问框架**，薪资是第四问之后才看的。
> 但反过来说：**如果一个岗位「方向对口、薪资还高 2–3 倍」，那它几乎不需要犹豫。**
