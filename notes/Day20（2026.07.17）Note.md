### 第二阶段：理论学习（约 0.5 小时

深入理解 Tensor 运算原理与空间维度变换逻辑：  

- **矩阵乘法 vs 逐元素相乘**：逐元素乘法要求 Shape 一致或满足广播条件；矩阵乘法要求前者的列数等于后者的行数。
  $$
  (A_{m \times n} \times B_{n \times k} = C_{m \times k})
  $$

- **维度升降（Squeeze & Unsqueeze）**：单张图片输入网络训练前，需要用 `unsqueeze(0)` 增加 Batch 维度（例如从 [C, H, W] 变为 [1, C, H, W]）；网络预测输出后需用 `squeeze()` 挤压掉大小为 1 的维度。  

- **遥感/CV 常用维度转换（Permute）**：

  - OpenCV/GDAL 读取遥感影像的常规格式为：`[H, W, C]`（高 X 宽 X 通道数 / 波段数）。  
  - PyTorch 卷积神经网络（CNN）要求输入的张量格式为：`[C, H, W]` 或 `[B, C, H, W]`。  
  - 使用 `tensor.permute(2, 0, 1)` 可将  `H x W x C` 调整为 `C x H x W`。

- **View 与 Contiguous**：`view()` 共享底层内存且要求内存连续；当执行 `transpose()` 或 `permute()` 后，张量在内存中不再连续，需先调用 `.contiguous()` 重新开辟连续内存空间，才能继续调用 `view()`。

创建 `tensor_shape.py` 文件，手工编写并运行以下代码，实现 Tensor 基础运算、索引切片及维度变换：  

```python
"""
程序名称：tensor_shape.py
作者：黄乐源
日期：2026-07-17
描述：PyTorch Tensor 基础运算、索引切片与维度变换实战（结合 GeoAI 遥感/GIS 维度转换背景）
"""
import torch

print("================= 任务 1：Tensor 基础运算与矩阵乘法 =================")

# 1. 逐元素运算
a = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
b = torch.tensor([[5.0, 6.0], [7.0, 8.0]])
print("逐元素相加:\n", a + b)
print("逐元素相乘 (mul):\n", a * b)

# 2. 矩阵乘法 (matmul / @)
matmul_res = torch.matmul(a, b)
print("矩阵乘法结果 (matmul):\n", matmul_res)

# 3. 统计运算 (如计算多光谱波段均值)
spectral_data = torch.tensor([[120.0, 150.0, 200.0], [80.0, 90.0, 110.0]])
print("按列求波段均值:", spectral_data.mean(dim=0))

print("\n================= 任务 2：Tensor 索引与切片操作 =================")

# 模拟单波段 4x4 遥感栅格高程/DN值
raster = torch.tensor([
    [10, 20, 30, 40],
    [15, 25, 35, 45],
    [20, 30, 40, 50],
    [25, 35, 45, 55]
])

# 切片获取中间 2x2 ROI 区域
roi = raster[1:3, 1:3]
print("提取 2x2 ROI 区域:\n", roi)

# 布尔掩码提取 (提取高程大于 35 的所有样点)
mask = raster > 35
print("高程大于 35 的掩码矩阵:\n", mask)
print("符合条件的样点值:", raster[mask])

print("\n================= 任务 3：维度变换（Reshape, Squeeze, Permute）=================")

# 1. 模拟 GDAL/OpenCV 读取的多光谱遥感影像: Height=256, Width=256, Channels=4 (RGB+NIR)
remote_sensing_img = torch.randn(256, 256, 4)
print("原始遥感影像形状 (H x W x C):", remote_sensing_img.shape)

# 2. 将 H x W x C 转换为 PyTorch CNN 所需的 C x H x W
rs_img_chw = remote_sensing_img.permute(2, 0, 1)
print("Permute 转换后的形状 (C x H x W):", rs_img_chw.shape)

# 3. 增加 Batch 维度，供深度学习网络输入 (1 x C x H x W)
input_tensor = rs_img_chw.unsqueeze(0)
print("Unsqueeze 增加 Batch 维度后形状:", input_tensor.shape)

# 4. 模拟网络输出，降维 (Squeeze)
output_tensor = input_tensor.squeeze(0)
print("Squeeze 挤压 Batch 维度后形状:", output_tensor.shape)

# 5. Reshape 与 Contiguous / View 试验
flat_features = rs_img_chw.reshape(4, -1)  # 展开空间维度
print("展平空间维度后的形状 (C x H*W):", flat_features.shape)

# 验证 non-contiguous 内存转换
permuted_t = remote_sensing_img.permute(2, 0, 1)
print("Permute 后内存是否连续:", permuted_t.is_contiguous())
contiguous_t = permuted_t.contiguous()
print("调用 contiguous 后内存是否连续:", contiguous_t.is_contiguous())

print("\n🏁 Day20 GeoAI Tensor 运算与维度变换实战完成！")
```

`reshape()`函数可以在**保证张量数据不变**的前提下**改变数据的维度**，将其**转换成指定的形状**。

**Day02-10 张量的形状操作_unsqueeze和squeeze函数**：

`squeeze()`函数删除形状为1的维度(**降维**)；`unsqueeze()`函数添加形状为1的维度(升维)。

**Day02-11 张量的形状操作_transpose和permute函数**：
`transpose()`函数可以实现**交换张量形状的指定维度**，例如：一个张量的形状为(2，3，4)，可通过`transpose`函数把3和4进行交换，将张量形状变为(2, 4, 3)。

`permute()`函数可以**一次交换更多的维度**。

**Day02-12 张量的形状操作_view和contiguous函数**：

`view()`函数也可以用于**修改张量的形状**，只能用于修改**连续**的张量。在PyTorch中，有些张量的底层数据在内存中的存储顺序与其在张量中的逻辑顺序不一致，`view`函数无法对这样的张量进行变形处理，例如：一个张量**经过了`transpose`或者`permute`函数的处理**之后，就**无法使用`view`函数**进行形状操作。
