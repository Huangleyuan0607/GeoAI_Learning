### 第二阶段：理论复习（约 1.0 小时）

按八个关键词把 Day31—Day42 串成一条主线，写成 `CNN知识体系.md`：

- **核心知识点**：

  - **① 卷积**：局部连接 + 权重共享 + 平移不变性；本质是滑动窗口点积（实现的是交叉相关）。参数量 = `c_i × k² × c_o + c_o`，**与图像尺寸无关**。

  - **② Padding**：`padding = (k-1)/2` 保持尺寸（Same）；不加会一路"啃边"（Valid）。Day34→Day35 的对比实验证明了这点：32→30→15→13→6→4→2 vs 全程保尺寸。
  - **③ Stride**：控制下采样与感受野；也是 Backbone 里 **stage 之间降分辨率**的主要手段之一。
- **④ Pooling**：最大池化保留显著响应、平均池化更平滑；**只在 H/W 上操作，通道数不变**；无参数。**全局平均池化（GAP）**替代巨型全连接层（Day40 NiN 提出）。
  - **⑤ Backbone**：主干网络负责"把图变成特征图"，Task Head 负责"把特征图变成任务输出"；同一 Backbone 可换不同 Head 服务分类 / 分割 / 检测。
- **⑥ ResNet**：残差块 `f(x) = x + g(x)` 解决深层网络的**退化问题**；`downsample` 只含 1×1 卷积 + BN，**没有 ReLU**（捷径分支只需线性变换）。Bottleneck（1×1→3×3→1×1，expansion=4）vs BasicBlock（两个 3×3）。
  - **⑦ BatchNorm**：训练用当前 batch 统计量、推理用 running 统计量；作用是加速训练 / 稳定梯度 / 提升泛化；参数量 = `C × 2`（γ 与 β）。
- **⑧ 数据增强**：翻转 / 裁剪 / 旋转 / 颜色变化；**只在训练时做**，本质是一个正则项；不改模型结构，只改输入分布。
  
- **贯穿全程的一条主线 —— 参数量分布的演进**：

  | 网络 | 参数量 | 全连接层占比 | 关键改进 |
  | ---- | ------ | ------------ | -------- |
  | AlexNet（Day36） | 61.1 M | **96.0%** | ReLU、Dropout、GPU |
  | VGG16（Day37） | 138.4 M | **89.4%** | 3×3 小核堆叠、Block 模块化 |
  | NiN / GoogLeNet（Day40） | 5.98 M | **0.17%** | 1×1 降维 + **GAP** |
  | 简化 ResNet（Day38） | 11.18 M | **0.05%** | 残差连接 |
  | ResNet50（Day39） | 25.6 M | **8.0%** | Bottleneck + 分层 stage |

  > **一句话总结这四天**：卷积层参数由**通道数和核大小**决定、与图像尺寸无关；全连接层参数随**展平维度**线性膨胀。整个经典 CNN 发展史，就是想办法**把参数从全连接层搬回卷积层**。

- **与课题组方向的对应关系**（这部分是今天新增的思考）：

  | 刚学完的 CNN 概念 | 在地图综合任务中的落点 |
  | ---------------- | ---------------------- |
  | 多尺度特征（Inception / 不同 stage 的特征图） | 不同比例尺下的要素取舍与详细程度 |
  | GAP 替代全连接 | 建筑物轮廓"整体形态"编码，不受顶点数影响 |
  | Backbone + Task Head | 同一骨干分别接"化简"、"选取"、"典型化"三种算子 |
  | 预训练 + 微调（Day39） | 影像 / 地图瓦片样本少，靠预训练迁移 |
  | 数据增强（Day42） | 缓解标注成本高；但**坡向、流向、注记方向不可随意翻转旋转** |
  | Encoder–Decoder（自编码器，2024 曲线压缩论文） | 正是下一阶段 FCN / U-Net 的结构雏形 |

```python
"""本程序用于数据预处理与加载器构建：训练带增广、测试不带增广"""


# 导包
import torch
from torch.utils.data import DataLoader, Subset
from torchvision.datasets import FashionMNIST
from torchvision import transforms

from config import config


# 1.定义增广变换：只在训练阶段使用（Day42结论：增广是正则项，测试时必须关闭）
def get_transforms():
    # 1.1训练阶段：几何 + 颜色增广
    # 注意：这里刻意不做RandomRotation与垂直翻转——真实的建筑物俯视图有朝向语义，
    #       坡向/流向/注记方向被转过后地理含义就变了（Day42笔记中记录的坑）
    train_transform = transforms.Compose([
        transforms.RandomHorizontalFlip(p = 0.5),                               # 翻转：左右朝向不影响形态类别
        transforms.RandomResizedCrop(config.IMAGE_SIZE, scale = (0.7, 1.0)),    # 裁剪：模拟不同图幅裁切
        transforms.ColorJitter(brightness = 0.3, contrast = 0.3),               # 颜色：模拟不同成像条件
        transforms.ToTensor(),
        transforms.Normalize(mean = (0.2860,), std = (0.3530,))
    ])
    # 1.2测试阶段：只做确定性预处理，保证评估口径固定
    test_transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize(mean = (0.2860,), std = (0.3530,))
    ])
    return train_transform, test_transform


# 2.定义标签映射：把FashionMNIST的10类折叠成3类形态，作为建筑物轮廓的替身任务
def map_to_morphology(label):
    """
    将原始类别映射为形态三分类
    compact(0)   ：团块状 -> 近似方块的建筑
    elongated(1) ：纵向延伸明显 -> 狭长条形建筑
    irregular(2) ：其余混合      -> 不规则形建筑
    """
    if label in (0, 8, 9):        # T恤 / 鞋 / 短靴
        return 0
    elif label in (7, 5, 3):      # 长靴 / 连衣裙 / 裙装
        return 1
    else:                         # 套衫 / 衬衫 / 大衣等
        return 2


class MorphologyDataset(torch.utils.data.Dataset):
    """把FashionMNIST包装成形态三分类数据集（真实数据接入时替换本类的读取逻辑即可）"""
    def __init__(self, root, train, transform, samples):
        base = FashionMNIST(root = root, train = train, transform = transform, download = False)
        self.data = Subset(base, range(samples))       # 取子集保证运行效率

    def __len__(self):
        return len(self.data)

    def __getitem__(self, idx):
        image, label = self.data[idx]
        return image, map_to_morphology(label)


# 3.定义数据加载函数：augment开关支持消融实验
def get_data_loaders(augment = True):
    train_transform, test_transform = get_transforms()
    train_dataset = MorphologyDataset(config.DATA_ROOT, train = True,
                                      transform = train_transform if augment else test_transform,
                                      samples = config.TRAIN_SAMPLES)
    test_dataset = MorphologyDataset(config.DATA_ROOT, train = False,
                                     transform = test_transform,
                                     samples = config.TEST_SAMPLES)
    train_loader = DataLoader(train_dataset, batch_size = config.BATCH_SIZE, shuffle = True, num_workers = config.NUM_WORKERS)
    test_loader = DataLoader(test_dataset, batch_size = config.BATCH_SIZE, shuffle = False, num_workers = config.NUM_WORKERS)
    return train_loader, test_loader


# 4.测试
if __name__ == '__main__':
    train_loader, test_loader = get_data_loaders(augment = True)
    x, y = next(iter(train_loader))
    print(f"train batches: {len(train_loader)}, test batches: {len(test_loader)}")
    print(f"batch shape: {tuple(x.shape)}  label shape: {tuple(y.shape)}")
    print(f"本批类别分布：{[int((y == c).sum()) for c in range(config.NUM_CLASSES)]}")
```

```python
"""本程序用于定义CNN模型：显式拆分 Backbone 与 Task Head（对应Day39的Backbone概念）"""


# 导包
import torch
import torch.nn as nn

from config import config


# 1.定义卷积块：Conv -> BN -> ReLU -> MaxPool（顺序来自Day35优化实践）
def conv_block(in_c, out_c, kernel_size = 3, padding = 1, pool = True):
    layers = [
        nn.Conv2d(in_c, out_c, kernel_size = kernel_size, padding = padding),
        nn.BatchNorm2d(out_c),
        nn.ReLU(),
    ]
    if pool:
        layers.append(nn.MaxPool2d(2, 2))
    return nn.Sequential(*layers)


# 2.定义形态判别网络：Backbone负责提特征，Head负责出结果
class MorphologyCNN(nn.Module):
    """建筑物（替身）形态三分类网络"""
    def __init__(self, in_channels = 1, num_classes = None, dropout = 0.5):
        super(MorphologyCNN, self).__init__()
        num_classes = num_classes or config.NUM_CLASSES
        # 1.Backbone：三级下采样，28 -> 14 -> 7 -> 3
        #   三个stage输出的空间分辨率不同，天然构成"多尺度特征"，
        #   与地图的多比例尺表达是同构的思想（Day40 Inception多尺度的延续）
        self.backbone = nn.Sequential(
            conv_block(in_channels, 32),        # (N, 32, 14, 14) 细节层：边缘、角点
            conv_block(32, 64),                 # (N, 64, 7, 7)   中间层：局部构件
            conv_block(64, 128),                # (N, 128, 3, 3)  语义层：整体形态
        )
        # 2.Task Head：全局平均池化 + 全连接
        #   用GAP而不是Flatten+大Linear，避免Day36/Day37看到的"全连接层占90%参数"问题
        self.head = nn.Sequential(
            nn.AdaptiveAvgPool2d((1, 1)),       # 对每个通道求平均 -> (N, 128, 1, 1)
            nn.Flatten(),                       # (N, 128)
            nn.Dropout(dropout),
            nn.Linear(128, num_classes),        # 输出logits：CrossEntropyLoss自带softmax，末端不再加
        )

    def forward(self, x):
        x = self.backbone(x)
        return self.head(x)

    def freeze_backbone(self):
        """冻结主干：做迁移学习/微调时用（对应导师论文中的预训练模型思路）"""
        for p in self.backbone.parameters():
            p.requires_grad = False


# 3.测试
if __name__ == '__main__':
    model = MorphologyCNN()
    x = torch.randn(2, 1, 28, 28)
    model.eval()
    with torch.no_grad():
        y = model(x)
    total = sum(p.numel() for p in model.parameters())
    bb = sum(p.numel() for p in model.backbone.parameters())
    hd = sum(p.numel() for p in model.head.parameters())
    print(f"输入 {tuple(x.shape)} -> 输出 {tuple(y.shape)}")
    print(f"Backbone参数量：{bb:,}（占 {bb / total * 100:.1f}%）")
    print(f"Task Head参数量：{hd:,}（占 {hd / total * 100:.1f}%）")
    print(f"总参数量：{total:,}")
```

```python
"""本程序用于定义辅助工具函数：随机种子、计时、混淆矩阵与OA/P/R/F1指标"""


# 导包
import random
import time

import numpy as np
import torch


# 1.固定随机种子：保证对比实验可复现（Day41对比BN时用过同样的做法）
def set_seed(seed = 42):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)


# 2.获取可用设备
def get_device():
    return torch.device('cuda' if torch.cuda.is_available() else 'cpu')


# 3.简易计时器
class Timer:
    def __enter__(self):
        self.start = time.time()
        return self

    def __exit__(self, *args):
        self.cost = time.time() - self.start
        print(f"[Time] {self.cost:.2f}s")


# 4.由预测与标签构建混淆矩阵
def confusion_matrix(y_pred, y_true, num_classes):
    cm = np.zeros((num_classes, num_classes), dtype = int)
    for p, t in zip(y_pred, y_true):
        cm[t][p] += 1
    return cm


# 5.计算OA与各类的Precision / Recall / F1（论文里最常用的指标组，Day44制图综合评价的地基）
def compute_metrics(cm, class_names):
    total = cm.sum()
    oa = np.trace(cm) / total                     # 总体精度：对角线之和 / 总数
    print(f"{'类别':<12}{'P':>8}{'R':>8}{'F1':>8}{'Support':>10}")
    f1_list = []
    for i, name in enumerate(class_names):
        tp = cm[i][i]
        fp = cm[:, i].sum() - tp                  # 被误判成该类
        fn = cm[i, :].sum() - tp                  # 该类被漏判
        precision = tp / (tp + fp) if (tp + fp) else 0.0
        recall = tp / (tp + fn) if (tp + fn) else 0.0
        f1 = 2 * precision * recall / (precision + recall) if (precision + recall) else 0.0
        f1_list.append(f1)
        print(f"{name:<12}{precision:>8.4f}{recall:>8.4f}{f1:>8.4f}{cm[i].sum():>10}")
    macro_f1 = float(np.mean(f1_list))            # 宏平均：每类同等重要，类别不平衡时看这个
    print(f"OA = {oa:.4f}   Macro-F1 = {macro_f1:.4f}")
    return oa, macro_f1


# 6.测试
if __name__ == '__main__':
    set_seed(42)
    cm = confusion_matrix([0, 1, 2, 0, 1, 2, 0, 0], [0, 1, 1, 0, 1, 2, 2, 0], num_classes = 3)
    print("混淆矩阵：\n", cm)
    compute_metrics(cm, ('compact', 'elongated', 'irregular'))
```

```python
"""本程序用于模型训练：标准五步训练循环 + 最优权重保存"""


# 导包
import os

import torch
import torch.nn as nn
import torch.optim as optim

from config import config
from dataset import get_data_loaders
from model import MorphologyCNN
from utils import set_seed, get_device, Timer, compute_metrics, confusion_matrix


# 1.定义训练一个epoch的函数
def train_one_epoch(model, loader, criterion, optimizer, device):
    model.train()             # 训练模式：BN用当前batch统计量，Dropout生效
    total_loss, total_correct, total_num = 0.0, 0, 0
    y_pred_all, y_true_all = [], []
    for x, y in loader:
        x, y = x.to(device), y.to(device)
        y_pred = model(x)     # 前向传播
        loss = criterion(y_pred, y)
        optimizer.zero_grad() # 梯度清零
        loss.backward()       # 反向传播
        optimizer.step()      # 参数更新
        pred = y_pred.argmax(dim = 1)
        total_correct += (pred == y).sum().item()
        total_loss += loss.item() * y.shape[0]
        total_num += y.shape[0]
        y_pred_all.extend(pred.tolist())
        y_true_all.extend(y.tolist())
    return total_loss / total_num, total_correct / total_num, (y_pred_all, y_true_all)


# 2.定义评估函数
@torch.no_grad()              # 不建计算图，省显存
def evaluate(model, loader, device):
    model.eval()              # 测试模式：BN改用running统计量，Dropout关闭
    total_loss, total_correct, total_num = 0.0, 0, 0
    y_pred_all, y_true_all = [], []
    criterion = nn.CrossEntropyLoss()
    for x, y in loader:
        x, y = x.to(device), y.to(device)
        y_pred = model(x)
        total_loss += criterion(y_pred, y).item() * y.shape[0]
        pred = y_pred.argmax(dim = 1)
        total_correct += (pred == y).sum().item()
        total_num += y.shape[0]
        y_pred_all.extend(pred.tolist())
        y_true_all.extend(y.tolist())
    return total_loss / total_num, total_correct / total_num, (y_pred_all, y_true_all)


# 3.定义主训练流程
def train(augment = True):
    set_seed(42)              # 固定种子，保证增广对比实验公平
    device = get_device()
    print(f"Training on {device} | augment = {augment}")

    # 3.1准备数据、模型、损失与优化器
    train_loader, test_loader = get_data_loaders(augment = augment)
    model = MorphologyCNN().to(device)
    criterion = nn.CrossEntropyLoss()
    optimizer = optim.Adam(model.parameters(), lr = config.LEARNING_RATE, weight_decay = config.WEIGHT_DECAY)
    scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max = config.EPOCHS)

    # 3.2打印模型结构与参数量分布（Backbone vs Head）
    print(model)
    total = sum(p.numel() for p in model.parameters())
    bb = sum(p.numel() for p in model.backbone.parameters())
    print(f"总参数量：{total:,} | Backbone占 {bb / total * 100:.1f}% | Head占 {(total - bb) / total * 100:.1f}%")
    print("=" * 60)

    # 3.3训练循环
    best_acc = 0.0
    os.makedirs(os.path.dirname(config.MODEL_SAVE_PATH), exist_ok = True)
    for epoch in range(1, config.EPOCHS + 1):
        with Timer() as t:
            train_loss, train_acc, _ = train_one_epoch(model, train_loader, criterion, optimizer, device)
            test_loss, test_acc, _ = evaluate(model, test_loader, device)
        scheduler.step()
        print(f"Epoch {epoch}/{config.EPOCHS}  train_loss = {train_loss:.4f}  train_acc = {train_acc:.4f}  "
              f"test_loss = {test_loss:.4f}  test_acc = {test_acc:.4f}  gap = {train_acc - test_acc:+.4f}  ({t.cost:.2f}s)")
        if test_acc > best_acc:                   # 保存最优权重而非最后一轮
            best_acc = test_acc
            torch.save(model.state_dict(), config.MODEL_SAVE_PATH)
    print("=" * 60)
    print(f"Best test acc = {best_acc:.4f}，权重已保存至 {config.MODEL_SAVE_PATH}")
    return model, test_loader, device


# 4.测试
if __name__ == '__main__':
    train(augment = True)
```

## 一、卷积（Convolution）

### 1.1 定义与三大特性

**CNN = 含有卷积层的神经网络**，卷积层的作用是**自动学习并提取图像特征**。相比全连接层，卷积层靠三个特性把参数量压低几个数量级：

| 特性 | 含义 | 带来的收益 |
|---|---|---|
| **局部连接（局部感受野）** | 每个神经元只与输入的一小块区域相连 | 参数大幅减少 |
| **权重共享** | 同一个卷积核在整张图上复用同一组权重 | 参数量与图像尺寸解耦 |
| **空间（平移）不变性** | 目标平移后仍能被同一核识别 | 不需要为每个位置单独学一遍 |

> 李沐第 63 讲的推导路径：**对全连接层同时施加「局部性」与「平移不变性」两条原则，就得到了卷积层。** 补充一句：**一个卷积核就是一个神经元**。

### 1.2 计算本质与公式

卷积运算本质是**卷积核与输入局部区域做点积**：

$$
\mathbf{Y} = \mathbf{X} \star \mathbf{W} + b
$$

| 张量 | 形状 |
|---|---|
| 输入 X | c_i x n_h x n_w |
| 核 W | c_o x c_i x k_h x k_w |
| 输出 Y | c_o x m_h x m_w |

**W 和 b 是可学习参数；核矩阵的大小是超参数**（训练前人为设定）。

**交叉相关 vs 卷积**：二维互相关是 
$$
y_{i,j} = \sum_{a}\sum_{b} w_{a,b} x_{i+a,j+b}
$$
，真正的卷积是把核翻转 180°（下标取负）。**由于对称性，实际使用中没有区别** —— 所以叫"卷积层"，实现的其实是交叉相关。

### 1.3 参数量公式（⭐ 重点）

$$
\text{卷积核参数} = c_i \times k_h \times k_w \times c_o + c_o
$$

最后一项是偏置（每个卷积核一个）。验证（Day35 conv1：3→32 通道，3×3）：3 x 3 x 3 x 32 + 32 = 896。

> ⚠️ **这条公式最重要的推论**：卷积层参数量**只由通道数和核大小决定，与图像尺寸完全无关**。这正是权重共享的回报，也是下一节问题的来源。

### 1.4 多通道卷积三条规则

1. **图像通道数 = 卷积核通道数**（输入 3 通道，核也必须有 3 个通道）；
2. 核的每个通道与**对应**输入通道做卷积；
3. 各通道结果**按位相加**，得到一个输出通道。

要输出 c_o 个特征图，就需要 c_o 个"具有 c_i 个通道"的三维核：**每个输出通道独立负责识别一种模式**。

### 1.5 1×1 卷积（⭐ 承上启下的关键）

- **不识别空间模式，只做跨通道融合**；
- 等价于把输入当 (n_h, n_w, c_i)、权重当 (c_o, c_i) 的**全连接层**；
- 用途：**通道升维 / 降维**、增强非线性表达能力。

> 它是理解后面一切的钥匙：NiN 的 MLP 卷积层是它、Inception 的降维瓶颈是它、ResNet Bottleneck 的先压后抬还是它。

### 1.6 计算复杂度

$$
O(c_i \, c_o \, k_h \, k_w \, m_h \, m_w)
$$

举例：c_i=c_o=100、k=5、m=64 ≈ 1 GFLOP；10 层 × 100 万样本 ≈ 10 PFlops —— CPU（0.15 TF）需 18 小时，GPU（12 TF）仅 14 分钟。**这就是"深度学习必须用 GPU"的定量答案。**

## 二、Padding 与 Stride

### 2.1 特征图尺寸推导公式（⭐ 最核心）

$$
\boxed{H_{out} = \left\lfloor \frac{H_{in} + 2P - F}{S} \right\rfloor + 1}
$$

F = kernel_size，P = padding，S = stride。**除不尽时向下取整**。

**两个常用特例**：

- 取 P = \frac{F-1}{2}（3×3 取 1、5×5 取 2）→ 输出尺寸**与输入相同**（Same Padding）；
- 输入高宽能被步幅整除时 → 简化为 H_in / S。

奇数核上下各填 P/2；偶数核一侧向上取整、另一侧向下取整。

### 2.2 Padding 三种类型

| 类型 | 说明 | 使用场景 |
|---|---|---|
| **Valid（No Padding）** | 不填充，一路"啃边" | 不在意边缘信息、输入足够大 |
| **Same** | 填充使输出 = 输入 | **最广泛**，现代网络默认做法 |
| **Full** | 填 k-1，输出反而变大 | 少用，计算量大且边缘有伪影 |

**实证对比（Day34 vs Day35，同一个 CIFAR-10 任务）**：

```
无 padding：32 → 30 → 15 → 13 → 6 → 4 → 2   （13→6 那次池化还丢掉一行一列）
padding=1：32 → 32 → 16 → 16 → 8 → 8 → 4    （全程整数、不丢边、分辨率翻倍）
```

> 这不是理论优劣，是**实测出来的差别**：加 padding 后测试集准确率从 0.77 提到 0.79。

### 2.3 Stride 的两个作用

- **降低计算复杂度**：滑动的次数变少；
- **增大感受野**：每个神经元覆盖更大的输入范围。

惯例：**早期层 stride=1** 保留空间细节，**后期层 stride=2/4** 快速降维。

> ⚠️ **易错点**：步长每次只能朝**一个方向**移动。某方向剩余可滑动距离不足一个步长时，取消该次滑动并**换向**重新滑动。

## 三、池化层（Pooling）

### 3.1 两大类型

| 类型 | 计算 | 特点 |
|---|---|---|
| **最大池化** | 取窗口最大值 | 保留最显著的边缘 / 高频特征，容忍约 1 像素移位 |
| **平均池化** | 取窗口均值 | 平滑响应，保留背景与全局平缓信息 |

### 3.2 三条铁律

1. **只在 H/W 上操作，通道数不变** —— 池化对每个通道**分别**处理，各通道结果**不相加**（这与卷积层正好相反，是最容易记混的一点）；
2. **无可学习参数** —— 没有 Weight 和 Bias，只是固定的窗口规则；
3. **步长一般取窗口大小**，保证池化窗口互不相交。

### 3.3 全局平均池化（GAP）—— 本知识体系的转折点

把每个通道的整张特征图直接压成一个数：(N, C, H, W) \to (N, C)。

> **来源澄清（Day40）**：GAP 最早由 **NiN（2013）** 提出，**不是 ResNet 的发明**，ResNet 只是沿用。

它解决的是这一整个阶段的头号问题 —— **巨型全连接层**：

| 网络 | 第一个全连接层参数量 |
|---|---|
| LeNet | 16 × 5 × 5 × 120 = 48K |
| AlexNet | 256 × 5 × 5 × 4096 = **26M** |
| VGG16 | 512 × 7 × 7 × 4096 = **102M** |

**卷积层参数与尺寸无关，全连接层参数随展平维度线性增长** —— 展平维度一大就爆炸。GAP 直接把"展平"这一步消掉了。

## 四、经典网络演进史

### 4.1 五个网络的定位

| 网络 | 年份 | 结构 | 关键创新 | 遗留问题 |
|---|---|---|---|---|
| **LeNet** | 1998 | 2 卷 + 2 池 + 3 全 | 最早成功的 CNN，卷积编码器 + 全连接密集块 | 浅、Sigmoid 易饱和 |
| **AlexNet** | 2012 | 5 卷 + 3 全 | **ReLU、MaxPool、Dropout、GPU 训练** | FC 占 96% |
| **VGG** | 2014 | 13/16 卷 + 3 全 | **3×3 小核堆叠** + Block 模块化 | 参数总量 138M |
| **NiN** | 2013 | NiN 块 + **GAP** | 1×1 卷积充当全连接、**首创 GAP** | — |
| **GoogLeNet** | 2014 | 9 个 Inception，5 段 | **多尺度并行** + 1×1 降维 | 手工设计支路 |
| **ResNet** | 2015 | BasicBlock / Bottleneck | **残差连接**，第一个上百层实用网络 | — |

### 4.2 VGG：为什么用小核堆叠

| 方案 | 感受野 | 参数量（通道均为 C） |
|---|---|---|
| 1 个 5×5 | 5×5 | 25C^2 |
| **2 个 3×3** | 5×5 | 2 x 9C^2 = 18C^2 ✅ |
| 1 个 7×7 | 7×7 | 49C^2 |
| **3 个 3×3** | 7×7 | 3 x 9C^2 = 27C^2 ✅ |

**双重收益**：参数更少，而且每层卷积之间都插了 ReLU，**非线性更强**。

### 4.3 GoogLeNet：Inception 的四条支路

| 线路 | 结构 | 作用 |
|---|---|---|
| 1 | 1×1 | 点状特征 + 通道变换 |
| 2 | 1×1 → 3×3 | 先降维再提特征 |
| 3 | 1×1 → 5×5 | 先降维再提特征 |
| 4 | 3×3 MaxPool → 1×1 | 池化提特征后调通道 |

四条支路**输出尺寸一致、通道数不同**，最后在**通道维 `torch.cat`** 拼接。

> **计算规律**：单个 Inception 的输出通道 = c_1 + c_2[1] + c_3[1] + c_4，下一层的输入通道必须等于上一层这个和 —— 各级配置就是这么串起来的。
> **为什么每条支路前都加 1×1？** 因为 3×3/5×5 若在原始通道数上直接做，计算量会爆炸。**1×1 先降维是 Inception 能控制计算量的关键**。

### 4.4 ResNet：残差连接

深层网络的问题是**退化（degradation）**：不是过拟合，而是**网络加深后训练误差本身反而上升** —— 理论上更深的网络至少能表达浅层的函数，却学不出来。

解法是改**学习目标**：让块学残差 F(x) = H(x) - x，即

$$
f(x) = x + F(x)
$$

多余的层只需把 F(x) 学成 0 就退化成恒等映射 —— **比直接学恒等映射容易得多**。

| 概念 | 含义 |
|---|---|
| **Shortcut / 捷径分支** | 那条把 x 直接加过来的通路 |
| **Identity Mapping** | 捷径分支不做任何变换，原样传递 |
| **Residual Block** | 主干 F(x) + 捷径 x 组成的整体 |

**两种情况**：形状一致时直接相加；形状不一致（如 stage 交界处通道翻倍、H/W 减半）时，捷径分支需用 **1×1 卷积 + BN** 调整。

> ⚠️ **踩过的坑（Day39）**：`downsample` 只含 1×1 卷积和 BN，**没有 ReLU** —— 因为它是捷径分支，只需线性变换。

**BasicBlock vs Bottleneck**：

| 特性 | BasicBlock | Bottleneck |
|---|---|---|
| 卷积层 | 两个 3×3 | 1×1 → 3×3 → 1×1 |
| `expansion` | 1 | **4** |
| 输出通道 | `planes` | `planes × 4` |
| 下采样位置 | conv1 | conv2（中间那个） |
| 适用网络 | ResNet-18/34 | ResNet-50/101/152 |

ResNet50 层数命名依据：16 个 Bottleneck × 3 卷积 + 1（stem conv）+ 1（fc）= **50**。

### 4.5 参数量分布：贯穿全程的那条线（⭐ 最重要的一张表）

| 网络 | 总参数量 | 全连接层占比 |
|---|---|---|
| AlexNet（Day36） | 61.1 M | **96.0%** |
| VGG16（Day37） | 138.4 M | **89.4%** |
| ResNet50（Day39） | 25.6 M | 8.0% |
| GoogLeNet（Day40） | 5.98 M | **0.17%** |
| 简化 ResNet（Day38） | 11.18 M | **0.05%** |
| **本日 CNN_template** | **237 K** | **Head 仅 1.7%** |

> **把这六个数字连起来看，就是半部 CNN 发展史**：卷积层参数由通道数和核大小决定、与图像尺寸无关；全连接层参数随展平维度线性膨胀。整个演进过程，就是**想办法把参数从全连接层搬回卷积层** —— 手段是 1×1 卷积（NiN / Inception）+ GAP（NiN → GoogLeNet → ResNet）。

## 五、Backbone 与 Task Head

### 5.1 分工

```
输入图像 →【Backbone 主干】→ 特征图 →【Task Head 任务头】→ 任务输出
```

- **Backbone**：把图像"读"成一组由粗到细的特征，**与具体任务无关，可复用**；
- **Task Head**：把特征转成任务需要的形式 —— 分类头（GAP+Linear）、检测头、分割头（反卷积上采样）。

### 5.2 Stage 与多尺度特征

Backbone 内部按 stride 下采样分成若干 **stage**，每个 stage 输出不同分辨率、不同通道数的特征图：

```
ResNet50：conv1+maxpool → layer1(56×56) → layer2(28×28) → layer3(14×14) → layer4(7×7)
              低层：边缘、角点等细节        ↑        高层：语义、整体形态
```

**这两个事实合起来就是现代视觉模型的骨架**：浅层保细节、深层保语义，且天然构成多尺度金字塔 —— U-Net 的 skip connection、DeepLabv3+ 的 ASPP 都是在这个金字塔上做文章。

### 5.3 预训练与微调

ImageNet 预训练权重已经把"如何从像素提取通用视觉特征"这件事学会了，下游任务只需：

1. 换掉 Task Head（类别数改成自己的）；
2. 冻结 / 部分解冻 Backbone；
3. 用小学习率微调。

> **这是课题组论文里最常见的范式**（《基于预训练模型的矢量海岸线形态模式判别方法》），也是地理数据标注样本少时最有效的应对手段。本日模板里专门留了 `freeze_backbone()` 方法就是这个用途。

## 六、BatchNorm（批量归一化）

### 6.1 动机与做法

深层网络中，**中间层的输入分布会随着前面层的更新而不断变化**，导致深层难训练。BN 的做法是**在 batch 维度上对每个通道做标准化**，再用可学习参数补偿：

$$
\mu_B = \frac{1}{|B|}\sum_{i \in B} x_i, \qquad \sigma_B^2 = \frac{1}{|B|}\sum_{i \in B}(x_i-\mu_B)^2 + \epsilon
$$

$$
x_{i+1} = \gamma \frac{x_i - \mu_B}{\sigma_B} + \beta
$$

> 用黑马的话概括就是两步：**先标准化（归一化），再缩放和平移**。γ 和 β 是可学习参数，用来补回标准化时被抹掉的有用信息。

### 6.2 三个作用 + 一个诚实的边界

- **加速训练**（可以配更大学习率）
- **稳定梯度**
- **提升泛化能力**

> ⚠️ **李沐第 91 讲的提醒**：最初的说法是"减少内部协变量转移"，但后续论文指出它更可能是**通过在每个小批量里引入随机噪声（随机的 \hat{\mu}_B、\hat{\sigma}_B）来控制模型复杂度**。因此：**BN 没必要跟 Dropout 混合使用**；BN **能加速收敛，但一般不改变模型最终精度**。

### 6.3 训练阶段 vs 推理阶段（⭐ 最容易考、最容易错）

| 阶段 | 均值 / 方差来源 | 特点 |
|---|---|---|
| **训练** | 当前 batch 的 `mean` / `variance` | 每个 batch 重新统计，同时更新 `running mean/var` |
| **推理** | `running mean` / `running variance` | 不再依赖 batch，**单张图片也能前向** |

实现要点：

- `moving_mean` / `moving_var` 用 **`register_buffer`** 注册 —— 不是可训练参数，但属于模型状态、随 `.to(device)` 和 `state_dict` 一起走；
- 更新用滑动平均：`moving = momentum * moving + (1 - momentum) * batch_stat.detach()`，**`detach()` 避免统计量被计入计算图**；
- 初始值：`moving_mean = 0`、`moving_var = 1`。

### 6.4 作用在哪一维

| 层类型 | 归一化维度 | `num_features` 传什么 |
|---|---|---|
| **全连接层** `(N, C)` | 在 **N（样本）** 维上求统计量 | 输出特征数 |
| **卷积层** `(N, C, H, W)` | 在 **(N, H, W)** 上求，**每个通道一套** | 通道数 |

放置顺序：**Conv → BN → ReLU → Pool**（激活函数**之前**）。

参数量：C x 2（只有 γ 和 β）。

> PyTorch 对照：`nn.BatchNorm1d`（全连接 / 一维）、`nn.BatchNorm2d`（图像）、`nn.BatchNorm3d`（视频 / 体数据）。

## 七、数据增强（Data Augmentation）

### 七种常见手段与其代价

| 手段 | 典型 API | 改变了什么 | 保持不变 |
|---|---|---|---|
| **翻转** | `RandomHorizontalFlip` | 左右朝向 | 类别标签 |
| **裁剪** | `RandomResizedCrop` | 位置、占比、视野 | 类别标签 |
| **旋转** | `RandomRotation` | 朝向 | 类别标签 |
| **颜色变化** | `ColorJitter` | 亮度 / 对比度 / 色调 / 饱和度 | 几何结构 |

李沐第 111 讲的补充细节：切割时会随机取**高宽比**（如 [3/4, 4/3]）、**大小**（如 [8%, 100%]）、**位置**；颜色则改**色调、饱和度、明亮度**（如 [0.5, 1.5]）；此外还有几十种，如高斯模糊、部分设黑、变形、锐化。

### 7.2 本质：它在给模型注入先验

> **数据增强并没有真的增加信息量。** 它是把"**人对数据不变性的先验知识**"（物体翻过来还是那个物体）注入到训练中 —— 相当于告诉网络："这些变化请忽略，别为它们分配容量。"

因此它**是一个正则项**，与 Dropout、weight decay 属于同一族。

### 7.3 两条使用纪律

1. **只在训练时做，测试时不做**（Day42 实验的直接结论）；
2. **增广不改变模型结构，只改变输入分布** —— 参数量前后完全一致（与 BN 恰好形成对照：BN 改结构、增广改数据）。

### 7.4 实验结论回顾（Day42）

| 观察点 | 无增广 | 有增广 |
|---|---|---|
| train_acc | 一路走高 0.85 → 0.95 | 明显偏低 0.79 → 0.88（样本变难了） |
| test_acc | 早早见顶 ≈ 0.90 | 持续上升，最终更高 ≈ 0.91 |
| **train/test gap** | **逐步拉开（过拟合征兆）** | **始终很小（泛化更好）** |

> ⚠️ **读这类数据的陷阱**：加了增广后 **train_acc 一定会下降**，如果盯着"准确率有没有涨"就会得出反向结论。**要看的是 gap 的变化方向。**

### 7.5 ⭐ 地理数据的特殊限制（本日新增思考）

自然图像里"倒过来的猫还是猫"，但地图要素未必如此：

| 限制 | 原因 | 后果 |
|---|---|---|
| **方向具有地理语义** | 坡度坡向、河流流向、指北针、注记文字方向 | 一旦翻转 / 旋转，**地理含义就变了** —— 这类数据不能无脑做几何增广 |
| **坐标必须同步** | 分割 / 检测任务的标签依附于像素位置 | 几何类增广必须**同时作用于图像和 mask / bbox**；颜色类只改图像、标签不动 |

> 本日 `CNN_template/dataset.py` 里刻意**不加 `RandomRotation` 与垂直翻转**，就是把这条限制落进了代码。

## 八、完整训练 Pipeline 与工程规范

### 8.1 端到端流程

$$
\text{数据加载} \to \text{特征提取(Conv+Pool)} \to \text{聚合(GAP/Flatten)} \to \text{分类(Linear)} \to \text{Loss} \to \text{Optimizer}
$$

### 8.2 训练循环骨架（五步）

```python
model.train()                      # ① 切训练模式（BN用batch统计量、Dropout生效）
y_pred = model(x)                  # ② 前向
loss = criterion(y_pred, y)
optimizer.zero_grad()              # ③ 梯度清零（不清会累加上一步的梯度）
loss.backward()                    # ④ 反向传播
optimizer.step()                   # ⑤ 参数更新
```

评估阶段：

```python
model.eval()                       # BN改用running统计量、Dropout关闭
with torch.no_grad():              # 不建计算图，省显存
    pred = model(x).argmax(dim=1)
```

> **`CrossEntropyLoss` 已内含 softmax** —— 网络末端不要再加 `softmax()`，预测时用 `argmax()` 取 logits 下标。

### 8.3 六文件工程模板（本日产出）

| 文件 | 职责 | 换任务时要不要动 |
|---|---|---|
| `config.py` | 超参数、类别名、路径、设备**集中管理** | 改数值即可 |
| `dataset.py` | 数据读取 + 增广流水线（`augment` 开关支持消融） | **换真实数据只动这里** |
| `model.py` | `self.backbone` + `self.head` 显式拆分 | 换算子只动 head |
| `utils.py` | 种子、设备、计时、混淆矩阵、OA/P/R/F1 | 通常不动 |
| `train.py` | 训练循环 + 保存**最优**权重（非最后一轮） | 通常不动 |
| `test.py` | 加载权重 + 指标报告 + 单样本概率输出 | 通常不动 |

> 这套拆法的价值在于**解耦**：数据、模型、训练、评估各自独立，做消融实验时只改一个入口 —— 呼应 Day35 踩过的"一次改多个变量，涨跌都不知道是谁的功劳"。

## 九、踩坑清单（全部来自本阶段真实实验）

1. **池化只在 H/W 上做，通道数不变** —— 各通道分别处理、**不相加**（与卷积相反）。
2. **全连接层只能吃二维数据** —— 展平不可省，除非改用 GAP。
3. **`CrossEntropyLoss` 已含 softmax** —— 末端重复加会算两遍。
4. **改了网络结构，旧权重必须重训** —— `load_state_dict` 会报 `size mismatch`，属于"响亮的失败"。
5. **改了输入预处理，旧权重也必须重训** —— 这次**不报任何错**（形状没变），但准确率会悄悄崩掉，**更隐蔽的坑**。
6. **改 `epochs` 时调度器的 `T_max` / `milestones` 必须同步改**，否则学习率提前归零、后半程空转。
7. **`downsample` 里没有 ReLU** —— 捷径分支只需线性变换。
8. **BN 的训练 / 推理两套统计量** —— 忘记 `model.eval()` 会把测试样本的 batch 统计量当成推理结果，指标虚高且不稳定。
9. **`moving_mean` 忘了 `detach()`** —— 统计量被计入计算图，白白占显存甚至报错。
10. **对比实验一次只改一个变量** —— 否则涨了不知道谁的功劳，跌了不知道回退哪项。
11. **跨实验比较 Loss 绝对值没有意义** —— Loss 定义一变数值就不可比，必须看**准确率和 train/test 差距**。
12. **跑 AlexNet 要注意输入尺寸** —— 用 FashionMNIST 得先把 28×28 拉伸到 224×224（Day36）。
13. **`NumPy` 的 `var(unbiased=False)` 才是有偏方差** —— 与 BN 内部的除以 N 一致，写错会导致前后统计量对不上。
14. **Windows 下 DataLoader `num_workers` 设为 0** —— 多进程容易卡死（本日模板 config 里已注明）。

## 十、核心公式速查表

| 项目 | 公式 |
|---|---|
| 输出特征图尺寸 | H_out = [(H_in + 2P - F) / S]（整体向下取整） + 1 |
| 保持尺寸的填充 | P = (F-1)/2（3×3 取 1，5×5 取 2） |
| 卷积层参数量 | c_i x k^2 x c_o + c_o |
| 全连接层参数量 | in x out + out |
| BatchNorm 参数量 | C x 2（γ、β） |
| 池化后尺寸 | H_out = H_in / stride（窗口=步长时） |
| 展平后维度 | C x H x W |
| Inception 输出通道 | c_1 + c_2[1] + c_3[1] + c_4 |
| 残差块输出 | f(x) = x + F(x) |
| BN 前向 | y = \gamma \dfrac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} + \beta |
| running 统计量更新 | \hat{\mu} \leftarrow m\hat{\mu} + (1-m)\mu_B |
| 卷积计算复杂度 | O(c_i c_o k_h k_w m_h m_w) |
| OA | \text{tr}(CM) / \text{sum}(CM) |
| Precision / Recall / F1 | TP/(TP+FP)， TP/(TP+FN)， 2PR/(P+R) |

## 十一、⭐ CNN 概念 ↔ 地图制图综合 对照表

这张表是本日复习真正的落点 —— 学的技术怎么接上课题组的方向。

| CNN 里的概念 | 地图综合里的对应物 | 怎么用 |
|---|---|---|
| **多尺度特征金字塔**（不同 stage 的 56/28/14/7） | **多比例尺表达**（大比例尺详细、小比例尺取舍） | 同一骨干的不同层输出，天然对应不同比例尺下的表达粒度 |
| **感受野大小**（1×1 / 3×3 / 5×5 并行） | **要素的尺度适应性**（建筑 vs 道路 vs 水系尺寸差异极大） | Inception 式并行支路可用于同时捕捉不同尺寸的要素 |
| **GAP 替代全连接** | **轮廓的整体形态编码** | 建筑物多边形顶点数不定，GAP 后的通道统计量不受顶点数影响 |
| **Backbone + Task Head** | **一套骨干服务多种综合算子** | 同一骨干接"选取""化简""典型化"三个不同的头，共享特征提取能力 |
| **预训练 + 微调** | **标注样本不足的破局手段** | 地图数据人工勾绘成本高，ImageNet / 遥感预训练权重迁移是首选路径 |
| **数据增强** | **季节 / 区域风格差异、符号化差异的模拟** | 颜色抖动模拟影像时相与配色差异；但**坡向、流向、注记方向不可乱转** |
| **Encoder–Decoder（自编码器）** | **曲线压缩、多边形化简** | 导师 2024《曲线数据压缩的自编码器》正是此结构；也是下一阶段 FCN / U-Net 的雏形 |
| **语义分割（U-Net，Day46+）** | **建筑物要素提取** | 像素级分类 → 得到要素分布图，再做矢量化与综合 |
| **Transformer（Day51+）** | **建筑多边形化简序列建模** | 把多边形顶点当序列，Attention 建模长程几何关系（导师 2026 论文） |

> **一句话**：接下来要从"**认得图里有什么**"（分类 / 分割）走向"**改变图该怎么画**"（综合 / 生成）。前者是判别式的，后者要引入生成式方法 —— 这正是导师要求补 GAN（Day61—Day66）的原因。
