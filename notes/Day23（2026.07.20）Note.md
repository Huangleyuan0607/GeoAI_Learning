### 第二阶段：理论学习（约 0.5 小时）

深入理解神经网络架构与激活函数的核心要素：

- **神经网络基本逻辑**：
  $$
  \text{Input} \longrightarrow \text{Linear (Weight & Bias)} \longrightarrow \text{Activation} \longrightarrow \text{Output}
  $$
  线性层执行多维特征组合，激活函数为模型引入非线性表达能力，使其能够拟合复杂的非线性空间决策边界。  

- **Sigmoid 激活函数**：
  $$
  \sigma(x) = \frac{1}{1 + e^{-x}}
  $$
  将实数范围的输入映射到 (0, 1) 区间，常用于二分类任务的概率输出。  

- **Tanh 激活函数**：
  $$
  \text{tanh}(x) = \frac{1 - e^{-2x}}{1 + e^{-2x}}
  $$
  将输入映射到 (-1, 1) 区间，输出均值为 0，相比 Sigmoid 在深层网络中收敛速度更快。

#### 实验任务

创建 `mlp_network.py` 文件，手工编写并运行以下代码，实现多层感知机（MLP）构建与激活函数曲线对比：  

```python
"""
程序名称：mlp_network.py
作者：黄乐源
日期：2026-07-20
描述：PyTorch 神经网络结构探究——搭建简单多层感知机 (MLP) 与 Sigmoid/Tanh 激活函数实战
"""

# 导包
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

print("================= 任务 1：搭建简单多层感知机 (MLP) =================")

class SimpleMLP(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(SimpleMLP, self).__init__()
        # 第一层：输入层 -> 隐藏层
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        # 激活函数
        self.sigmoid = nn.Sigmoid()
        # 第二层：隐藏层 -> 输出层
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        out = self.fc1(x)
        out = self.sigmoid(out)
        out = self.fc2(out)
        return out

# 实例化模型
input_size = 10
hidden_size = 20
output_size = 2

model = SimpleMLP(input_size, hidden_size, output_size)
print("自定义 MLP 模型结构:\n", model)

# 测试前向传播
dummy_input = torch.randn(5, input_size)  # Batch Size = 5
output = model(dummy_input)
print(f"\n输入张量形状: {dummy_input.shape}")
print(f"输出张量形状: {output.shape}")

print("\n================= 任务 2：激活函数特性计算与可视化 =================")

# 生成区间 [-6, 6] 的连续数据
x = torch.linspace(-6, 6, 200)

# 计算 Sigmoid 与 Tanh
sigmoid_layer = nn.Sigmoid()
tanh_layer = nn.Tanh()

y_sigmoid = sigmoid_layer(x)
y_tanh = tanh_layer(x)

# 绘制曲线
plt.figure(figsize=(10, 4))

plt.subplot(1, 2, 1)
plt.plot(x.numpy(), y_sigmoid.numpy(), color='blue', linewidth=2, label='Sigmoid')
plt.axhline(0, color='black', linestyle='--', alpha=0.5)
plt.axhline(1, color='black', linestyle='--', alpha=0.5)
plt.title("Sigmoid Activation Function")
plt.xlabel("Input x")
plt.ylabel("Output y")
plt.grid(True)
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(x.numpy(), y_tanh.numpy(), color='red', linewidth=2, label='Tanh')
plt.axhline(-1, color='black', linestyle='--', alpha=0.5)
plt.axhline(1, color='black', linestyle='--', alpha=0.5)
plt.title("Tanh Activation Function")
plt.xlabel("Input x")
plt.ylabel("Output y")
plt.grid(True)
plt.legend()

plt.tight_layout()
plt.show()

print("\n🏁 Day23 GeoAI 神经网络结构与 MLP 搭建学习完成！")
```

**Day03-06 至 Day03-07 神经网络结构与构建**：

**机器学习**：只要数学好，**公式等都能推导出来**；

**深度学习**：**解释性稍差**，例如：分层 -> 6层就是比5层好，至于为啥，我们可能不知道，是实验出来的（黑盒性）。

**人工神经网络**（**Artificial Neural Network**，简写为**ANN**）：也简称为**神经网络（NN）**，是一种模仿生物神经网络结构和功能的**计算模型**。人脑可以看做是一个生物神经网络，由众多的**神经元**连接而成。各个神经元传递复杂的电信号，**树突**接收到**输入信号**，然后对信号进行处理，通过**轴突输出信号**。

当电信号通过树突进入到细胞核时，会逐渐聚集电荷。达到一定的电位后，细胞就会被激活，通过轴突发出电信号。

神经网络是由多个神经元组成的，构建神经网络就是在构建神经元。以下是神经网络中神经元的构建说明：

![Day23_神经网络中神经元的构建说明](D:\CCNU\PreLearning_Plan\GeoAI-Learning\notes\Screenshot\Day23\Day23_神经网络中神经元的构建说明.png)

这个过程就像，**来源不同树突（树突都会有不同权重）**的信息，进行的**加权计算**，输入到细胞中做加和，再通过激活函数输出细胞值。

使用多个神经元来构建神经网络，**相邻层**之间的神经元**相互连接**，并给每一个连接分配一个强度（权重系数,w和b），而**同层**神经元之间**相互隔离**，如下图所示：

![Day23_神经网络基本结构与特征映射图](D:\CCNU\PreLearning_Plan\GeoAI-Learning\notes\Screenshot\Day23\Day23_神经网络基本结构与特征映射图.png)

每一个神经元工作时，前向传播会产生两个值，**内部状态值（加权求和值）**和**激活值**；反向传播时会产生**激活值梯度**和**内部状态值梯度**。

- **内部状态值**：神经元或隐藏单元的内部存储值，它反映了当前神经元接收到的输入、历史信息以及网络内部的权重计算结果。`z = W * x + b`，其中：**W为权重矩阵**，**x为输入值**，**b为偏置**。
- **激活值**：通过激活函数（如：Sigmoid、Tanh、ReLU、Softmax等）对内部状态值进行非线性变换后得到的结果。`a = f(z)`，其中：**f为激活函数**，**z为内部状态值**。

一句话概括神经网络及其构成：

神经网络是**由神经元构成（加权求和 + 激活函数）**的一种模仿生物网络结构和功能的**计算模型**，由**输入层、隐藏层和输出层**组成。

**Day03-08 激活函数介绍**：

**激活函数**：用于**对每层的输出数据进行变换**，进而为整个网络注入了**非线性因素**。此时，神经网络就可以拟合各种曲线。

- **没有引入非线性因素**的网络等价于使用一个**线性模型**（只有加权求和，没有激活函数）来拟合；
- 通过给网络输出增加激活函数，实现引入非线性因素，使得网络模型可以逼近任意函数，提升网络对复杂问题的拟合能力。

**Day03-09 至 Day03-10 Sigmoid 与 Tanh 激活函数**：

- **Sigmoid激活函数**

  - 公式：
    $$
    f(x) = \frac{1}{1 + e^{-x}}，x：加权求和；x越大，整体越大
    $$

  - 求导公式：
    $$
    f'(x) = \left(\frac{1}{1+e^{-x}}\right)' = \frac{1}{1+e^{-x}}\left(1 - \frac{1}{1+e^{-x}}\right) = f(x)(1 - f(x))
    $$
  
- 函数图像如下：
  
  ![Day23_Sigmoid激活函数图像](D:\CCNU\PreLearning_Plan\GeoAI-Learning\notes\Screenshot\Day23\Day23_Sigmoid激活函数图像.png)
  
  由图可知，**Sigmoid**激活函数在**[-6, 6]有效果**，**在[-3, 3]效果明显**；**导数结果：[0, 0.25]**。
  
- sigmoid函数可以将**任意的输入**映射到 **(0，1)**之间，当输入的值大致在**<-6**或者**>6**时，意味着输入任何值得到的激活值都是差不多的，这样会丢失部分的信息。比如：输入100和输出10000经过sigmoid的激活值几乎都是等于1的，但是输入的数据之间相差100倍的信息就丢失了。
  
- 对于sigmoid函数而言，输入值在**[-6，6]**之间输出值才会有**明显差异**，输入值在**[-3，3]**之间才会有**比较好的效果**。
  
- 通过上述导数图像，我们发现导数数值范围是**(0, 0.25)**，当输入<-6或者>6时，sigmoid激活函数图像的**导数接近为0**，此时**网络参数将更新极其缓慢**，**或者无法更新**。
  
- 一般来说，sigmoid网络在**5层之内**就会产生**梯度消失**现象。而且，该激活函数并不是以0为中心（大概以0.5为中心）的，所以在实践中这种激活函数使用的很少。sigmoid函数一般只用于**浅层神经网络**和**二分类的输出层**。题外话：**多分类的输出层**一般用**Softmax**，**中间的隐藏层**一般用**ReLU**（ReLU搞不定就用**LeakyReLU、PReLU、Tanh、Sigmoid**）。具体如下图所示：
  
  ![Day23_神经网络基本结构与特征映射图补充](D:\CCNU\PreLearning_Plan\GeoAI-Learning\notes\Screenshot\Day23\Day23_神经网络基本结构与特征映射图补充.png)
  
- Tanh激活函数

  - 公式：
    $$
    f(x) = \frac{1 - e^{-2x}}{1 + e^{-2x}}，x：加权求和，x越大，整体越接近于1；x越小，整体越接近于-1
    $$
  
- 求导公式：
    $$
    f'(x) = \left(\frac{1 - e^{-2x}}{1 + e^{-2x}}\right)' = 1 - f^2(x)
    $$
    
  - 函数图像、导数图像：

    ![Day23_Tanh激活函数图像](D:\CCNU\PreLearning_Plan\GeoAI-Learning\notes\Screenshot\Day23\Day23_Tanh激活函数图像.png)

    由图可知，**Tanh**激活函数在**[-3, 3]有效果**，在**[-1, 1]效果明显**；**导数结果：[0, 1]**。

  - 与Sigmoid激活函数相比，Tanh迭代次数更少（收敛速度越快，参数变化越快），因为Tanh的极值为1，而Sigmoid极值为0.25。

  - Tanh函数将**输入映射到(-1，1)之间**，图像**以0为中心**，在**0点对称**，当输入大概<-3或者>3时将被映射为-1或者1。其**导数值范围(0, 1)**，当输入的值大概<-3或者>3时，其导数近似0。

  - 与Sigmoid相比，它是**以0为中心**的，且梯度相对于sigmoid大，使得**其收敛速度要比Sigmoid快**，**减少迭代次数**。然而，从图中可以看出，Tanh两侧的导数也为0，同样会造成**梯度消失**（当输入的值大概<-3或者>3时）。

  - 若使用时可**在隐藏层使用tanh**函数，**在输出层使用sigmoid**函数。

  - Tanh函数主要应用于**隐藏层**，且适用于**浅层神经网络(不超过5层)**。

## 遇到的问题/注意事项

注意：神经网络中隐藏层的每层神经元数量的设置最好遵循**前层多，后层少（前多后少）**的法则，且**隐藏层至少需要设置两层**（一层**加权求和**，一层**激活函数**）。

注意：全神经网络连接接收的样本数据是二维的，数据在每一层之间需要以二维的形式传递。

注意：前层神经元的输出就是后一层神经元的输入（前层输出 = 后层输入）。
