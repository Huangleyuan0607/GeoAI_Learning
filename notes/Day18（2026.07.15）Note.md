### 第二阶段：理论学习（约 0.5 小时）
深入理解 Autograd 自动求导机制在神经网络训练与 GeoAI 模型中的意义：
* **张量与梯度追踪（Requires Grad）**：
  在 PyTorch 中，将张量的 `requires_grad` 设置为 `True` 时，系统会自动构建计算图，记录该张量上的所有数学运算。
* **反向传播与链式法则（Backward & Chain Rule）**：
  神经网络的前向传播计算 Loss，反向传播则利用微积分链式法则求出损失函数关于每个参数的偏导数（梯度）。
* **梯度清零（Gradient Accumulation/Zero_）**：
  PyTorch 默认会累加梯度（`.grad`），因此在每次迭代更新参数前，必须手动调用 `.grad.zero_()` 清空历史梯度。
* **计算图截断与梯度阻断（Detach / no_grad）**：
  在模型评估或推断阶段，使用 `torch.no_grad()` 或 `.detach()` 可以切断梯度计算图，从而节省显存并提高计算效率。

#### 实验任务

创建 `tensor_autograd_demo.py` 文件，手工编写并运行以下代码，实现 Tensor 梯度计算与 Autograd 自动求导：  

```python
# -*- coding: utf-8 -*-
"""
程序名称：tensor_autograd_demo.py
作者：黄乐源
日期：2026-07-15
描述：PyTorch Tensor 基础、Autograd 自动求导与计算图机制实战
"""

import torch

print("================= 任务 1：Tensor 自动求导基础 =================")

# 1. 创建标量变量 x 并开启梯度追踪
x = torch.arange(4.0, requires_grad=True)
print(f"初始张量 x: {x}")
print(f"x 的初始梯度: {x.grad}")

# 2. 前向计算 y = 2 * x^T * x (标量函数)
y = 2 * torch.dot(x, x)
print(f"前向计算结果 y: {y}")

# 3. 反向传播计算 dy/dx
y.backward()
print(f"y 关于 x 的梯度 dy/dx (应为 4*x): {x.grad}")

# 校验梯度计算结果: dy/dx = 4 * x
print(f"梯度校验逻辑判定: {torch.all(x.grad == 4 * x).item()}")


print("\n================= 任务 2：梯度清零与计算图重置 =================")

# 1. 在默认的梯度累加机制下再次求导 (不推荐)
# PyTorch 默认会累加梯度，因此在新计算前需清零
x.grad.zero_()  # 显式清空梯度
y = x.sum()
y.backward()
print(f"清零后计算 y = sum(x) 的梯度 dy/dx: {x.grad}")


print("\n================= 任务 3：非标量变量的反向传播 =================")

# 当 y 不是标量时，调用 backward() 需要传入与 y 同形状的 gradient 权重向量
x.grad.zero_()
y = x * x  # y 是一个向量 [0, 1, 4, 9]

# 对非标量 y 进行梯度计算 (等价于对 y 的各元素求和后再求导)
y.backward(torch.ones_like(y))
print(f"非标量 y = x*x 梯度 dy/dx (应为 2*x): {x.grad}")


print("\n================= 任务 4：梯度阻断 (Detach) 实验 =================")

x.grad.zero_()
y = x * x
u = y.detach()  # 将 u 从 y 的计算图中分离，视其为常数
z = u * x

z.sum().backward()
print(f"阻断后 z = u * x 关于 x 的梯度 (应为 u): {x.grad}")
print(f"验证 x.grad == u: {torch.all(x.grad == u).item()}")

# 依然可以对 y 本身进行反向传播
x.grad.zero_()
y.sum().backward()
print(f"直接对 y 求和求导结果: {x.grad}")

print("\n🏁 Day18 Tensor 与 Autograd 自动求导实战完成！")
```
