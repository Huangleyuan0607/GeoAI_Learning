### 第二阶段：理论学习（约 1.0 小时）

系统梳理深层网络的退化问题与残差连接原理：

- **核心知识点**：

  - **为什么需要 ResNet？**

    ```
    网络越来越深
        ↓
    梯度消失
        ↓
    训练困难
    ```

  - **残差结构**：

    ```
    x
    ↓
    Conv
    ↓
    Conv
    ↓
    +   ←── x（捷径分支 / Shortcut）
    ↓
    output
    ```

  - **三个核心概念**：

    | 概念 | 含义 |
    | ------------------------ | ------------------------------------------------------------ |
    | **Shortcut（捷径分支）** | 把输入 x 直接加到主分支的输出上，这条支路不含任何变换 |
    | **Residual Block（残差块）** | 由「主分支（若干卷积）+ 捷径分支 + 相加 + 激活」构成的基本单元 |
    | **Identity Mapping（恒等映射）** | 当输入输出**形状一致**时，捷径分支**不做任何变换**（零参数），直接把 x 传过去 |

  - **关键理解**：

    - 网络要学的不是完整映射 H(x)，而是**残差** F(x) = H(x) - x
    - 如果某几层是多余的，只要把 F(x) 学成 0（权重压到 0），该块就退化成**恒等映射**
      → **加深网络至少不会变差**，这是 ResNet 能堆到上百层的根本原因
    - 反向传播时梯度可以通过捷径分支**直接回传**，缓解梯度消失
    - **形状不一致时**（通道数变化 / 尺寸减半）需要用 **1×1 卷积（配 stride）** 把捷径分支调整到与主分支一致

#### 实验任务

创建 `ResNet_Block.py`，实现残差块与简化版 ResNet（结构参考 ResNet-18）：

```python
import torch
import torch.nn as nn


class Residual(nn.Module):
    """残差块：y = f(x) + x（形状不一致时用 1x1 卷积调整捷径分支）"""
    def __init__(self, in_channels, out_channels, use_1x1conv=False, stride=1):
        super(Residual, self).__init__()
        # 主分支：两个 3x3 卷积（padding=1 保持尺寸）
        self.conv1 = nn.Conv2d(in_channels, out_channels, kernel_size=3, padding=1, stride=stride)
        self.conv2 = nn.Conv2d(out_channels, out_channels, kernel_size=3, padding=1)
        # 捷径分支：需要调整形状时才用 1x1 卷积
        if use_1x1conv:
            self.conv3 = nn.Conv2d(in_channels, out_channels, kernel_size=1, stride=stride)
        else:
            self.conv3 = None
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.bn2 = nn.BatchNorm2d(out_channels)

    def forward(self, x):
        # 1.主分支：卷积 -> BN -> 激活 -> 卷积 -> BN
        y = torch.relu(self.bn1(self.conv1(x)))
        y = self.bn2(self.conv2(y))
        # 2.捷径分支：形状不一致时做 1x1 卷积变换
        if self.conv3:
            x = self.conv3(x)
        # 3.残差连接：主分支输出 + 捷径分支输入
        y = y + x
        # 4.相加后再激活
        return torch.relu(y)


def resnet_block(in_channels, out_channels, num_residuals, first_block=False):
    """一个 ResNet 阶段：由 num_residuals 个残差块组成"""
    blk = []
    for i in range(num_residuals):
        if i == 0 and not first_block:
            # 每个阶段的首块：尺寸减半 + 通道数翻倍（stride=2 + 1x1 卷积）
            blk.append(Residual(in_channels, out_channels, use_1x1conv=True, stride=2))
        else:
            blk.append(Residual(out_channels, out_channels))
    return nn.Sequential(*blk)


class ResNet(nn.Module):
    """简化版 ResNet（ResNet-18 结构）"""
    def __init__(self, num_classes=10):
        super(ResNet, self).__init__()
        # 1.输入干：大卷积核快速降采样
        self.stem = nn.Sequential(
            nn.Conv2d(1, 64, kernel_size=7, stride=2, padding=3),
            nn.BatchNorm2d(64),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=3, stride=2, padding=1),
        )
        # 2.四个阶段，每个阶段 2 个残差块
        self.stage1 = resnet_block(64, 64, 2, first_block=True)
        self.stage2 = resnet_block(64, 128, 2)
        self.stage3 = resnet_block(128, 256, 2)
        self.stage4 = resnet_block(256, 512, 2)
        # 3.全局平均池化 + 全连接输出
        self.pool = nn.AdaptiveAvgPool2d((1, 1))
        self.fc = nn.Linear(512, num_classes)

    def forward(self, x):
        x = self.stem(x)
        x = self.stage1(x)
        x = self.stage2(x)
        x = self.stage3(x)
        x = self.stage4(x)
        x = self.pool(x)                      # (N, 512, 3, 3) -> (N, 512, 1, 1)
        x = x.reshape(x.shape[0], -1)          # (N, 512, 1, 1) -> (N, 512)
        return self.fc(x)


def main():
    print("=" * 60)
    print("1. 残差块的两种情况对比")
    print("=" * 60)

    # 情况A：输入输出形状一致 -> Identity Mapping，捷径零参数
    x = torch.randn(2, 3, 6, 6)
    blk_a = Residual(3, 3, use_1x1conv=False)
    print(f"  情况A 形状相同: {tuple(x.shape)} -> {tuple(blk_a(x).shape)}  (捷径零参数)")

    # 情况B：通道数变化 + 尺寸减半 -> 需要 1x1 卷积
    x = torch.randn(2, 3, 6, 6)
    blk_b = Residual(3, 6, use_1x1conv=True, stride=2)
    print(f"  情况B 形状变化: {tuple(x.shape)} -> {tuple(blk_b(x).shape)}  (捷径含 1x1 卷积)")

    print()
    print("=" * 60)
    print("2. 完整 ResNet 各阶段特征图形状")
    print("=" * 60)
    net = ResNet(num_classes=10)
    t = torch.randn(1, 1, 96, 96)
    print(f"  输入           {tuple(t.shape)}")
    with torch.no_grad():
        t = net.stem(t);   print(f"  stem 之后      {tuple(t.shape)}")
        t = net.stage1(t); print(f"  stage1 之后    {tuple(t.shape)}")
        t = net.stage2(t); print(f"  stage2 之后    {tuple(t.shape)}")
        t = net.stage3(t); print(f"  stage3 之后    {tuple(t.shape)}")
        t = net.stage4(t); print(f"  stage4 之后    {tuple(t.shape)}")

    out = net(torch.randn(1, 1, 96, 96))
    print(f"  最终输出       {tuple(out.shape)}")

    # 参数量统计
    total = sum(p.numel() for p in net.parameters())
    fc_params = sum(p.numel() for p in net.fc.parameters())
    print()
    print(f"  总参数量: {total:,} ({total / 1e6:.2f} M)")
    print(f"  全连接层参数量: {fc_params:,} (占 {fc_params / total * 100:.2f}%)")


if __name__ == "__main__":
    main()
```

#### 维度推导验证

| 阶段 | 操作 | 输入 Shape | 输出 Shape | 计算依据 |
|---|---|---|---|---|
| 输入 | — | — | (N, 1, 96, 96) | 单通道灰度图 |
| **stem** | `Conv(7×7, s=2, p=3)` + BN + ReLU + `MaxPool(3, 2, 1)` | (N, 1, 96, 96) | (N, 64, 24, 24) | 卷积：(96+6-7)/2+1=48；池化：(48+2-3)/2+1=24$ |
| **stage1** | 2 × `Residual(64→64)` | (N, 64, 24, 24) | (N, 64, 24, 24) | 3×3 卷积 `padding=1`，尺寸不变 |
| **stage2** | 首块 `stride=2` + 1×1 卷积；2 × `Residual(64→128)` | (N, 64, 24, 24) | (N, 128, 12, 12) | 尺寸减半 24/2=12，通道翻倍 |
| **stage3** | 2 × `Residual(128→256)` | (N, 128, 12, 12) | (N, 256, 6, 6) | 12/2=6 |
| **stage4** | 2 × `Residual(256→512)` | (N, 256, 6, 6) | (N, 512, 3, 3) | 6/2=3 |
| 全局平均池化 | `AdaptiveAvgPool2d(1, 1)` | (N, 512, 3, 3) | (N, 512, 1, 1) | 每个通道内取平均，压成 1×1 |
| 展平 + FC | `reshape` + `Linear(512→10)` | (N, 512) | (N, 10) | 10 个类别 |

> **一句话规律**：**stage 首块**用 `stride=2` 让尺寸减半、通道翻倍（同时捷径分支必须配 1×1 卷积）；**stage 内其余块**尺寸与通道都不变（捷径分支为恒等映射）。

#### 参数量分析（重要观察）

| 项目 | 参数量 | 占比 |
|---|---|---|
| 全模型 | 11,178,378 | 100% |
| **全连接层 `fc`** | **5,130** | **0.05%** |

**与前几天学过的网络对比**：

| 网络 | 全连接层参数占比 |
|---|---|
| AlexNet（Day36） | **96.0%** |
| VGG16（Day37） | **89.4%** |
| **简化 ResNet（本日）** | **0.05%** |

**原因**：ResNet 用 **全局平均池化（GAP）** `AdaptiveAvgPool2d(1, 1)` 把 (N, 512, 3, 3) 直接压成 (N, 512, 1, 1)，通道数不变但空间维度归 1，于是全连接层只需 `Linear(512, 10)` 共 5,130 个参数。

> 对比 VGG16 的 `Linear(25088→4096)` 一层就 1.02 亿参数 —— **GAP 把全连接层的参数量几乎彻底消灭了**，这正是 Day36/Day37 里那个"89%~96% 参数堆在 FC 层"问题的最终解法。
>
> 顺带一个好处：GAP 让网络**不再受输入尺寸限制**（换成 224×224 也能跑通，自动池化成 512 维）。
