### 第二阶段：理论学习（约 1.0 小时）

系统梳理图像增强的手段与它在地理数据上的针对性作用：

- **核心知识点**：

  - **图像增强（数据增广）的四种基本手段**：

    | 手段 | 典型做法 | 改变了什么 | 保持不变的是 |
    | ---- | -------- | ---------- | ------------ |
    | **翻转** | 水平翻转 / 垂直翻转 | 目标的左右（上下）朝向 | 类别标签、目标本身的外观 |
    | **裁剪** | 随机裁剪后再缩放回原尺寸 | 目标的位置与占比、视野范围 | 类别标签（前提是没裁掉关键部分） |
    | **旋转** | 按任意角度旋转 | 目标的朝向 | 类别标签 |
    | **颜色变化** | 调整亮度、对比度、色彩、色调 | 像素的数值分布 | 类别标签、几何结构 |

  - **本质思想**：

    ```
    一张图 + 保持标签不变的合理变换
            ↓
    等价于"免费"得到一批新样本
            ↓
    模型见过更多变体 → 学到与位置/朝向/光照无关的本质特征
    ```

    > 数据增广并没有真的增加信息量，它是把"**人对数据不变性的先验知识**"（物体翻过来还是那个物体、天亮点还是那条路）注入到训练中，从而**抑制过拟合、提升泛化能力**。

  - **在地图 / 地理数据上的应用价值**：

    | 地理数据的现实问题 | 对应的增广手段 | 理由 |
    | ---------------- | -------------- | ---- |
    | **标注样本不足**（人工勾绘、外业采集成本高） | 全部四种手段 | 用最少的标注换取最多的有效训练变体 |
    | **不同季节、不同区域的地图风格差异** | 颜色变化（亮度 / 对比度 / 色调抖动） | 模拟植被季相、影像时相、区域配色差异 |
    | **采集条件与符号化差异** | 旋转、裁剪、翻转 | 模拟不同成像方位、不同图幅裁切、不同符号表达尺度 |

  - **两个必须谨慎的地方（地理数据的特殊性）**：

    - **方向是有语义的**：自然图像里"倒过来的猫还是猫"，但地图要素未必如此。坡度坡向、河流流向、指北针、注记文字方向一旦被翻转或旋转，**地理含义就变了**——这类数据不能无脑做翻转 / 旋转。
    - **坐标一致性**：做分割 / 检测任务时，几何类增广（翻转、裁剪、旋转）必须**同步作用于图像和标签**（mask、bbox），否则监督信号错位。颜色类增广只改图像，标签不动。

    > 承接 Day35：当时 CIFAR-10 优化版的遗留问题是**过拟合**（训练集准确率 0.93 / 测试集仅 0.79），笔记里明确写了"根本解法是数据增强，等 Day42 补齐"——今天补的就是这块。

- **有增广 vs 无增广的训练对比**：同样的网络结构与超参数，只在训练变换里加不加增广，对比两者的 test_acc，验证增广对泛化（train/test 差距）的改善。

#### 参考代码

创建 `image_augmentation.py`，用 `torchvision.transforms` 实现翻转、裁剪、旋转、颜色变化与归一化，并对比"有增广 / 无增广"的训练表现：

```python
# 导包
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, Subset
from torchvision.datasets import FashionMNIST
from torchvision import transforms


# 1.定义增广变换：训练用（带随机性）与测试用（只做确定性预处理）
def get_transforms():
    # 1.1训练阶段：随机翻转 + 随机裁剪缩放 + 随机旋转 + 颜色抖动，最后转张量并归一化
    train_transform = transforms.Compose([
        transforms.RandomHorizontalFlip(p = 0.5),                   # 随机水平翻转：以0.5概率左右翻一下
        transforms.RandomResizedCrop(size = 28, scale = (0.6, 1.0)),# 随机裁剪：面积比例在0.6~1.0之间，再缩放回28x28
        transforms.RandomRotation(degrees = 15),                    # 随机旋转：在±15度内取一个角度
        transforms.ColorJitter(brightness = 0.4, contrast = 0.4),   # 颜色变化：亮度与对比度各扰动±0.4
        transforms.ToTensor(),                                      # PIL图像 -> (C, H, W)浮点张量，并缩放到[0, 1]
        transforms.Normalize(mean = (0.2860,), std = (0.3530,))     # 归一化：FashionMNIST全局均值与标准差
    ])
    # 1.2测试阶段：不做任何随机变换，保证评估口径固定
    test_transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize(mean = (0.2860,), std = (0.3530,))
    ])
    return train_transform, test_transform


# 2.定义数据加载函数：augment开关控制训练集是否使用增广变换
def get_data_loaders(batch_size = 64, augment = True):
    train_transform, test_transform = get_transforms()
    # 数据已在notebooks/data目录下，download = False表示不再联网下载
    root = './notebooks/data'
    train_dataset = FashionMNIST(root = root, train = True, transform = train_transform if augment else test_transform, download = False)
    test_dataset = FashionMNIST(root = root, train = False, transform = test_transform, download = False)
    # 只取一部分数据保证运行速度：6k张训练 + 1k张测试
    train_dataset = Subset(train_dataset, range(6000))
    test_dataset = Subset(test_dataset, range(1000))
    train_loader = DataLoader(train_dataset, batch_size = batch_size, shuffle = True)
    test_loader = DataLoader(test_dataset, batch_size = batch_size, shuffle = False)
    return train_loader, test_loader


# 3.定义小型CNN：顺序为 Conv -> BN -> ReLU -> MaxPool（沿用Day41学到的BN放置方式）
class SmallCNN(nn.Module):
    def __init__(self, num_classes = 10):
        super(SmallCNN, self).__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size = 3, padding = 1), nn.BatchNorm2d(32), nn.ReLU(), nn.MaxPool2d(2, 2),   # 28 -> 14
            nn.Conv2d(32, 64, kernel_size = 3, padding = 1), nn.BatchNorm2d(64), nn.ReLU(), nn.MaxPool2d(2, 2),  # 14 -> 7
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),                       # (N, 64, 7, 7) -> (N, 3136)
            nn.Linear(64 * 7 * 7, 128), nn.ReLU(),
            nn.Dropout(0.5),                    # 增广与Dropout都是抑制过拟合的手段，这里叠加使用做对照
            nn.Linear(128, num_classes),
        )

    def forward(self, x):
        return self.classifier(self.features(x))


# 4.定义训练一个epoch与测试的函数
def train_one_epoch(model, train_loader, criterion, optimizer, device):
    model.train()       # 训练模式：BN用当前batch统计量，Dropout生效
    total_loss, total_num = 0.0, 0
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        y_pred = model(x)
        loss = criterion(y_pred, y)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * x.shape[0]
        total_num += x.shape[0]
    return total_loss / total_num


def evaluate(model, loader, device):
    model.eval()        # 测试模式：BN改用running统计量，Dropout关闭
    correct, total = 0, 0
    with torch.no_grad():
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            y_pred = model(x).argmax(dim = 1)
            correct += (y_pred == y).sum().item()
            total += y.shape[0]
    return correct / total


# 5.定义主函数
def main():
    # 1.设置设备
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    print("Training on", device)
    lr, epochs = 0.01, 5

    # 2.单张图的各变换效果：同一张原图分别做各种变换，看形状与数值的变化
    print()
    print("=" * 60)
    print("1.各种增广变换的效果（同一张图）")
    print("=" * 60)
    base_ds = FashionMNIST(root = './notebooks/data', train = True, transform = transforms.ToTensor(), download = False)
    img_tensor = base_ds[0][0]      # 取第一张图，形状(C, H, W)，标签是T-shirt(9)
    print(f"原图        shape = {tuple(img_tensor.shape)}  mean = {img_tensor.mean().item():.4f}  label = {base_ds[0][1]}")
    pil_img = transforms.ToPILImage()(img_tensor)       # 还原成PIL图像才能喂给几何/颜色类变换
    single_ops = {
        '随机水平翻转': transforms.RandomHorizontalFlip(p = 1.0),       # p = 1.0强制翻转，便于对比效果
        '随机裁剪缩放': transforms.RandomResizedCrop(28, scale = (0.6, 0.8)),
        '随机旋转30度': transforms.RandomRotation(30),
        '颜色抖动': transforms.ColorJitter(brightness = 0.6, contrast = 0.6),
    }
    for name, op in single_ops.items():
        out = transforms.ToTensor()(op(pil_img))
        print(f"{name:<8} shape = {tuple(out.shape)}  mean = {out.mean().item():.4f}")

    # 3.归一化的效果：验证Normalize确实把数据拉到了均值0、方差1附近
    print()
    print("=" * 60)
    print("2.归一化(Normalize)的效果")
    print("=" * 60)
    norm = transforms.Normalize(mean = (0.2860,), std = (0.3530,))
    n_img = norm(img_tensor)
    print(f"归一化前 mean = {img_tensor.mean().item():.4f}  std = {img_tensor.std().item():.4f}")
    print(f"归一化后 mean = {n_img.mean().item():.4f}  std = {n_img.std().item():.4f}")

    # 4.增广的随机性：同一个变换连续调用两次，结果应当不同（说明每个epoch看到的都是新样本）
    print()
    print("=" * 60)
    print("3.增广的随机性验证（同图两次变换是否一致）")
    print("=" * 60)
    flip = transforms.RandomHorizontalFlip(p = 0.5)
    rrc = transforms.RandomResizedCrop(28, scale = (0.6, 1.0))
    diff_flip = torch.equal(transforms.ToTensor()(flip(pil_img)), transforms.ToTensor()(flip(pil_img)))
    diff_crop = torch.equal(transforms.ToTensor()(rrc(pil_img)), transforms.ToTensor()(rrc(pil_img)))
    print(f"两次随机水平翻转结果相同？{diff_flip}")
    print(f"两次随机裁剪结果相同？{diff_crop}")

    # 5.训练对比：两个模型只差"训练集要不要做增广"这一个变量
    print()
    print("=" * 60)
    print(f"4.有增广 / 无增广训练对比（FashionMNIST 6000张训练 / 1000张测试，lr = {lr}，epochs = {epochs}）")
    print("=" * 60)
    criterion = nn.CrossEntropyLoss()
    results = {}
    for augment in (False, True):
        name = "有增广" if augment else "无增广"
        torch.manual_seed(42)       # 固定种子，保证两个模型初始权重一致
        train_loader, test_loader = get_data_loaders(64, augment = augment)
        model = SmallCNN().to(device)
        optimizer = optim.Adam(model.parameters(), lr = lr)
        history = []
        print(f"---------- {name} ----------")
        for epoch in range(1, epochs + 1):
            train_loss = train_one_epoch(model, train_loader, criterion, optimizer, device)
            train_acc = evaluate(model, train_loader, device)
            test_acc = evaluate(model, test_loader, device)
            history.append((train_loss, train_acc, test_acc))
            print(f"epoch {epoch} train_loss = {train_loss:.4f} train_acc = {train_acc:.4f} test_acc = {test_acc:.4f}")
        results[name] = history

    # 6.汇总对比：重点看train_acc与test_acc的差距（过拟合程度）
    print()
    print("=" * 60)
    print("5.结果汇总")
    print("=" * 60)
    print(f"{'epoch':<8}{'无增广 train':>13}{'无增广 test':>13}{'gap':>9}{'有增广 train':>13}{'有增广 test':>13}{'gap':>9}")
    for i in range(epochs):
        no_aug = results['无增广'][i]
        aug = results['有增广'][i]
        gap_no = no_aug[1] - no_aug[2]
        gap_aug = aug[1] - aug[2]
        print(f"{i + 1:<8}{no_aug[1]:>13.4f}{no_aug[2]:>13.4f}{gap_no:>9.4f}{aug[1]:>13.4f}{aug[2]:>13.4f}{gap_aug:>9.4f}")

    print()
    print("结论：增广会让训练集准确率略降（因为训练样本变难了），但测试集准确率上升、train/test差距收窄，说明增广确实提升了泛化能力。")


# 6.测试
if __name__ == "__main__":
    main()
```

#### 代码与输出说明

| 观察点 | 无增广 | 有增广 |
| ---- | ---- | ---- |
| 训练集准确率 | 一路走高（0.85 → 0.95） | 明显偏低（0.79 → 0.88），因为每轮喂进去的都是"变难过的新图" |

| train / test 差距 | 逐步拉开（过拟合征兆） | 始终很小（泛化更好） |
| 参数量 | 两者完全相同 | 增广不改变模型结构，只改变输入数据 |

> **一句话记住**：增广是**用数据的多样性换模型的泛化能力**——它不增加信息，而是把人知道的"哪些变换不改变类别"这件事教给网络。
