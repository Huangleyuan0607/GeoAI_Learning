### 第二阶段：理论学习（约 0.5 小时）

深入理解反向传播（Backpropagation）与自动求导逻辑：

- **自动微分与计算图**：PyTorch 在正向传播（Forward）时会隐式构建动态计算图。只有设置了 `requires_grad=True` 的张量才会记录梯度操作，计算图的终点通常是标量 Loss。

- **梯度计算与更新流程**：
  $$
  \text{Forward} \longrightarrow \text{Loss} \longrightarrow \text{Backward (loss.backward())} \longrightarrow \text{Gradient (w.grad)} \longrightarrow \text{Update (w = w - lr * w.grad)}
  $$
  

- **梯度累加与清零**：在默认情况下，PyTorch 的 `backward()` 会将计算出的梯度**累加**到 `.grad` 属性中（即 `w.grad += new_grad`）。因此在下一轮迭代求导前，必须手动调用 `w.grad.zero_()` 或使用优化器的 `optimizer.zero_grad()`。

- **梯度阻断 (Detach & no_grad)**：

  - `tensor.detach()`：生成一个新的 Tensor，共享底层内存数据，但从当前计算图中分离出来（`requires_grad=False`），常用于迁移学习中冻结 Backbone 参数。
  - `with torch.no_grad():`：在其包裹的代码块内部禁用所有梯度的计算与追踪，常用于模型推理（Inference）与参数手写更新阶段，可显著节省显存与计算资源。

#### 实验任务

创建 `autograd.py` 文件，手工编写并运行以下代码，实现张量拼接、自动求导、梯度清零及 `detach` 截断实验：

```python
"""
程序名称：autograd.py
作者：黄乐源
日期：2026-07-18
描述：PyTorch 张量拼接、自动求导 (Autograd) 机制、梯度更新与计算图截断实战
"""
import torch

print("================= 任务 1：张量拼接操作 (cat vs stack) =================")

# 模拟两期遥感单波段 Feature Map (H=4, W=4)
feat_t1 = torch.randn(4, 4)
feat_t2 = torch.randn(4, 4)

# 1. torch.cat 按照现有维度拼接 (通道扩展/特征融合)
cat_res = torch.cat([feat_t1, feat_t2], dim=0) # 变为 (8, 4)
print("torch.cat (dim=0) 拼接后形状:", cat_res.shape)

# 2. torch.stack 增加新维度拼接 (时间序列维度/Batch维度构建)
stack_res = torch.stack([feat_t1, feat_t2], dim=0) # 变为 (2, 4, 4)
print("torch.stack (dim=0) 堆叠后形状:", stack_res.shape)

print("\n================= 任务 2：自动求导 (Autograd) 基础流程 =================")

# 假设 w 为待优化参数 (如权重)，x 为输入特征
w = torch.tensor([2.0], requires_grad=True)
b = torch.tensor([1.0], requires_grad=True)
x = torch.tensor([3.0])
y_true = torch.tensor([10.0]) # 真实标签

# 1. 正向传播 (Forward)
y_pred = w * x + b
loss = (y_pred - y_true) ** 2 # MSE 损失

print(f"正向传播预测值 y_pred: {y_pred.item():.2f}, Loss: {loss.item():.2f}")

# 2. 反向传播 (Backward)
loss.backward()

# 3. 查看梯度
print("w 的梯度 (d_loss/d_w):", w.grad)
print("b 的梯度 (d_loss/d_b):", b.grad)

print("\n================= 任务 3：循环更新参数与梯度清零 (grad.zero_) =================")

# 重新初始化参数
w = torch.tensor([2.0], requires_grad=True)
learning_rate = 0.01

print("开始 3 轮循环参数更新模拟:")
for epoch in range(1, 4):
    # 正向传播
    y_pred = w * x
    loss = (y_pred - y_true) ** 2
    
    # 反向传播计算梯度
    loss.backward()
    
    # 模拟无梯度追踪环境下的参数更新
    with torch.no_grad():
        w -= learning_rate * w.grad
        
    print(f"Epoch {epoch} - Loss: {loss.item():.4f}, 当前 w 的梯度: {w.grad.item():.4f}, 更新后的 w: {w.item():.4f}")
    
    # 手动将梯度清零，防止下一轮梯度累加
    w.grad.zero_()

print("\n================= 任务 4：计算图截断 (detach 与 no_grad) =================")

x = torch.tensor([2.0], requires_grad=True)
y = x ** 2

# 使用 detach 截断梯度流
y_detached = y.detach()
z = y_detached * 3

print("y_detached 的 requires_grad 状态:", y_detached.requires_grad)
print("z 的 requires_grad 状态:", z.requires_grad)

# 验证 no_grad 上下文
with torch.no_grad():
    m = x * 5
print("no_grad 内创建张量的 requires_grad 状态:", m.requires_grad)

print("\n🏁 Day21 GeoAI PyTorch 自动求导与梯度更新实战完成！")
```
