"""

作者：黄乐源
日期：2026-07-23
描述：PyTorch 常见损失函数（CrossEntropyLoss, BCEWithLogitsLoss, MSELoss, L1Loss, SmoothL1Loss）使用规范与计算逻辑实战

# 导包
import torch
import torch.nn as nn

print("================= 任务 1：多分类交叉熵损失 (CrossEntropyLoss) =================")

# 模拟网络输出：3个样本，3个类别（未经 Softmax 的原始 Logits）
logits = torch.tensor([
    [2.0, 1.0, 0.1],   # 预测样本 0 最可能是类别 0
    [0.5, 3.0, 0.2],   # 预测样本 1 最可能是类别 1
    [0.1, 0.8, 2.5]    # 预测样本 2 最可能是类别 2
], dtype=torch.float32)

# 真实类别标签：维度为 (N,)，元素类型必须为 torch.int64 (Long)
targets_multiclass = torch.tensor([0, 1, 2], dtype=torch.long)

# 实例化损失函数
ce_loss_fn = nn.CrossEntropyLoss()

# 计算损失
loss_ce = ce_loss_fn(logits, targets_multiclass)

print("多分类 Logits:\n", logits)
print("真实标签 Index:\n", targets_multiclass)
print(f"nn.CrossEntropyLoss 计算结果: {loss_ce.item():.4f}")


print("\n================= 任务 2：二分类交叉熵损失 (BCEWithLogitsLoss) =================")

# 模拟二分类网络输出：4个样本（未经过 Sigmoid 的 Logits）
binary_logits = torch.tensor([2.5, -1.2, 0.3, -3.0], dtype=torch.float32)

# 真实标签：0 或 1，类型需与 logits 一致（FloatTensor）
binary_targets = torch.tensor([1.0, 0.0, 1.0, 0.0], dtype=torch.float32)

# 使用数值更稳定的 BCEWithLogitsLoss
bce_logits_loss_fn = nn.BCEWithLogitsLoss()

loss_bce = bce_logits_loss_fn(binary_logits, binary_targets)

print("二分类 Logits:\n", binary_logits)
print("真实标签 Float:\n", binary_targets)
print(f"nn.BCEWithLogitsLoss 计算结果: {loss_bce.item():.4f}")


print("\n================= 任务 3：回归损失函数对比 (MSE, MAE, Smooth L1) =================")

# 模拟回归任务预测值与真实值（例如地表温度预测，单位：摄氏度）
pred_regression = torch.tensor([23.5, 18.0, 30.2, 15.0], dtype=torch.float32)
target_regression = torch.tensor([23.0, 20.0, 25.0, 15.2], dtype=torch.float32)  # 注意：第3个样本差距较大(5.2)，属于离群点

# 1. 均方误差损失 MSELoss
mse_fn = nn.MSELoss()
loss_mse = mse_fn(pred_regression, target_regression)

# 2. 平均绝对误差损失 L1Loss (MAE)
l1_fn = nn.L1Loss()
loss_l1 = l1_fn(pred_regression, target_regression)

# 3. 平滑 L1 损失 SmoothL1Loss
smooth_l1_fn = nn.SmoothL1Loss(beta=1.0)
loss_smooth_l1 = smooth_l1_fn(pred_regression, target_regression)

print("预测值:\n", pred_regression)
print("真实值:\n", target_regression)
print("-" * 40)
print(f"1. MSELoss (均方误差): {loss_mse.item():.4f}")
print(f"2. L1Loss (MAE):       {loss_l1.item():.4f}")
print(f"3. SmoothL1Loss:       {loss_smooth_l1.item():.4f}")

**Day04-07 多分类交叉熵损失介绍 至 Day04-08 二分类交叉熵损失介绍** ：

- 损失函数：在深度学习中，损失函数是用来**衡量模型参数的质量**的函数，衡量的方式是**比较网络输出和真实输出的差异**。损失函数在不同的文献中名称是不一样的，主要有以下几种命名方式：损失函数（loss function）；代价函数（cost function）；目标函数（objective function）；误差函数（error function）。
  - 多分类任务损失函数：在多分类任务通常使用softmax将logits转换为概率的形式，所以多分类的交叉熵损失也叫做**softmax损失**，它的计算方法是：
    $$
    \mathcal{L}
    =
    -\sum_{i=1}^{n}
    y_i \log\left(S\left(f_{\theta}(x_i)\right)\right)
    $$
    其中，

    - 1、y是样本x属于某一个类别的**真实概率**（取值为0或1）；

    - 2、而f(x)是样本属于某一类别的预测分数，可以理解成**加权求和**的结果；

    - 3、S是**softmax激活函数**，将属于某一类别的预测分数（即加权求和结果）转换成概率；

    - 4、L用来衡量真实值y和预测值f(x)之间**差异性的损失结果**。

    因为多分类交叉熵损失的公式中包含softmax()，所以在输出层，多分类问题中，在使用多分类交叉熵的情况下，输出层可以不用softmax()激活函数。

    **多分类交叉熵损失 = softmax() + 损失计算**。

    从概率角度理解，我们的目的是**最小化正确类别所对应的预测概率的对数的负值**（即让**损失值最小**）。

  - 二分类交叉熵损失函数：在处理二分类任务时，我们不再使用softmax激活函数，而是**使用sigmoid激活函数**，那损失函数也相应的进行调整，使用二分类的交叉熵损失函数，它的计算方法是：
    $$
    L = -y\log\hat{y} - (1-y)\log(1-\hat{y})
    $$
    其中，

    - 1、y是样本x属于某一个类别的**真实概率**（取值为0或1）；

    - 2、而y^是样本属于某一类别的预测概率，可以理解成**加权求和**的结果；

    - 3、L用来衡量真实值y和预测值y^之间**差异性的损失结果**。

**Day04-09 至 Day04-11 回归损失函数 (MAE, MSE, Smooth L1)**：

- 回归任务损失函数分类：

  - MAE(Mean Absolute Error)损失函数：Mean Absolute Loss(MAE)也被称为L1 Loss，是以**绝对误差**作为距离。损失函数公式：
    $$
    \mathcal{L}
    =
    \frac{1}{n}
    \sum_{i=1}^{n}
    \left|y_i - f_{\theta}(x_i)\right|
    $$
    

    特点是：

    - 1、由于L1 loss具有稀疏性，为了惩罚较大的值，因此常常将其作为**正则项**添加到其他loss中作为约束；
    - 2、L1 loss的最大问题是**梯度在零点不平滑**（在0点不可导），导致会跳过极小值。

  - MSE(Mean Squared Error)损失函数：Mean Squared Loss/ Quadratic Loss (MSE loss)，也被称为L2 loss，或欧氏距离，它以**误差的平方和的均值**作为距离。损失函数公式：
    $$
    \mathcal{L} = \frac{1}{n} \sum_{i=1}^{n} (y_i - f_{\theta}(x_i))^2
    $$
    特点是：

    - 1、L2 loss也常常作为**正则项**（充当惩罚系数，解决其他模型中的过拟合现象）；
    - 2、当预测值与目标值**相差很大**时，**梯度容易爆炸**。

    曲线如下图所示：

  - Smooth L1损失函数：Smooth L1说的是光滑之后的L1。损失函数公式：
    $$
    \text{smooth}_{L_1}(x) = \begin{cases} 0.5x^2 & \text{if } |x| < 1 \\ |x| - 0.5 & \text{otherwise} \end{cases}

    其中：`x = f(x) - y`为**真实值和预测值的差值**。

## 遇到的问题/注意事项

- MAE与MSE比较：
  - MAE -> L1 Loss，误差**绝对值之和**的**平均数**。     L1：权重可为0
  - MSE -> MSELoss，误差**平方和**的**平均数**。          L2：权重趋近于0

# Loss函数总结.md

本文档梳理了深度学习中常见损失函数（Loss Functions）的数学公式、遥感/GeoAI 典型应用场景以及 PyTorch 中的 API 使用规范。

## 1. 多分类交叉熵损失 (CrossEntropyLoss)

### 1.1 数学公式

对于单样本，类别数为 C，网络输出原始 logits 为 x = [x₁, x₂, ... , Xc]，真实类别标签为 y ∈ {0, 1, ... , c - 1}：
$$
L = -\log \left( \frac{\exp(x_{y})}{\sum_{j=1}^{C} \exp(x_j)} \right) = -x_y + \log \left( \sum_{j=1}^{C} \exp(x_j) \right)
$$
对于 Batch Size 为 N 的样本集合：
$$
\text{Loss} = \frac{1}{N} \sum_{i=1}^{N} \left( -x_{i, y_i} + \log \sum_{j=1}^{C} \exp(x_{i, j}) \right)
$$

> **内部机制**：`nn.CrossEntropyLoss` 在内部集成了 Softmax 计算与 NLLLoss（Negative Log Likelihood Loss）。

### 1.2 使用场景与特点

- **典型场景**：单标签多分类任务（如土地覆盖类型分类：耕地、水体、林地、建筑用地等；遥感语义分割中的多类别像素标记）。
- **核心特点**：对正确类别的概率预测值施加负对数惩罚，预测越不准确，Loss 越大。

### 1.3 PyTorch API 规范

```python
import torch
import torch.nn as nn

# 实例化
criterion = nn.CrossEntropyLoss(weight=None, reduction='mean', ignore_index=-100)

# 输入要求：
# logits: Shape 为 (N, C) 或 (N, C, H, W) [语义分割]，dtype 为 torch.float32（未经 Softmax 的原始输出）
# target: Shape 为 (N,) 或 (N, H, W) [语义分割]，dtype 为 torch.int64 (torch.long)，数值范围 [0, C-1]

logits = torch.randn(4, 5, requires_grad=True)  # 4 个样本，5 个类别
target = torch.tensor([0, 2, 4, 1], dtype=torch.long)

loss = criterion(logits, target)
```

**注意事项**：网络最后一层**切勿手动添加 Softmax**，否则会导致重复求概率并破坏数值梯度的稳定性。

## 2. 二分类交叉熵损失 (BCEWithLogitsLoss / BCELoss)

### 2.1 数学公式

对于二分类任务（标签 y ∈ {0， 1}），网络未经过 Sigmoid 的输出 logits 为 x：

- 经过 Sigmoid 变换：

$$
\sigma(x) = \frac{1}{1 + e^{-x}}
$$

- 单个样本的二分类交叉熵 Loss：

$$
l_n = - \left[ y_n \cdot \log \sigma(x_n) + (1 - y_n) \cdot \log(1 - \sigma(x_n)) \right]
$$

- 展开并优化 Log-Sum-Exp 形式可防溢出：

$$
l_n = x_n - x_n \cdot y_n + \log(1 + e^{-x_n})
$$

### 2.2 使用场景与特点

- **典型场景**：
  - 单目标二值提取（如遥感水体提取、建筑物二值提取、冰川边界识别）。
  - 多标签分类任务（Multi-label Classification，每个类别互相独立且输出独立概率）。
- **核心特点**：`BCEWithLogitsLoss` 比 `Sigmoid + BCELoss` 具有更高的数值稳定性，可避免上溢或下溢（Overflow/Underflow）。

### 2.3 PyTorch API 规范

```python
# 实例化
criterion = nn.BCEWithLogitsLoss(pos_weight=None, reduction='mean')

# 输入要求：
# logits: Shape 为 (N, *)，dtype 为 torch.float32（未经 Sigmoid 激活）
# target: Shape 与 logits 完全一致，dtype 必须为 torch.float32，取值为 0.0 或 1.0

logits = torch.randn(4, 1, requires_grad=True)
target = torch.tensor([[1.0], [0.0], [1.0], [0.0]], dtype=torch.float32)

loss = criterion(logits, target)
```

## 3. 均方误差损失 (MSELoss / L2 Loss)

### 3.1 数学公式

假设预测值为xᵢ，真实连续值为yᵢ，Batch 内包含 N 个元素：
$$
\text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (x_i - y_i)^2
$$

### 3.2 使用场景与特点

- **典型场景**：连续变量回归任务（如地表温度 LST 反演、植被覆盖度 FVC 估算、生物量预测、遥感图像超分辨率重构）。
- **核心特点**：
  - 处处可导，具有凸优化特性，收敛速度较快。
  - 由于存在平方项，对误差较大的离群点（Outliers）非常敏感，离群点容易主导梯度更新方向。

### 3.3 PyTorch API 规范

```python
# 实例化
criterion = nn.MSELoss(reduction='mean')

# 输入要求：
# pred: Shape 为 (N, *)，dtype 为 torch.float32
# target: Shape 与 pred 完全一致，dtype 为 torch.float32

pred = torch.tensor([23.5, 18.0, 30.2], dtype=torch.float32, requires_grad=True)
target = torch.tensor([23.0, 20.0, 25.0], dtype=torch.float32)

loss = criterion(pred, target)
```

## 4. 平均绝对误差损失 (L1Loss / MAE Loss)

### 4.1 数学公式

假设预测值为xᵢ，真实连续值为yᵢ：
$$
\text{MAE} = \frac{1}{N} \sum_{i=1}^{N} \vert{}x_i - y_i\vert{}
$$

### 4.2 使用场景与特点

- **典型场景**：存在较多云遮挡、遥感噪声或离群异常值的定量反演回归任务。
- **核心特点**：
  - 梯度幅值恒定为±1，抗离群点干扰能力强（鲁棒性高）。
  - 在零点处不可导；在接近零点（小误差）时梯度依然为常数，可能导致预测值在极小值附近发生震荡。

### 4.3 PyTorch API 规范

```python
# 实例化
criterion = nn.L1Loss(reduction='mean')

# 输入要求：
# pred: Shape 为 (N, *)，dtype 为 torch.float32
# target: Shape 与 pred 完全一致，dtype 为 torch.float32

pred = torch.tensor([23.5, 18.0, 30.2], dtype=torch.float32, requires_grad=True)
target = torch.tensor([23.0, 20.0, 25.0], dtype=torch.float32)

loss = criterion(pred, target)
```

## 5. 平滑 L1 损失 (SmoothL1Loss / Huber Loss)

### 5.1 数学公式

对于单个元素的误差 eᵢ = xᵢ - yᵢ，，阈值参数为 β（默认β = 1.0）：
$$
\text{SmoothL1}(e_i) = \begin{cases} 0.5 \frac{e_i^2}{\beta}, & \text{if } \vert{}e_i\vert{} < \beta \\ \vert{}e_i\vert{} - 0.5 \beta, & \text{otherwise} \end{cases}
$$

$$
\text{Loss} = \frac{1}{N} \sum_{i=1}^{N} \text{SmoothL1}(x_i - y_i)
$$

### 5.2 使用场景与特点

- **典型场景**：
  - 目标检测中的 Bounding Box 边界框坐标回归（如 Faster R-CNN, YOLO 损失函数组合）。
  - 既需要高精度平滑收敛、又需要抗噪声干扰的遥感反演任务。
- **核心特点**：
  - 当 |eᵢ| < β 时，表现为 L2 损失，近零点处平滑可导，易于收敛。
  - 当 |eᵢ| ≥ β 时，转换为 L1 损失，限制最大梯度幅值，防止梯度爆炸。

### 5.3 PyTorch API 规范

```python
# 实例化
criterion = nn.SmoothL1Loss(beta=1.0, reduction='mean')

# 输入要求：
# pred: Shape 为 (N, *)，dtype 为 torch.float32
# target: Shape 与 pred 完全一致，dtype 为 torch.float32

pred = torch.tensor([23.5, 18.0, 30.2], dtype=torch.float32, requires_grad=True)
target = torch.tensor([23.0, 20.0, 25.0], dtype=torch.float32)

loss = criterion(pred, target)
```

## 6. 常见损失函数特性速查表

| **Loss 函数**      | **对应 API**           | **任务类型**    | **Target 类型 / Shape 要求** | **核心特性**                              |
| ------------------ | ---------------------- | --------------- | ---------------------------- | ----------------------------------------- |
| **交叉熵损失**     | `nn.CrossEntropyLoss`  | 多分类          | `LongTensor` / (N, )         | 内置 Softmax，无需在网络末端加激活函数    |
| **二分类交叉熵**   | `nn.BCEWithLogitsLoss` | 二分类 / 多标签 | `FloatTensor` / (N, *)       | 内置 Sigmoid，数值稳定性更高              |
| **均方误差 (MSE)** | `nn.MSELoss`           | 回归            | `FloatTensor` / (N, *)       | 对大误差惩罚重，易受异常离群点影响        |
| **绝对误差 (MAE)** | `nn.L1Loss`            | 回归            | `FloatTensor` / (N, *)       | 鲁棒性强，但极小误差附近易发生震荡        |
| **平滑 L1 损失**   | `nn.SmoothL1Loss`      | 回归 / 目标检测 | `FloatTensor` / (N, *)       | 融合 MSE 与 L1 优势，平滑收敛且防梯度爆炸 |
