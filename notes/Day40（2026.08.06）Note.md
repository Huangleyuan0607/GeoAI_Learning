### 第二阶段：理论学习（约 1.0 小时）

系统梳理两个经典网络的结构创新：

- **核心知识点**：

  - **NiN 的核心思想**：

    ```
    MLP卷积层
    +
    CNN
    ```

    **NiN 的两个贡献**：

    | 贡献 | 说明 |
    | ------------------ | ------------------------------------------------------------ |
    | **1×1 卷积（MLP 卷积层）** | 在**通道维度**上做全连接 + 非线性激活，增强表达能力（不改变空间尺寸） |
    | **全局平均池化（GAP）** | 把每个通道的特征图直接取平均，**替代全连接层**降低参数量 |

    > ⚠️ **重要联系**：你在 Day38 / Day39 学到的 **GAP（全局平均池化）最早就是 NiN（2013）提出的**，并不是 ResNet 的发明。ResNet 只是沿用了它。

  - **GoogLeNet 的核心**：

    - **Inception 模块**：并行使用多种尺寸的卷积核，提取**多尺度特征**
    - **多尺度特征**：同一层同时看 1×1、3×3、5×5 的感受野，再在通道维拼接

  - **Inception 模块的四条支路**：

    | 线路 | 结构 | 作用 |
    | ---- | --------------------- | -------------------------- |
    | 线路1 | **1×1** 卷积 | 提取点状特征，同时做通道变换 |
    | 线路2 | **1×1 → 3×3** 卷积 | 用 1×1 先降维，再用 3×3 提特征 |
    | 线路3 | **1×1 → 5×5** 卷积 | 用 1×1 先降维，再用 5×5 提特征 |
    | 线路4 | **3×3 最大池化 → 1×1** | 池化提特征后调整通道数 |

    四条支路**输出尺寸一致、通道数不同**，最后在**通道维 `torch.cat`** 拼接。

    > **为什么每条支路前面都加 1×1 卷积？** 因为 3×3 / 5×5 卷积如果在原始通道数上直接做，计算量会爆炸。**1×1 卷积先降维**，是 Inception 能控制计算量的关键。

  - **多尺度特征与多尺度地图表达的对应**：

    为什么需要多尺度（以地图为例）：

    ```
    建筑物
    道路
    河流

    尺寸不同，且随比例尺变化取舍规则不同

    大比例尺：要素详细表达
    小比例尺：只保留主要要素，并进行化简、合并
    ```

    | CNN 中的多尺度 | 地图中的多尺度 |
    | -------------------------------- | ---------------------------- |
    | Inception 用 1×1 / 3×3 / 5×5 并行 | 地图用不同比例尺并行表达要素 |
    | 感受野不同 → 捕捉不同尺度的目标 | 比例尺不同 → 表达不同层级的要素 |
    | 通道维拼接融合多尺度信息 | 多尺度级联（尺度变换）表达 |

#### 实验任务

创建 `GoogLeNet.py`，实现 Inception 模块与简化版 GoogLeNet：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class Inception(nn.Module):
    """Inception 模块：四条并行支路，输出在通道维拼接"""
    def __init__(self, in_channels, c1, c2, c3, c4):
        super(Inception, self).__init__()
        # 线路1：单 1x1 卷积
        self.p1_1 = nn.Conv2d(in_channels, c1, kernel_size=1)
        # 线路2：1x1 降维后接 3x3 卷积
        self.p2_1 = nn.Conv2d(in_channels, c2[0], kernel_size=1)
        self.p2_2 = nn.Conv2d(c2[0], c2[1], kernel_size=3, padding=1)
        # 线路3：1x1 降维后接 5x5 卷积
        self.p3_1 = nn.Conv2d(in_channels, c3[0], kernel_size=1)
        self.p3_2 = nn.Conv2d(c3[0], c3[1], kernel_size=5, padding=2)
        # 线路4：3x3 最大池化后接 1x1 卷积
        self.p4_1 = nn.MaxPool2d(kernel_size=3, stride=1, padding=1)
        self.p4_2 = nn.Conv2d(in_channels, c4, kernel_size=1)

    def forward(self, x):
        p1 = F.relu(self.p1_1(x))
        p2 = F.relu(self.p2_2(F.relu(self.p2_1(x))))
        p3 = F.relu(self.p3_2(F.relu(self.p3_1(x))))
        p4 = F.relu(self.p4_2(self.p4_1(x)))
        # 四条支路在通道维度拼接
        return torch.cat((p1, p2, p3, p4), dim=1)


def main():
    # 1.搭建 GoogLeNet 的五个模块
    b1 = nn.Sequential(nn.Conv2d(1, 64, kernel_size=7, stride=2, padding=3), nn.ReLU(),
                       nn.MaxPool2d(kernel_size=3, stride=2, padding=1))
    b2 = nn.Sequential(nn.Conv2d(64, 64, kernel_size=1), nn.ReLU(),
                       nn.Conv2d(64, 192, kernel_size=3, padding=1), nn.ReLU(),
                       nn.MaxPool2d(kernel_size=3, stride=2, padding=1))
    b3 = nn.Sequential(Inception(192, 64, (96, 128), (16, 32), 32),
                       Inception(256, 128, (128, 192), (32, 96), 64),
                       nn.MaxPool2d(kernel_size=3, stride=2, padding=1))
    b4 = nn.Sequential(Inception(480, 192, (96, 208), (16, 48), 64),
                       Inception(512, 160, (112, 224), (24, 64), 64),
                       Inception(512, 128, (128, 256), (24, 64), 64),
                       Inception(512, 112, (144, 288), (32, 64), 64),
                       Inception(528, 256, (160, 320), (32, 128), 128),
                       nn.MaxPool2d(kernel_size=3, stride=2, padding=1))
    b5 = nn.Sequential(Inception(832, 256, (160, 320), (32, 128), 128),
                       Inception(832, 384, (192, 384), (48, 128), 128),
                       nn.AdaptiveAvgPool2d((1, 1)), nn.Flatten())

    net = nn.Sequential(b1, b2, b3, b4, b5, nn.Linear(1024, 10))

    # 2.逐模块输出形状
    print("=" * 60)
    print("GoogLeNet 各模块输出形状：")
    print("=" * 60)
    x = torch.randn(1, 1, 96, 96)
    print(f"  输入      {tuple(x.shape)}")
    net.eval()
    with torch.no_grad():
        for name, blk in zip(["b1", "b2", "b3", "b4", "b5"], list(net)[:5]):
            x = blk(x)
            print(f"  {name:<8}  {tuple(x.shape)}")

    out = net(torch.randn(1, 1, 96, 96))
    print(f"  最终输出  {tuple(out.shape)}")

    # 3.拆解单个 Inception 模块的四条支路
    print()
    print("=" * 60)
    print("单个 Inception 模块的四条支路：")
    print("=" * 60)
    inc = Inception(192, 64, (96, 128), (16, 32), 32)
    t = torch.randn(1, 192, 24, 24)
    with torch.no_grad():
        p1 = F.relu(inc.p1_1(t))
        p2 = F.relu(inc.p2_2(F.relu(inc.p2_1(t))))
        p3 = F.relu(inc.p3_2(F.relu(inc.p3_1(t))))
        p4 = F.relu(inc.p4_2(inc.p4_1(t)))
        cat = torch.cat((p1, p2, p3, p4), dim=1)
    print(f"  输入                    {tuple(t.shape)}")
    print(f"  线路1 1x1卷积           {tuple(p1.shape)}   (64 通道)")
    print(f"  线路2 1x1->3x3          {tuple(p2.shape)}  (128 通道)")
    print(f"  线路3 1x1->5x5          {tuple(p3.shape)}   (32 通道)")
    print(f"  线路4 3x3池化->1x1      {tuple(p4.shape)}   (32 通道)")
    print(f"  通道拼接后              {tuple(cat.shape)}  (64+128+32+32=256)")

    # 4.参数量统计
    total = sum(p.numel() for p in net.parameters())
    fc_params = sum(p.numel() for p in net[-1].parameters())
    print()
    print(f"总参数量: {total:,} ({total / 1e6:.2f} M)")
    print(f"全连接层参数量: {fc_params:,} (占 {fc_params / total * 100:.2f}%)")


if __name__ == "__main__":
    main()
```

#### 通道数推导验证

| 模块 | 操作 | 输入 Shape | 输出 Shape | 通道数计算 |
|---|---|---|---|---|
| 输入 | — | — | $(N, 1, 96, 96)$ | 单通道灰度图 |
| **b1** | `Conv(7×7, s=2, p=3)` + ReLU + `MaxPool(3, 2, 1)` | $(N, 1, 96, 96)$ | $(N, 64, 24, 24)$ | 卷积：$(96+6-7)/2+1=48$；池化：$(48+2-3)/2+1=24$ |
| **b2** | `Conv(1×1)` + `Conv(3×3, p=1)` + `MaxPool(3, 2, 1)` | $(N, 64, 24, 24)$ | $(N, 192, 12, 12)$ | 通道 64 → 192；$24/2 = 12$ |
| **b3** | Inception(192→256) + Inception(256→480) + `MaxPool` | $(N, 192, 12, 12)$ | $(N, 480, 6, 6)$ | $64+128+32+32=256$；$128+192+96+64=480$ |
| **b4** | 5 × Inception + `MaxPool` | $(N, 480, 6, 6)$ | $(N, 832, 3, 3)$ | 依次 512 → 512 → 512 → 528 → **832** |
| **b5** | Inception(832→832) + Inception(832→1024) + **GAP** + `Flatten` | $(N, 832, 3, 3)$ | $(N, 1024)$ | $384+384+128+128=1024$ |
| 输出层 | `Linear(1024→10)` | $(N, 1024)$ | $(N, 10)$ | 10 个类别 |

> **通道数计算规律**：每个 Inception 的输出通道 = **四条支路通道数之和**（`c1 + c2[1] + c3[1] + c4`）。所以下一层的输入通道数必须等于上一层的输出通道数，各级配置就是这么串起来的。

#### 参数量分析（延续四天的观察）

| 网络 | 参数量 | 全连接层占比 |
|---|---|---|
| AlexNet（Day36） | 61.1 M | **96.0%** |
| VGG16（Day37） | 138.4 M | **89.4%** |
| 简化 ResNet（Day38） | 11.18 M | **0.05%** |
| ResNet50（Day39） | 25.6 M | **8.0%** |
| **GoogLeNet（本日）** | **5.98 M** | **0.17%** |

**两个关键观察**：

1. **GoogLeNet 参数只有 AlexNet 的 1/10，却比它更深（22 层）** —— 靠的就是 Inception 里的 **1×1 卷积降维**，把大卷积核的计算量压下来。
2. **全连接层只占 0.17%** —— 因为 GoogLeNet 也用 **GAP** 替代了巨型全连接层（沿用了 NiN 的设计）。而 **GAP 正是本日 NiN 那一讲的贡献**。
