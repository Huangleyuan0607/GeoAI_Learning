### 第二阶段：理论学习（约 1.0 小时）

深入理解模型正则化技巧、学习率衰减及批归一化的底层机制：  

- **过拟合与欠拟合机制**：
  - **欠拟合**：模型表达能力不足（网络过浅或训练不充分），训练集与测试集 Loss 均较高。
  - **过拟合**：模型过于复杂或样本不足，过分拟合训练集中噪声，训练集 Loss 极低但测试集 Loss 升高。遥感数据由于地物复杂且高质量标注样本受限，极易产生过拟合。  
- **学习率衰减（Learning Rate Decay）**：
  
  - **StepLR**：
    $$
    lr = lr_{0} \cdot \gamma^{\lfloor \frac{epoch}{step\_size} \rfloor}
    $$
    ，每隔固定轮次将学习率乘以衰减系数。
  
  - **MultiStepLR**：在指定的 epoch 列表达到时触发衰减。
  
  - **ExponentialLR**：
    $$
    lr = lr_{0} \cdot \gamma^{epoch}
    $$
    ，每轮按指数平滑衰减。
- **Dropout（随机失活）**：
  
  - **训练阶段**：以概率 p 随机将部分神经元输出置 0，并对剩余激活值乘以 1 / (1 - p)（Inverted Dropout）以保持期望数值一致。
  - **测试阶段**：全连接网络完全保留所有神经元，不需要做额外缩放，直接前向传播。
- **Batch Normalization（批归一化）**：
  
  - **计算流程**：对于批次数据 
    $$
    B = \{x_{1..m}\}:
    $$
    
    1. 均值：
       $$
       \mu_B = \frac{1}{m}\sum_{i=1}^m x_i
       $$
       
    2. 方差：
       $$
       \sigma_B^2 = \frac{1}{m}\sum_{i=1}^m (x_i - \mu_B)^2
       $$
       
    3. 归一化：
       $$
       $\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$
       $$
       
    4. 缩放与平移（重构）：
       $$
       y_i = \gamma \hat{x}_i + \beta
       $$
        （其中 γ, β 为可学习参数）。
- **优化技巧在 GeoAI 遥感任务中的选择逻辑**：

| **优化技巧**            | **核心作用**                                   | **局限性/注意事项**                                 | **GeoAI 典型适用场景**                      |
| ----------------------- | ---------------------------------------------- | --------------------------------------------------- | ------------------------------------------- |
| **Learning Rate Decay** | 后期跳出局部震荡，精准落入全局极小值点         | 需合理设置衰减步长与系数，避免过早停止学习          | 遥感 Backbone 微调与复杂 U-Net 语义分割训练 |
| **Dropout**             | 抑制参数共适应，增强泛化能力，防止过拟合       | 通常应用于全连接层（FC），在 CNN 卷积层效果相对有限 | 大规模遥感特征向量分类、高维表格数据预测    |
| **BatchNorm**           | 加速深层网络收敛，稳定梯度传播，允许更高学习率 | 依赖小 Batch 尺寸时估计值波动大，RNN 序列任务不适用 | 遥感影像语义分割（U-Net/FCN）、建筑物提取   |

#### 实验任务

创建 `regularization.py` 文件，编写并运行以下代码，在同一多层感知机（MLP）模型上对比基础模型、使用 Dropout、使用 BatchNorm 以及结合 Learning Rate Decay 的训练及验证 Loss 变化趋势：  

```python
"""
程序名称：regularization.py
作者：黄乐源
日期：2026-07-25
描述：PyTorch 中过拟合抑制技巧（Dropout, BatchNorm）与学习率衰减策略（StepLR）的代码实现与对比实验
"""

# 导包
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset

# 1. 构造高维拟合数据集（模拟易过拟合数据）
torch.manual_seed(42)
X_train = torch.randn(200, 100, dtype=torch.float32)
y_train = torch.randint(0, 2, (200,), dtype=torch.int64)

X_val = torch.randn(100, 100, dtype=torch.float32)
y_val = torch.randint(0, 2, (100,), dtype=torch.int64)

train_dataset = TensorDataset(X_train, y_train)
train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)

# 2. 定义包含 Dropout 与 BatchNorm 的对比网络结构
class RegularizedMLP(nn.Module):
    def __init__(self, use_dropout=False, use_bn=False, drop_rate=0.5):
        super(RegularizedMLP, self).__init__()
        
        layers = []
        # Block 1
        layers.append(nn.Linear(100, 128))
        if use_bn:
            layers.append(nn.BatchNorm1d(128))
        layers.append(nn.ReLU())
        if use_dropout:
            layers.append(nn.Dropout(p=drop_rate))
            
        # Block 2
        layers.append(nn.Linear(128, 64))
        if use_bn:
            layers.append(nn.BatchNorm1d(64))
        layers.append(nn.ReLU())
        if use_dropout:
            layers.append(nn.Dropout(p=drop_rate))
            
        # Output Layer
        layers.append(nn.Linear(64, 2))
        
        self.net = nn.Sequential(*layers)
        
    def forward(self, x):
        return self.net(x)

# 3. 编写通用训练与验证函数
def train_and_evaluate(use_dropout=False, use_bn=False, use_scheduler=False, epochs=50):
    model = RegularizedMLP(use_dropout=use_dropout, use_bn=use_bn)
    criterion = nn.CrossEntropyLoss()
    optimizer = optim.Adam(model.parameters(), lr=0.01)
    
    # 初始化学习率衰减器 (每 15 轮衰减为原来的 0.5 倍)
    scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=15, gamma=0.5) if use_scheduler else None
    
    for epoch in range(epochs):
        # 训练模式
        model.train()
        for batch_x, batch_y in train_loader:
            optimizer.zero_grad()
            preds = model(batch_x)
            loss = criterion(preds, batch_y)
            loss.backward()
            optimizer.step()
            
        if scheduler:
            scheduler.step()
            
    # 验证模式
    model.eval()
    with torch.no_grad():
        val_preds = model(X_val)
        val_loss = criterion(val_preds, y_val).item()
        
    return val_loss

# 4. 执行对比实验
print("================= 模型正则化与优化技巧对比实验 (Epochs=50) =================")

configs = [
    ("基础模型 (Baseline)", False, False, False),
    ("引入 Dropout", True, False, False),
    ("引入 BatchNorm", False, True, False),
    ("引入 LR Decay (StepLR)", False, False, True),
    ("综合策略 (BN + Dropout + Decay)", True, True, True)
]

for name, use_drop, use_bn, use_sched in configs:
    final_val_loss = train_and_evaluate(use_dropout=use_drop, use_bn=use_bn, use_scheduler=use_sched, epochs=50)
    print(f"配置方案: {name:<30} | 验证集最终 Loss: {final_val_loss:.4f}")

print("\n----------------- 观察分析结果 -----------------")
print("1. 基础模型在前向传播中易对高维噪声过拟合，导致 Validation Loss 相对偏高。")
print("2. Dropout 通过随机遮蔽神经元显著降低了模型过拟合程度。")
print("3. BatchNorm 标准化了中间层数据分布，使得网络训练更加平稳，收敛更快。")
print("4. StepLR 动态降低学习率，有助于模型在后期落入更加稳定的局部极小值。")

print("\n🏁 Day28 正则化与模型优化技巧实验成功完成！")
```

**Day05-10 学习率优化_背景介绍**：

- 学习率优化的**原因**：
  - 在训练神经网络时，一般情况下学习率都会随着训练而变化。这主要是由于，在神经网络训练的后期，如果**学习率过高**，会造成**loss的振荡**；但是如果**学习率减小的过慢**，又会造成**收敛变慢**的情况。

**Day05-11 至 Day05-13 学习率衰减策略**：

- 常见**学习率衰减策略**：

  - 等间隔学习率衰减：
    - 用法：`optim.lr_scheduler.StepLR(optimazer, step_size, gamma = 0.1)`
      - step_size：调整间隔数（=50）
      - gamma：调整系数（=0.5）
      - 调整方式：`lr = lr * gamma`
    - 即每50轮调整一次学习率，调整方式为：`lr = lr * gamma`。
  - 指定间隔学习率衰减：
    - 用法：`optim.lr_scheduler.MultiStepLR(optimazer, milestones, gamma = 0.1)`
      - milestones：设定调整轮次：[50, 125, 160]
      - gamma：调整系数
      - 调整方式：`lr = lr * gamma`
    - 即在指定的轮次调整学习率，调整方式为：`lr = lr * gamma`。
  - 指数学习率衰减：
    - 用法：`optim.lr_scheduler.ExponentialLR(optimazer, gamma)`
      - gamma：指数的底
      - 调整方式：`lr = lr * gamma^epoch`
    - 即每轮都调整学习率，调整方式为：`lr = lr * gamma^epoch`。前期学习率衰减快，中期慢，后期更慢。

- 总结：

  - 常见的衰减策略有哪些？

    - 等间隔衰减
    - 指定间隔衰减
    - 指数衰减

  - 常见学习率衰减策略对比：

    | 方法         | 等间隔学习率衰减（Step Decay）   | 指定间隔学习率衰减（Exponential Decay）    | 指数学习率衰减（Exponential Moving Average Decay） |
    | ------------ | -------------------------------- | ------------------------------------------ | -------------------------------------------------- |
    | **衰减方式** | 固定步长衰减                     | 指定步长衰减                               | 平滑指数衰减，历史平均考虑                         |
    | **实现难度** | 简单易实现                       | 相对简单，容易调整                         | 需要额外历史计算，较复杂                           |
    | **适用场景** | 大型数据集、较为简单的任务       | 对训练平稳性要求较高的任务                 | 高精度训练，避免过快收敛                           |
    | **优点**     | 直观、易于调试，适用于大批量数据 | 易于调试，稳定训练过程                     | 平滑且考虑历史更新，收敛稳定性较强                 |
    | **缺点**     | 学习率变化较大，可能跳过最优点   | 在某些情况下可能衰减过快，导致优化提前停滞 | 超参数调节较为复杂，可能需要更多的计算资源         |

**Day05-15 至 Day05-18 正则化**：

- 正则化：

  - 在设计机器学习算法时希望在新样本上的泛化能力强。许多机器学习算法都采用相关的策略来**减少测试误差**，这些策略被统称为正则化。神经网络强大的表示能力经常遇到过拟合，所以需要使用不同形式的正则化策略。目前在深度学习中使用较多的策略有：**范数惩罚**，**DropOut**，**特殊的网络层**等。
  - 目的：避免模型过拟合。

- 常见的正则化策略：

  - Dropout（随机失活）正则化：

    - 在训练过程中，Dropout的实现是让神经元以超参数p的概率停止工作或者激活被置为0，未被置为0的进行缩放，缩放比例为1 / (1 - p)。训练过程可以认为是对完整神经网络的一些**子集**进行训练，每次基于输入数据只更新子网络的参数。
    - 一批次一批次训练，每个批次死亡的神经元不确定，通过组合数据，增加“数据量”。p就是随机失活概率。
    - 存活的神经元，缩放比例：1 / (1 - p)，相当于增加了权重。
    - 在实际应用中，Dropout参数p的概率通常取值在**0.2到0.5之间**。
      - 对于较小的模型或较复杂的任务，丢弃率可以选择0.3或更小；
      - 对于非常深的网络，较大的丢弃率（如0.5或0.6）可能会有效防止过拟合；
      - 实际应用中，通常会在全连接层（激活函数后）之后添加Dropout层。
    - 在测试过程中，Dropout（随机失活）不起作用。
      - 在测试阶段，使用所有的神经元进行预测，以获得更稳定的结果。
    - 缩放的必要性：
      - 在训练阶段，将参与计算的神经元的输出除以(1 - p)；
      - 经过Dropout后的期望输出变为：E[x_dropout] = [(1 - p) * x] / (1 - p) = x，与测试阶段的期望输出一致。

  - 批量归一化（BN，即Batch Normalization）：

    - **先对数据标准化，再对数据重构（缩放+平移）**（数据标准化会丢失一些信息，缩放可以理解成w权重，平移理解成b偏置，这样再找补一些信息回来），如下所示：
      $$
      f(x)=\lambda \cdot\frac{x - E(x)}{\sqrt{\operatorname{Var}(x) + \epsilon}}+\beta
      $$

      - λ和β是可学习的参数，它相当于对标准化后的值做了一个**线性变换**，**λ为系数**，**β为偏置**；
      - ε通常指为1e-5，避免分母为0；
      - E(x)表示变量的均值；
      - Var(x)表示变量的方差。

    - 批量归一化在计算机视觉（CV）领域使用较多。

    - 例如：使用sigmoid激活函数，它只有在[-3, 3]之间有较好的效果，如果没有标准化（数据没有在上述区间），可能模型收敛较慢，标准化之后，数据在[0, 1]之间，分布更均匀，模型收敛效果更好，更快。

    - 大白话：

      - 没有批量归一化：乡村小道没有限速随便开，可以1km/h，也可以130km/h；
      - 有了批量归一化：高速公路，最低80km/h，最高120km/h。

    - 批量归一化作用：

      - **减少内部协方差偏移**：通过对每层的输入进行标准化，减少了输入数据分布的变化，从而加速了训练过程，网络在训练过程中更加稳定。
      - **加速训练**：
      - **起到正则化作用**：
      - **提升泛化能力**：

- 总结：

  - 正则化的作用：
    - 缓解模型的过拟合情况。
  - 随机失活Dropout策略：

# 模型优化方法总结.md

本文档为 PyTorch 深度学习与 GeoAI 遥感数据处理中模型优化技巧的专题总结。重点梳理了模型拟合状态分析、动态学习率衰减（`lr_scheduler`）、Dropout（随机失活）以及 Batch Normalization（批归一化）的数学原理、代码实现规范与实践经验，旨在为后续复杂网络（如 U-Net、ResNet 等）的稳定训练提供指导。

## 一、 模型拟合状态与正则化概述

在深度学习任务中，模型拟合能力与泛化能力之间的平衡是核心难题。

### 1. 拟合状态对比

| 拟合状态 | 现象表现 | 主要原因 | 核心解决策略 |
| :---: | :--- | :--- | :--- |
| **欠拟合<br>(Underfitting)** | - 训练集 Loss 居高不下<br>- 验证集 Loss 居高不下 | - 模型表达能力不足（网络过浅/过窄）<br>- 训练轮次（Epochs）不足<br>- 学习率设置不合理 | - 增加网络深度与特征通道数<br>- 延长训练轮次<br>- 减弱正则化约束强度 |
| **过拟合<br>(Overfitting)** | - 训练集 Loss 极低<br>- 验证集 Loss 停滞或反升 | - 模型参数量相对数据量过大<br>- 训练样本单一或存在噪声<br>- 未使用有效的正则化 | - 引入 Dropout / L2 正则化（Weight Decay）<br>- 增加数据增强（Data Augmentation）<br>- 采用早停法（Early Stopping） |

> **💡 GeoAI 场景提示**：遥感影像通常具备通道多、背景地物复杂、高质量标注样本受限等特点。在进行高分辨率遥感影像语义分割或地物提取时，模型极易出现过拟合，合理使用正则化技术尤为重要。

---

## 二、 学习率衰减策略（Learning Rate Decay）

固定学习率容易导致模型在训练后期于极小值附近发生震荡，无法精准收敛。PyTorch 提供了 `torch.optim.lr_scheduler` 模块来实现学习率的动态调整。

### 1. 三种典型衰减策略

#### (1) 等间隔衰减：`StepLR`
- **计算公式**：
  $$
  lr = lr_{0} \times \gamma^{\lfloor \frac{epoch}{step\_size} \rfloor}
  $$
  
- **特点**：每经过固定轮次（`step_size`），将学习率乘以衰减系数 γ。

- **适用场景**：训练目标明确、收敛曲线规律的 Baseline 任务。

#### (2) 多间隔指定衰减：`MultiStepLR`
- **特点**：在自定义的 epoch 节点列表（如 `milestones=[30, 80, 120]`）触发衰减。
- **适用场景**：多阶段训练（如主干网络预训练微调、复杂任务分段优化）。

#### (3) 指数连续衰减：`ExponentialLR`
- **计算公式**：
  $$
  lr = lr_{0} \times \gamma^{epoch}
  $$
  
- **特点**：每个 epoch 均按指数连续平滑衰减。

- **适用场景**：平滑收敛需求较高的深层神经网络。

### 2. 代码调用规范

```python
import torch.optim as optim
from torch.optim.lr_scheduler import StepLR

# 1. 绑定优化器
optimizer = optim.Adam(model.parameters(), lr=0.01)

# 2. 初始化 Scheduler (每 15 轮衰减为原来的 0.5 倍)
scheduler = StepLR(optimizer, step_size=15, gamma=0.5)

# 3. 训练循环中更新（注意：必须在 optimizer.step() 之后）
for epoch in range(epochs):
    train_one_epoch(...)
    optimizer.step()
    scheduler.step()  # 更新学习率
```

## 三、 Dropout（随机失活）

### 1. 工作原理

Dropout 通过在训练过程中随机隐去部分神经元，降低参数之间的共适应性（Co-adaptation），增强模型的泛化能力。

- **训练阶段 (Training)**：

  以概率 p 随机将部分神经元激活值置 0，并对剩余激活值乘以 1 / (1 - p) 进行缩放（Inverted Dropout）：
  $$
  y = \frac{1}{1-p} \cdot m \odot x \quad (m \sim \text{Bernoulli}(1-p))
  $$
  使得前向传播在训练和测试阶段的期望数值保持一致。

- **测试阶段 (Evaluation)**：

  保留所有神经元权重，不再进行随机遮蔽与缩放。

> **⚠️ 注意**：由于 Dropout 在训练和测试时的行为不一致，在模型评估前必须显式调用 `model.eval()`；恢复训练时调用 `model.train()`。

## 四、 Batch Normalization（批归一化）

### 1. 数学计算流程

对于 Batch 大小为 m 的特征数据 B = x_1..m：

1. **计算均值**：
   $$
   \mu_B = \frac{1}{m}\sum_{i=1}^m x_i
   $$
   
2. **计算方差**：
   $$
   \sigma_B^2 = \frac{1}{m}\sum_{i=1}^m (x_i - \mu_B)^2
   $$
   
3. **标准化**：
   $$
   \hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}
   $$
   
4. **缩放与平移（重构）**：
   $$
   y_i = \gamma \hat{x}_i + \beta
   $$
   *（其中 γ，β为网络自主学习的参数）*

### 2. 核心优势与实践建议

- **缓解梯度消失/爆炸**：稳定了中间层数据的数值分布，允许使用更高的初始学习率。
- **加速网络收敛**：大幅降低了模型对权重初始化的敏感度。
- **维度选择**：
  - 1D 特征（全连接层输出/表格数据）：使用 `nn.BatchNorm1d(num_features)`
  - 2D 图像特征（卷积层输出 [B, C, H, W]）：使用 `nn.BatchNorm2d(num_channels)`

## 五、 模块组合与工程实践规范

在构建包含卷积层与全连接层的网络结构时，通常遵循以下标准层级嵌入顺序：

```
[ Linear / Conv2d ] ──> [ BatchNorm ] ──> [ Activation (ReLU) ] ──> [ Dropout ]
```

### 代码结构示例

```python
import torch.nn as nn

class OptimizedBlock(nn.Module):
    def __init__(self, in_dim, out_dim, drop_rate=0.3):
        super(OptimizedBlock, self).__init__()
        self.block = nn.Sequential(
            nn.Linear(in_dim, out_dim),
            nn.BatchNorm1d(out_dim),  # 1. 批归一化
            nn.ReLU(),                # 2. 激活函数
            nn.Dropout(p=drop_rate)   # 3. 随机失活
        )
        
    def forward(self, x):
        return self.block(x)
```
