### 第二阶段：理论学习（约 0.5 小时）

深入理解非线性激活函数与参数初始化的核心理论：  

- **ReLU 激活函数**：
  $$
  f(x) = \max(0, x)
  $$
  在 x > 0 时梯度恒为 1，彻底解决了正半轴的梯度消失问题，计算速度极快；在 $x \le 0$ 时输出为 $0$，具有稀疏激活特性。  

- **Softmax 激活函数**：
  $$
  S_i = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}}
  $$
  将包含 C 个类别得分的 logits 向量映射为总和为 $1$ 的概率分布（每个概率区间均在 (0, 1)）。  

- **参数初始化策略**：

  - **Xavier (Glorot) 初始化**：适用于 Sigmoid / Tanh 激活函数，旨在保持输入输出的方差一致。  

  - **Kaiming (He) 初始化**：专为 ReLU / LeakyReLU 设计，考虑到零点裁剪造成的方差减半，采用
    $$
    \sqrt{2 / \text{fan_in}}
    $$
     缩放因子。

#### 实验任务

创建 `activation_function.py` 文件，编写并运行以下代码，实现激活函数（Sigmoid、Tanh、ReLU）对比、Softmax 概率计算以及参数初始化实战：  

```python
"""
程序名称：activation_function.py
作者：黄乐源
日期：2026-07-21
描述：PyTorch 常用激活函数特性对比 (Sigmoid, Tanh, ReLU, Softmax) 与参数初始化 (Xavier / Kaiming) 实战
"""

import torch
import torch.nn as nn
import matplotlib.pyplot as plt

print("================= 任务 1：Sigmoid, Tanh 与 ReLU 激活函数可视化对比 =================")

# 生成区间 [-6, 6] 的连续数据
x = torch.linspace(-6, 6, 300)

# 实例化激活函数模块
sigmoid_func = nn.Sigmoid()
tanh_func = nn.Tanh()
relu_func = nn.ReLU()

y_sigmoid = sigmoid_func(x)
y_tanh = tanh_func(x)
y_relu = relu_func(x)

# 绘制三图对比
plt.figure(figsize=(14, 4))

# 1. Sigmoid
plt.subplot(1, 3, 1)
plt.plot(x.numpy(), y_sigmoid.numpy(), color='blue', linewidth=2, label='Sigmoid')
plt.axhline(0, color='black', linestyle='--', alpha=0.4)
plt.axhline(1, color='black', linestyle='--', alpha=0.4)
plt.title("Sigmoid Activation")
plt.xlabel("Input x")
plt.ylabel("Output y")
plt.grid(True)
plt.legend()

# 2. Tanh
plt.subplot(1, 3, 2)
plt.plot(x.numpy(), y_tanh.numpy(), color='green', linewidth=2, label='Tanh')
plt.axhline(-1, color='black', linestyle='--', alpha=0.4)
plt.axhline(1, color='black', linestyle='--', alpha=0.4)
plt.title("Tanh Activation")
plt.xlabel("Input x")
plt.ylabel("Output y")
plt.grid(True)
plt.legend()

# 3. ReLU
plt.subplot(1, 3, 3)
plt.plot(x.numpy(), y_relu.numpy(), color='red', linewidth=2, label='ReLU')
plt.axhline(0, color='black', linestyle='--', alpha=0.4)
plt.title("ReLU Activation")
plt.xlabel("Input x")
plt.ylabel("Output y")
plt.grid(True)
plt.legend()

plt.tight_layout()
plt.show()

print("\n================= 任务 2：Softmax 多分类概率转换实验 =================")

# 假设神经网络对 3 个样本的 4 分类 Logits 输出
logits = torch.tensor([
    [2.0, 1.0, 0.1, 0.5],
    [0.5, 3.2, 0.1, 0.2],
    [-1.0, 0.0, 2.5, 1.1]
], dtype=torch.float32)

softmax_layer = nn.Softmax(dim=1)
probabilities = softmax_layer(logits)

print("原始 Logits得分:\n", logits)
print("\n经过 Softmax 转换后的类别概率:\n", probabilities)
print("\n每个样本所有类别概率之和:", torch.sum(probabilities, dim=1))

print("\n================= 任务 3：PyTorch 参数初始化实战 =================")

class CustomNet(nn.Module):
    def __init__(self):
        super(CustomNet, self).__init__()
        self.fc1 = nn.Linear(10, 20)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(20, 5)

        # 执行参数初始化
        self._init_weights()

    def _init_weights(self):
        # 对 Linear 层做 Kaiming 正态分布初始化（针对 ReLU 激活）
        nn.init.kaiming_normal_(self.fc1.weight, nonlinearity='relu')
        nn.init.constant_(self.fc1.bias, 0.0)

        # 对最后一层输出层做 Xavier 均匀分布初始化
        nn.init.xavier_uniform_(self.fc2.weight)
        nn.init.constant_(self.fc2.bias, 0.0)

    def forward(self, x):
        x = self.relu(self.fc1(x))
        out = self.fc2(x)
        return out

net = CustomNet()
print("自定义网络权重 shape:", net.fc1.weight.shape)
print("fc1 权重前 2 行初始化数值示例:\n", net.fc1.weight[:2])
print("fc1 偏置前 5 项初始化数值示例:\n", net.fc1.bias[:5])

print("\n🏁 Day24 激活函数与参数初始化实验成功完成！")
```
