### 第二阶段：理论学习（约 0.5 小时）

深入理解 PyTorch 深度学习训练的标准五大核心要素：

- **数据准备 (Dataset & DataLoader)**：构建输入特征 X 与目标值 y，确保张量维度匹配（通常为 `(N, in_features)` 与 `(N, out_features)`）。  

- **模型定义 (Model)**：继承 `nn.Module`，在 `__init__` 中定义网络层（如 `nn.Linear(in_features, out_features)`），在 `forward` 中定义前向传播逻辑。  

- **损失函数与优化器 (Loss & Optimizer)**：

  - 均方误差损失：
    $$
    \text{MSELoss}() = \frac{1}{N} \sum (y_{\text{pred}} - y_{\text{true}})^2
    $$
    。  

  - 优化算法：`optim.SGD(model.parameters(), lr=0.01)` 或 `optim.Adam`。  

- **训练标准循环步骤 (Training Loop)**：
  $$
  \text{y_pred = model(x)} \longrightarrow \text{loss = criterion(y_pred, y)} \longrightarrow \text{optimizer.zero_grad()} \longrightarrow \text{loss.backward()} \longrightarrow \text{optimizer.step()}
  $$

#### 实验任务

创建 `linear_regression.py` 文件，手工编写并运行以下代码，实现 PyTorch 模拟线性回归拟合、Loss 记录与结果可视化：  

```python
"""
程序名称：linear_regression.py
作者：黄乐源
日期：2026-07-19
描述：PyTorch 完整模型训练流程实战——模拟线性回归与 Loss 可视化
"""
import torch
import torch.nn as nn
import torch.optim as optim
import matplotlib.pyplot as plt

print("================= 任务 1：准备合成数据集 =================")

# 设定随机种子以保证实验可复现
torch.manual_seed(42)

# 真实参数：w = 3.0, b = 2.0
true_w = 3.0
true_b = 2.0

# 生成 100 个随机样本 X，并加入高斯噪声构建 y
X = torch.randn(100, 1)
noise = torch.randn(100, 1) * 0.2
y = true_w * X + true_b + noise

print(f"数据集构建完成！X 形状: {X.shape}, y 形状: {y.shape}")

print("\n================= 任务 2：构建线性回归模型 =================")

class LinearRegressionModel(nn.Module):
    def __init__(self):
        super(LinearRegressionModel, self).__init__()
        # 输入维度为 1，输出维度为 1 的全连接线性层
        self.linear = nn.Linear(in_features=1, out_features=1)

    def forward(self, x):
        return self.linear(x)

model = LinearRegressionModel()
print("模型结构:\n", model)

print("\n================= 任务 3：配置损失函数与优化器 =================")

criterion = nn.MSELoss()
optimizer = optim.SGD(model.parameters(), lr=0.05)

print("\n================= 任务 4：开始模型训练循环 =================")

epochs = 100
loss_history = []

for epoch in range(1, epochs + 1):
    # 1. 前向传播
    y_pred = model(X)
    
    # 2. 计算损失
    loss = criterion(y_pred, y)
    loss_history.append(loss.item())
    
    # 3. 梯度清零
    optimizer.zero_grad()
    
    # 4. 反向传播
    loss.backward()
    
    # 5. 参数更新
    optimizer.step()
    
    if epoch % 10 == 0 or epoch == 1:
        # 获取当前学到的参数
        learned_w = model.linear.weight.item()
        learned_b = model.linear.bias.item()
        print(f"Epoch [{epoch:3d}/{epochs}] - Loss: {loss.item():.4f} | 学到的 w: {learned_w:.4f}, b: {learned_b:.4f}")

print("\n================= 任务 5：拟合结果与 Loss 曲线可视化 =================")

# 绘制拟合直线与数据点
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.scatter(X.numpy(), y.numpy(), color='blue', label='Real Data (Noise)', alpha=0.6)
with torch.no_grad():
    predictions = model(X).numpy()
plt.plot(X.numpy(), predictions, color='red', linewidth=2, label='Fitted Line')
plt.xlabel('X')
plt.ylabel('y')
plt.title('Linear Regression Fit')
plt.legend()
plt.grid(True)

# 绘制 Loss 收敛曲线
plt.subplot(1, 2, 2)
plt.plot(range(1, epochs + 1), loss_history, color='green', linewidth=2)
plt.xlabel('Epoch')
plt.ylabel('MSE Loss')
plt.title('Training Loss Convergence')
plt.grid(True)

plt.tight_layout()
plt.show()

print("\n🏁 Day22 GeoAI PyTorch 线性回归模型训练实战完成！")
```
