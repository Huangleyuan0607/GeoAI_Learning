### 第二阶段：理论学习（约 1.0 小时）

系统梳理 CNN 经典网络的发展脉络与 AlexNet 的结构细节：

- **核心知识点**：

  - **LeNet 的局限 vs AlexNet 的突破**：

    | LeNet | AlexNet |
    | -------- | --------- |
    | 浅层网络 | 深层网络 |
    | CPU训练 | GPU训练 |
    | 小数据 | ImageNet |
    | 简单卷积 | 大规模CNN |

  - **核心技术**：

    - **ReLU 激活函数**：相比 Sigmoid / Tanh 缓解梯度消失，计算更快，训练更深网络成为可能
    - **Dropout**：随机失活神经元，抑制过拟合
    - **GPU 训练**：让大规模网络 + 大规模数据的训练在可接受时间内完成
    - **数据增广**：扩大有效样本量
    - **重叠最大池化**：池化窗口大于步长，提特征更充分

  - **AlexNet 网络结构（共 8 层）**：**5 个卷积层 + 3 个全连接层**

#### 实验任务

创建 `AlexNet.py`，在 `pytorch/Day36/AlexNet.py` 中搭建 AlexNet 网络，查看网络结构并测试前向传播：

```python
import torch
import torch.nn as nn


class AlexNet(nn.Module):
    """AlexNet 网络结构（2012）：5 个卷积层 + 3 个全连接层"""
    def __init__(self, num_classes=1000):
        super(AlexNet, self).__init__()
        # 特征提取部分：5 个卷积层（每层后接 ReLU，共 3 次最大池化）
        self.features = nn.Sequential(
            # 第1组：卷积 -> 激活 -> 池化
            nn.Conv2d(in_channels=3, out_channels=64, kernel_size=11, stride=4, padding=2),   # 224 -> 55
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),                                            # 55 -> 27

            # 第2组：卷积 -> 激活 -> 池化
            nn.Conv2d(in_channels=64, out_channels=192, kernel_size=5, padding=2),            # 27 -> 27
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),                                            # 27 -> 13

            # 第3~5组：连续三个卷积层（不改变空间尺寸）
            nn.Conv2d(in_channels=192, out_channels=384, kernel_size=3, padding=1),           # 13 -> 13
            nn.ReLU(inplace=True),
            nn.Conv2d(in_channels=384, out_channels=256, kernel_size=3, padding=1),           # 13 -> 13
            nn.ReLU(inplace=True),
            nn.Conv2d(in_channels=256, out_channels=256, kernel_size=3, padding=1),           # 13 -> 13
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),                                            # 13 -> 6
        )
        # 分类部分：3 个全连接层（前两个全连接层前各加一个 Dropout）
        self.classifier = nn.Sequential(
            nn.Dropout(p=0.5),
            nn.Linear(256 * 6 * 6, 4096),
            nn.ReLU(inplace=True),
            nn.Dropout(p=0.5),
            nn.Linear(4096, 4096),
            nn.ReLU(inplace=True),
            nn.Linear(4096, num_classes),
        )

    def forward(self, x):
        # 1.特征提取：(N, 3, 224, 224) -> (N, 256, 6, 6)
        x = self.features(x)
        # 2.展平：(N, 256, 6, 6) -> (N, 256 * 6 * 6) = (N, 9216)
        x = x.reshape(x.shape[0], -1)
        # 3.全连接分类：(N, 9216) -> (N, num_classes)
        x = self.classifier(x)
        return x


def main():
    # 1.创建模型对象
    model = AlexNet(num_classes=1000)
    print("=" * 60)
    print("AlexNet 网络结构：")
    print("=" * 60)
    print(model)

    # 2.统计参数量
    total = sum(p.numel() for p in model.parameters())
    conv_params = sum(p.numel() for p in model.features.parameters())
    fc_params = sum(p.numel() for p in model.classifier.parameters())
    print("=" * 60)
    print(f"总参数量: {total:,} ({total / 1e6:.1f} M)")
    print(f"  卷积层参数: {conv_params:,} ({conv_params / total * 100:.1f}%)")
    print(f"  全连接层参数: {fc_params:,} ({fc_params / total * 100:.1f}%)")

    # 3.输入随机图片测试前向传播
    x = torch.randn(1, 3, 224, 224)     # 模拟一张 224x224 的 RGB 图像
    model.eval()
    with torch.no_grad():
        y = model(x)
    print("=" * 60)
    print(f"输入 Shape: {tuple(x.shape)}")
    print(f"输出 Shape: {tuple(y.shape)}")


if __name__ == "__main__":
    main()
```

## 今日收获

**第79讲 AlexNet**：

- **AlexNet**

  - 本质上是**更深更大的LeNet**

  - 主要**改进**：

    - 增加**Dropout**层
    - 改用**ReLU**激活函数
    - 改用**MaxPooling最大池化**

  - 与LeNet**相比**：

    - **卷积层**和**池化层**
      - 采用了**更大的池化窗口**（AlexNet：3x3最大池化 LeNet：2x2平均池化），使用**最大池化层**
      - 使用了**更大的核窗口**（AlexNet：11x11 LeNet：5x5）和**步长**（AlexNet：4 LeNet：1），因为图片更大了（AlexNet：3x224x224 LeNet：32x32）
      - 新加了**3层卷积层**及**更多的输出通道**
    - **全连接层**
      - **输入数据**从 **120 -> 4096**
      - **输出类**从 **10 -> 1000**
      - 整体全连接层从 **LeNet的(120 -> 84 -> 10)** 变为 **AlexNet的(4096 -> 4096 -> 1000)**

  - 更多**细节**

    - 激活函数从Sigmoid变为**ReLU**（**减缓梯度消失**）
    - **隐藏全连接层后加入了Dropout层**
    - **数据增强**（如在训练中模拟实际中可能会出现的变化，从而改善训练效果）

  - **复杂度**

    |          | AlexNet参数个数 | LeNet参数个数 | AlexNet FLOP（**浮点运算次数**） | LeNet FLOP（**浮点运算次数**） |
    | :------- | :-------------: | :-----------: | :------------------------------: | :----------------------------: |
    | Conv1    |       35K       |      150      |               101M               |              1.2M              |
    | Conv2    |      614K       |     2.4K      |               415M               |              2.4M              |
    | Conv3-5  |       3M        |               |               445M               |                                |
    | Dense1   |       26M       |     0.48M     |               26M                |             0.48M              |
    | Dense2   |       16M       |     0.1M      |               16M                |              0.1M              |
    | Total    |       46M       |     0.6M      |                1G                |               4M               |
    | Increase |       11x       |      1x       |               250x               |               1x               |

  - 总结

    - AlexNet是更大更深的LeNet，10x参数个数，260x计算复杂度
    - 新加入了Dropout，ReLU，最大池化层和数据增强
    - AlexNet赢下了2012ImageNet竞赛后，标志着新一轮的神经网络热潮的开始
