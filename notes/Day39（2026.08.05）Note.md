### 第二阶段：理论学习（约 1.0 小时）

系统梳理 CNN Backbone 的概念与用法：

- **核心知识点**：

  - **什么是 Backbone**：

    ```
    Input Image
        ↓
    CNN Backbone     ← 特征提取主干（负责把图像变成特征图）
        ↓
    Feature Map
        ↓
    Task Head        ← 任务头（负责把特征图变成任务输出）
    ```

    **一个 Backbone，可以接不同的 Task Head**，这正是迁移学习的基础。

  - **同一 Backbone 适配不同任务**：

    **分类任务**：

    ```
    ResNet
     ↓
    FC
     ↓
    Class
    ```

    **分割任务**：

    ```
    ResNet
     ↓
    Decoder
     ↓
    Mask
    ```

    其他任务头还有：目标检测（FPN + RPN）、关键点检测、特征嵌入等。

  - **为什么 Backbone 可以复用**：
    - 浅层学到的**边缘、纹理、角点**是几乎所有视觉任务共有的
    - 深层学到的**语义特征**才与具体任务相关
    - 所以常见做法是：**加载预训练 Backbone 权重 → 冻结或微调 → 只换 Task Head**

  - **ResNet50 的命名规则**：

    | 网络 | 残差块类型 | 每个 stage 的块数 | 层数计算 |
    | -------- | ---------- | ----------------- | ---------------------------------------- |
    | ResNet18 | BasicBlock | 2 / 2 / 2 / 2 | 8 块 × 2 卷积 + 1 + 1 = 18 |
    | ResNet34 | BasicBlock | 3 / 4 / 6 / 3 | 16 块 × 2 卷积 + 1 + 1 = 34 |
    | **ResNet50** | **Bottleneck** | **3 / 4 / 6 / 3** | 16 块 × **3** 卷积 + 1 + 1 = **50** |

  - **Bottleneck 与 BasicBlock 的区别**（对应 Day38 学过的残差块）：

    | 类型 | 结构 | 用途 |
    | -------- | ------------------------- | ------------- |
    | **BasicBlock** | 两个 3×3 卷积 | ResNet18 / 34 |
    | **Bottleneck** | **1×1 降维 → 3×3 → 1×1 升维** | ResNet50 / 101 / 152 |

    > Bottleneck 先用 1×1 把通道压到 1/4，做 3×3 卷积后再用 1×1 升回去 —— **在加深网络的同时控制参数量**。

#### 实验任务

创建 `backbone_test.py`，加载 `torchvision` 官方 ResNet50，查看网络层并输出各阶段 feature map：

```python
import torch
import torch.nn as nn
from torchvision import models


def main():
    # 1.加载 ResNet50（weights=None 表示随机初始化，避免联网下载预训练权重）
    model = models.resnet50(weights=None)
    model.eval()

    # 2.查看网络层（顶层结构）
    print("=" * 60)
    print("ResNet50 顶层结构：")
    print("=" * 60)
    for name, module in model.named_children():
        print(f"  {name:<12} {module.__class__.__name__}")

    # 3.统计参数量
    total = sum(p.numel() for p in model.parameters())
    print()
    print(f"总参数量: {total:,} ({total / 1e6:.1f} M)")

    # 4.逐段输出 feature map（观察 Backbone 的特征提取过程）
    x = torch.randn(1, 3, 224, 224)
    print()
    print("=" * 60)
    print("Backbone 各阶段 feature map 形状：")
    print("=" * 60)
    with torch.no_grad():
        print(f"  输入           {tuple(x.shape)}")
        x = model.conv1(x);   print(f"  conv1          {tuple(x.shape)}")
        x = model.bn1(x)
        x = model.relu(x)
        x = model.maxpool(x); print(f"  maxpool        {tuple(x.shape)}")
        x = model.layer1(x);  print(f"  layer1         {tuple(x.shape)}")
        x = model.layer2(x);  print(f"  layer2         {tuple(x.shape)}")
        x = model.layer3(x);  print(f"  layer3         {tuple(x.shape)}")
        x = model.layer4(x);  print(f"  layer4         {tuple(x.shape)}   <- Backbone 输出")

    # 5.把 Backbone 单独截取出来（去掉 avgpool 与 fc）
    backbone = nn.Sequential(*list(model.children())[:-2])
    feat = backbone(torch.randn(1, 3, 224, 224))
    print()
    print(f"  用 Sequential 截取的 Backbone 输出: {tuple(feat.shape)}")

    # 6.接上不同的 Task Head
    gap = nn.AdaptiveAvgPool2d(1)
    v = gap(feat).reshape(1, -1)
    print(f"  经过 GAP 之后: {tuple(v.shape)}  -> 可直接接分类头 / 分割头")


if __name__ == "__main__":
    main()
```

#### 维度推导验证（ResNet50）

| 阶段 | 操作 | 输入 Shape | 输出 Shape | 计算依据 |
|---|---|---|---|---|
| 输入 | — | — | (N, 3, 224, 224) | ImageNet 图像尺寸 |
| conv1 | `Conv(7×7, s=2, p=3)` | (N, 3, 224, 224) | (N, 64, 112, 112) | (224+6-7)/2+1 = 112 |
| maxpool | `MaxPool(3, 2, 1)` | (N, 64, 112, 112) | (N, 64, 56, 56) | (112+2-3)/2+1 = 56 |
| **layer1** | 3 × Bottleneck（256 通道） | (N, 64, 56, 56) | (N, 256, 56, 56) | 尺寸不变，通道升到 256 |
| **layer2** | 4 × Bottleneck（512 通道） | (N, 256, 56, 56) | (N, 512, 28, 28) | 56/2 = 28 |
| **layer3** | 6 × Bottleneck（1024 通道） | (N, 512, 28, 28) | (N, 1024, 14, 14) | 28/2 = 14 |
| **layer4** | 3 × Bottleneck（2048 通道） | (N, 1024, 14, 14) | (N, 2048, 7, 7) | 14/2 = 7 |
| **avgpool（GAP）** | `AdaptiveAvgPool2d(1)` | (N, 2048, 7, 7) | (N, 2048, 1, 1) | 每通道取平均 |
| fc | `Linear(2048→1000)` | (N, 2048) | (N, 1000) | 1000 个类别 |

> **与 Day38 的对应关系**：`conv1 + maxpool` 相当于 Day38 写的 `stem`；`layer1~layer4` 对应 Day38 的 `stage1~stage4`；`avgpool + fc` 就是 GAP + 全连接输出。

#### 参数量分析（延续前两天的观察）

| 项目 | 参数量 | 占比 |
|---|---|---|
| ResNet50 全模型 | 25,557,032 | 100% |
| **全连接层 `fc`** | **2,049,000** | **8.0%** |

**全连接层占比的三天对比**：

| 网络 | 全连接层参数占比 | 说明 |
|---|---|---|
| AlexNet（Day36） | **96.0%** | 3 层巨型 FC |
| VGG16（Day37） | **89.4%** | 第一层 FC 独占 74% |
| 简化 ResNet（Day38） | **0.05%** | GAP + 10 类输出 |
| **ResNet50（本日）** | **8.0%** | 1000 类输出，FC 也不到 1/10 |

> ResNet50 的 FC 占比回升到 8%，是因为类别数从 10 涨到 1000（`2048×1000`），但**相比 AlexNet / VGG 已经是数量级的改善** —— GAP 把"展平维度高达 2 万"这个根源问题彻底解掉了。
