### 第二阶段：理论学习（约 1.0 小时）

系统梳理 CNN Backbone 的概念与用法：

- **核心知识点**：

  - **什么是 Backbone**：

    ```
    Input Image
        ↓
    CNN Backbone     ← 特征提取主干（负责把图像变成特征图）
        ↓
    Feature Map
        ↓
    Task Head        ← 任务头（负责把特征图变成任务输出）
    ```

    **一个 Backbone，可以接不同的 Task Head**，这正是迁移学习的基础。

  - **同一 Backbone 适配不同任务**：

    **分类任务**：

    ```
    ResNet
     ↓
    FC
     ↓
    Class
    ```

    **分割任务**：

    ```
    ResNet
     ↓
    Decoder
     ↓
    Mask
    ```

    其他任务头还有：目标检测（FPN + RPN）、关键点检测、特征嵌入等。

  - **为什么 Backbone 可以复用**：
    - 浅层学到的**边缘、纹理、角点**是几乎所有视觉任务共有的
    - 深层学到的**语义特征**才与具体任务相关
    - 所以常见做法是：**加载预训练 Backbone 权重 → 冻结或微调 → 只换 Task Head**

  - **ResNet50 的命名规则**：

    | 网络 | 残差块类型 | 每个 stage 的块数 | 层数计算 |
    | -------- | ---------- | ----------------- | ---------------------------------------- |
    | ResNet18 | BasicBlock | 2 / 2 / 2 / 2 | 8 块 × 2 卷积 + 1 + 1 = 18 |
    | ResNet34 | BasicBlock | 3 / 4 / 6 / 3 | 16 块 × 2 卷积 + 1 + 1 = 34 |
    | **ResNet50** | **Bottleneck** | **3 / 4 / 6 / 3** | 16 块 × **3** 卷积 + 1 + 1 = **50** |

  - **Bottleneck 与 BasicBlock 的区别**（对应 Day38 学过的残差块）：

    | 类型 | 结构 | 用途 |
    | -------- | ------------------------- | ------------- |
    | **BasicBlock** | 两个 3×3 卷积 | ResNet18 / 34 |
    | **Bottleneck** | **1×1 降维 → 3×3 → 1×1 升维** | ResNet50 / 101 / 152 |

    > Bottleneck 先用 1×1 把通道压到 1/4，做 3×3 卷积后再用 1×1 升回去 —— **在加深网络的同时控制参数量**。

#### 实验任务

创建 `backbone_test.py`，加载 `torchvision` 官方 ResNet50，查看网络层并输出各阶段 feature map：

```python
import torch
import torch.nn as nn
from torchvision import models


def main():
    # 1.加载 ResNet50（weights=None 表示随机初始化，避免联网下载预训练权重）
    model = models.resnet50(weights=None)
    model.eval()

    # 2.查看网络层（顶层结构）
    print("=" * 60)
    print("ResNet50 顶层结构：")
    print("=" * 60)
    for name, module in model.named_children():
        print(f"  {name:<12} {module.__class__.__name__}")

    # 3.统计参数量
    total = sum(p.numel() for p in model.parameters())
    print()
    print(f"总参数量: {total:,} ({total / 1e6:.1f} M)")

    # 4.逐段输出 feature map（观察 Backbone 的特征提取过程）
    x = torch.randn(1, 3, 224, 224)
    print()
    print("=" * 60)
    print("Backbone 各阶段 feature map 形状：")
    print("=" * 60)
    with torch.no_grad():
        print(f"  输入           {tuple(x.shape)}")
        x = model.conv1(x);   print(f"  conv1          {tuple(x.shape)}")
        x = model.bn1(x)
        x = model.relu(x)
        x = model.maxpool(x); print(f"  maxpool        {tuple(x.shape)}")
        x = model.layer1(x);  print(f"  layer1         {tuple(x.shape)}")
        x = model.layer2(x);  print(f"  layer2         {tuple(x.shape)}")
        x = model.layer3(x);  print(f"  layer3         {tuple(x.shape)}")
        x = model.layer4(x);  print(f"  layer4         {tuple(x.shape)}   <- Backbone 输出")

    # 5.把 Backbone 单独截取出来（去掉 avgpool 与 fc）
    backbone = nn.Sequential(*·list(model.children())[:-2])
    feat = backbone(torch.randn(1, 3, 224, 224))
    print()
    print(f"  用 Sequential 截取的 Backbone 输出: {tuple(feat.shape)}")

    # 6.接上不同的 Task Head
    gap = nn.AdaptiveAvgPool2d(1)
    v = gap(feat).reshape(1, -1)
    print(f"  经过 GAP 之后: {tuple(v.shape)}  -> 可直接接分类头 / 分割头")


if __name__ == "__main__":
    main()
```

#### 维度推导验证（ResNet50）

| 阶段 | 操作 | 输入 Shape | 输出 Shape | 计算依据 |
|---|---|---|---|---|
| 输入 | — | — | (N, 3, 224, 224) | ImageNet 图像尺寸 |
| conv1 | `Conv(7×7, s=2, p=3)` | (N, 3, 224, 224) | (N, 64, 112, 112) | (224+6-7)/2+1 = 112 |
| maxpool | `MaxPool(3, 2, 1)` | (N, 64, 112, 112) | (N, 64, 56, 56) | (112+2-3)/2+1 = 56 |
| **layer1** | 3 × Bottleneck（256 通道） | (N, 64, 56, 56) | (N, 256, 56, 56) | 尺寸不变，通道升到 256 |
| **layer2** | 4 × Bottleneck（512 通道） | (N, 256, 56, 56) | (N, 512, 28, 28) | 56/2 = 28 |
| **layer3** | 6 × Bottleneck（1024 通道） | (N, 512, 28, 28) | (N, 1024, 14, 14) | 28/2 = 14 |
| **layer4** | 3 × Bottleneck（2048 通道） | (N, 1024, 14, 14) | (N, 2048, 7, 7) | 14/2 = 7 |
| **avgpool（GAP）** | `AdaptiveAvgPool2d(1)` | (N, 2048, 7, 7) | (N, 2048, 1, 1) | 每通道取平均 |
| fc | `Linear(2048→1000)` | (N, 2048) | (N, 1000) | 1000 个类别 |

> **与 Day38 的对应关系**：`conv1 + maxpool` 相当于 Day38 写的 `stem`；`layer1~layer4` 对应 Day38 的 `stage1~stage4`；`avgpool + fc` 就是 GAP + 全连接输出。

## 今日收获

**PyTorch官方模型阅读：torchvision.models.resnet**：

- 官方模型要点

  - **`BasicBlock`**

    - 主要用于 ResNet-18 和 ResNet-34。
    - 它定义中多了甄别**分组卷积**和**空洞卷积**的参数，因为 `BasicBlock` 的设计就是简单的两个 3×3 卷积，不支持**分组卷积**和**空洞卷积**。

  - **`Bottleneck`**

    - 主要用于 ResNet-50、ResNet-101、ResNet-152 等更深的网络。
    - 它和 `BasicBlock` 最大的区别是：**用三个卷积层（1×1 → 3×3 → 1×1）代替两个 3×3 卷积，并且输出通道会扩展 4 倍**。如：`planes`代表这个块的**基础通道数**，而**`expansion = 4`**表示这个块的输出通道数是内部工作通道数 `planes` 的 4 倍，即： `planes * expansion = planes * 4`。
    - **`width` 计算**：这是 `Bottleneck` 内部 3×3 卷积的通道数。
      - 标准 ResNet：`groups=1, base_width=64`，所以 `width = int(planes * (64/64)) * 1 = planes`。

  - **`Bottleneck`**与**`BasicBlock`** 的对比

    | 特性         | `BasicBlock`              | `Bottleneck`                           |
    | :----------- | :------------------------ | :------------------------------------- |
    | 卷积层       | 两个 3×3                  | 1×1 → 3×3 → 1×1                        |
    | `expansion`  | 1                         | 4                                      |
    | 输出通道     | `planes`                  | `planes * 4`                           |
    | 下采样位置   | `conv1`（第一个 3×3）     | `conv2`（中间的 3×3）                  |
    | 支持分组卷积 | 不支持（强制 `groups=1`） | 支持（ResNeXt）                        |
    | 支持空洞卷积 | 不支持（`dilation=1`）    | 支持（`dilation>1`）                   |
    | 适用网络     | ResNet-18/34              | ResNet-50/101/152                      |
    | 计算量       | 相对较大（两个 3×3）      | 相对较小（先降维再升维，3×3 通道数少） |

  - **`conv3x3`**：创建 3×3 卷积

    - 用于快速创建 3x3 卷积层，并统一设置好常用的参数（如 `bias=False`、`padding` 等）。
      - `BasicBlock` 中的两个 3×3 卷积都用 `conv3x3` 创建。
      - `Bottleneck` 中间的 3×3 卷积也用 `conv3x3`，并且可以传入 `stride`、`groups`、`dilation`。
    - 参数含义：
      - `in_planes`：输入通道数。
      - `out_planes`：输出通道数。
      - `stride`：步长，默认 1。当 `stride=2` 时，特征图尺寸减半。
      - `groups`：分组卷积的组数，默认 1（普通卷积）。用于 ResNeXt。
      - `kernel_size=3`：固定为 3×3 卷积。
      - `dilation`：空洞卷积的膨胀率，默认 1（普通卷积）。用于语义分割等任务。
      - `padding=dilation`：这是为了在 `stride=1` 时保持特征图尺寸不变。
        - 对于 3×3 卷积，当膨胀率为 `dilation` 时，有效卷积核大小变为 `3 + (3-1)*(dilation-1) = 2*dilation + 1`。
        - 为了保持输出尺寸与输入相同，需要`padding = dilation`。
        - 例如：`dilation=1` 时`padding=1`；`dilation=2` 时`padding=2`。
      - `bias=False`：不使用偏置。因为 ResNet 中每个卷积后都紧跟 `BatchNorm2d`，BN 中的 `beta` 参数可以起到偏置的作用，所以卷积的 `bias` 是冗余的。去掉它可以减少参数量，并且训练更稳定。

  - **`conv1x1`**：创建 1×1 卷积

    - 用于快速创建 1x1 卷积层，并统一设置好常用的参数（如 `bias=False`、`padding` 等）。
      - `Bottleneck` 的 `conv1`：1×1 卷积，用于降维（`inplanes → width`）。
      - `Bottleneck` 的 `conv3`：1×1 卷积，用于升维（`width → planes * expansion`）。
      - `downsample` 模块：当残差块的输入输出维度不匹配时，捷径分支用 1×1 卷积来调整通道数和空间尺寸（通常配合 `stride=2` 和 `BatchNorm`），也就是让初始输入x与经过卷积后的y保持维度一致。
    - 参数含义：
      - `in_planes`：输入通道数。
      - `out_planes`：输出通道数。
      - `stride`：步长，默认 1。当 `stride=2` 时，也可以用来下采样（但通常 1×1 卷积不用于空间下采样，而是用于通道变换）。
      - `kernel_size=1`：固定为 1×1 卷积。
      - 无 `padding`：1×1 卷积不需要 padding，因为卷积核大小为 1，不会改变特征图的空间尺寸（除非 stride > 1）。
      - `bias=False`：同样因为后面接 BatchNorm，所以不需要偏置。
      - 不支持 `groups` 和 `dilation`：1×1 卷积通常用于通道变换，不需要分组或空洞。

  - **`ResNet`**

    - ResNet网络的完整实现，包括网络构建（`__init__`）、阶段生成（`_make_layer`）和前向传播（`_forward_impl` / `forward`）。
    - **`__init__`**：搭建网络骨架
      - 参数含义：
        - `block`：残差块类型，`BasicBlock` 或 `Bottleneck`。
        - `layers`：长度为 4 的列表，如 `[2,2,2,2]`，表示四个 stage 的块数。
        - `num_classes`：分类数。
        - `zero_init_residual`：是否零初始化残差分支最后一个 BN。
        - `groups` / `width_per_group`：ResNeXt 参数。
        - `replace_stride_with_dilation`：是否用空洞卷积替代 stride 下采样。
        - `norm_layer`：归一化层，默认 `BatchNorm2d`。
      - 初始化流程：
        - 1、设置 `self.inplanes = 64`（当前通道数），`self.dilation = 1`。
        - 2、构建 **stem**：`conv1`（7×7, stride=2, padding=3）→ `bn1` → `relu` → `maxpool`（3×3, stride=2, padding=1）。
        - 3、构建四个 stage：
        - 4、分类头：`AdaptiveAvgPool2d((1,1))` → `flatten` → `fc`。
        - 5、权重初始化：卷积用 Kaiming，BN 用标准初始化，可选零初始化残差分支最后一个 BN。
    - **`_make_layer`**：按配置批量生成阶段
      - ResNet中最核心的构建逻辑，负责生产一个stage中的所有残差块。
      - 参数含义：
        - `block`：残差块类型。
        - `planes`：该 stage 的基础通道数。对于 `BasicBlock`，输出通道就是 `planes`；对于 `Bottleneck`，输出是 `planes * 4`。
        - `blocks`：该 stage 包含的残差块数量。
        - `stride`：第一个块的步长，默认为 1。当 `stride=2` 时，特征图尺寸减半。
        - `dilate`：是否用空洞卷积替代 stride 下采样（用于分割任务）。
      - 总结逻辑：
        - 每个stage由多个残差块组成。
        - 第一个块负责可能的下采样和通道变换（这里对应的就是李牧说的stage1高宽减半，通道数翻倍），并创建`downsample`捷径分支（就是李沐说的高速公路）。
        - 后续块保持输入输出一致，直接堆叠。
        - 通过`dilate`参数支持空洞卷积，用于分割任务。
        - `self.inplanes`（即李沐的`in_channels`）在第一个块后更新，确保后续块知道输入通道数。
    - `_forward_impl`、`forward`：前向传播
      - `_forward_impl`
        - 输入 `x` 依次经过：
          - Stem：`conv1 → bn1 → relu → maxpool`。（这里的**最大池化**用于**降分辨率**，提升运算效率）
          - 四个 stage：`layer1 → layer2 → layer3 → layer4`。
          - 分类头：`avgpool → flatten → fc`。
        - `torch.flatten(x, 1)` 将 `(N, C, 1, 1)` 展平为 `(N, C)`，因为 `avgpool` 输出是 1×1。
        - 返回最终分类得分。
      - `forward`
        - 直接调用`_forward_impl`，直接为了兼容`TorchScript`的`super()`调用。

## 遇到的问题/注意事项

**Stride下采样**：用**步长大于 1**的**卷积**（或**池化**）来降低特征图的空间分辨率。

官方的展平层`nn.Flatten()`定义在**前向传播函数**中，与此前我们的定义方式`x.reshape()`效果相同。

注意：`downsample`只包含**1x1卷积和BN**，**没有ReLU**。因为他是**捷径分支**，只需线性变换。
