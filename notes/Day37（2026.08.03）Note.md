系统梳理 VGG 的设计思想、Block 结构与三代经典网络的演进脉络：

- **核心知识点**：

  - **VGG 核心思想**：

    ```
    多个3×3卷积
           ↓
    替代大卷积核
           ↓
    增加网络深度
    ```

  - **为什么用小卷积核堆叠？**（相同感受野下参数量更少、非线性更强）

    | 方案 | 感受野 | 参数量（各层通道数均为 C） |
    |---|---|---|
    | 1 个 5×5 卷积 | 5×5 | 25C^2 |
    | **2 个 3×3 卷积** | 5×5 | 2 x 9C^2 = 18C^2 |
    | 1 个 7×7 卷积 | 7×7 | 49C^2 |
    | **3 个 3×3 卷积** | 7×7 | 3 x 9C^2 = 27C^2 |

    堆叠 3×3 卷积既**减少了参数量**，又因为每层卷积之间都插入 ReLU 而**增强了非线性表达能力**。

  - **VGG Block 设计思想**：把「若干个 3×3 卷积（`padding=1` 保持尺寸）+ 1 个 2×2 最大池化（尺寸减半）」打包成一个**可复用的块**，整个网络就是若干 Block 的顺序堆叠。

  - **VGG16 结构**：**13 个卷积层 + 3 个全连接层**，共 5 个 Block
  
  - **VGG19 结构**：**16 个卷积层 + 3 个全连接层**，比 VGG16 在 Block3/4/5 各多一个卷积层

#### 实验任务

创建 `VGG.py`，在 `pytorch/Day37/VGG.py` 中实现 VGG Block、按配置搭建 VGG 网络，并统计参数量：

```python
import torch
import torch.nn as nn


def vgg_block(num_convs, in_channels, out_channels):
    """VGG 块：num_convs 个 3x3 卷积（padding=1 保持尺寸）+ 1 个 2x2 最大池化"""
    layers = []
    for _ in range(num_convs):
        layers.append(nn.Conv2d(in_channels, out_channels, kernel_size=3, padding=1))
        layers.append(nn.ReLU(inplace=True))
        in_channels = out_channels          # 块内后续卷积的输入通道 = 本块的输出通道
    layers.append(nn.MaxPool2d(kernel_size=2, stride=2))   # 每个块结束后 H/W 减半
    return nn.Sequential(*layers)


def vgg(conv_arch, num_classes=1000):
    """按卷积配置列表 conv_arch 搭建 VGG 网络"""
    conv_blks = []
    in_channels = 3
    for (num_convs, out_channels) in conv_arch:
        conv_blks.append(vgg_block(num_convs, in_channels, out_channels))
        in_channels = out_channels
    return nn.Sequential(
        *conv_blks,
        nn.Flatten(),                                    # (N, 512, 7, 7) -> (N, 25088)
        nn.Linear(out_channels * 7 * 7, 4096),           # 512 * 7 * 7 = 25088
        nn.ReLU(inplace=True),
        nn.Dropout(p=0.5),
        nn.Linear(4096, 4096),
        nn.ReLU(inplace=True),
        nn.Dropout(p=0.5),
        nn.Linear(4096, num_classes),
    )


def main():
    # 卷积配置列表：(每个块的卷积层数, 输出通道数)
    conv_arch_vgg11 = ((1, 64), (1, 128), (2, 256), (2, 512), (2, 512))
    conv_arch_vgg16 = ((2, 64), (2, 128), (3, 256), (3, 512), (3, 512))

    for name, arch in (("VGG11", conv_arch_vgg11), ("VGG16", conv_arch_vgg16)):
        net = vgg(arch)
        x = torch.randn(1, 3, 224, 224)
        print("=" * 60)
        print(f"{name} 各阶段特征图尺寸：")
        with torch.no_grad():
            for i, blk in enumerate(net):
                x = blk(x)
                if i < 5:
                    print(f"  Block{i + 1} 输出: {tuple(x.shape)}")

        # 参数量统计
        total = sum(p.numel() for p in net.parameters())
        conv_params = sum(p.numel() for p in net[:5].parameters())
        fc_params = sum(p.numel() for p in net[5:].parameters())
        print(f"  总参数量: {total:,} ({total / 1e6:.1f} M)")
        print(f"  卷积部分: {conv_params:,} ({conv_params / total * 100:.1f}%)")
        print(f"  全连接部分: {fc_params:,} ({fc_params / total * 100:.1f}%)")
        print(f"  最终输出 Shape: {tuple(net(torch.randn(1, 3, 224, 224)).shape)}")


if __name__ == "__main__":
    main()
```

#### 维度推导验证（VGG16）

| 阶段 | 配置 | 输入 Shape | 输出 Shape | 计算依据 |
|---|---|---|---|---|
| 输入 | — | — | (N, 3, 224, 224) | ImageNet 图像尺寸 |
| Block1 | 2 × `Conv(3→64, k=3, p=1)` + `MaxPool(2,2)` | (N, 3, 224, 224) | (N, 64, 112, 112) | 224 / 2 = 112 |
| Block2 | 2 × `Conv(64→128, k=3, p=1)` + `MaxPool(2,2)` | (N, 64, 112, 112) | (N, 128, 56, 56) | 112 / 2 = 56 |
| Block3 | 3 × `Conv(128→256, k=3, p=1)` + `MaxPool(2,2)` | (N, 128, 56, 56) | (N, 256, 28, 28) | 56 / 2 = 28 |
| Block4 | 3 × `Conv(256→512, k=3, p=1)` + `MaxPool(2,2)` | (N, 256, 28, 28) | (N, 512, 14, 14) | 28 / 2 = 14 |
| Block5 | 3 × `Conv(512→512, k=3, p=1)` + `MaxPool(2,2)` | (N, 512, 14, 14) | (N, 512, 7, 7) | 14 / 2 = 7 |
| **展平** | `Flatten` | (N, 512, 7, 7) | (N, 25088) | 512 x 7 x 7 |
| FC1 | `Linear(25088→4096)` | (N, 25088) | (N, 4096) | — |
| FC2 | `Linear(4096→4096)` | (N, 4096) | (N, 4096) | — |
| FC3 | `Linear(4096→1000)` | (N, 4096) | (N, 1000) | 1000 个类别 |

> **一句话规律**：Block 内所有 3×3 卷积因 `padding=1` **尺寸不变**；每个 Block 末尾的 `MaxPool(2,2)` 让 H/W **减半**。
> 所以 VGG16 的尺寸链是：224 -> 112 -> 56 -> 28 -> 14 -> 7，展平维度 512 x 7 x 7 = 25088。

#### 参数量分析（重要观察）

| 部分 | 参数量 | 占比 |
|---|---|---|
| 5 个卷积 Block（13 个卷积层） | 14,714,688 | 10.6% |
| 3 个全连接层 | 123,642,856 | **89.4%** |
| **↳ 其中 FC1 一层** | **102,764,544** | **74.3%** |
| **合计** | **138,357,544** | 100% |

**结论**：VGG16 虽然卷积层多达 13 个，但**参数量 89.4% 都在全连接层**，而**第一个全连接层 `Linear(25088→4096)` 一层就占了全网的 74.3%**。

> 这与 AlexNet（全连接层占 96%）是同一个问题：**展平维度越大，第一个全连接层越臃肿**。这也是后续网络（NiN / GoogLeNet / ResNet）用**全局平均池化**替代巨型全连接层的直接动机。
>
> 另一个好处是：**卷积层的参数量与输入图像尺寸无关**（权重共享），而全连接层会随展平维度线性增长。

## 1 LeNet

### 1.1 组成部分

LeNet (LeNet-5) 由两个部分组成：**卷积编码器**（即**卷积 + 池化层**）和**全连接层密集块**（即**全连接层**）。

### 1.2 网络结构

LeNet的卷积编码器由**2个卷积层**和**2个平均池化层**构成，用于**单通道28x28图像的多分类任务**，具体定义如下：

```python
conv_net = nn.Sequential(
    # 将输入重塑为 (batch_size, 1, 28, 28) 的灰度图像格式
    Reshape(),
    # 卷积层1：输入：(N， 1， 28， 28) -> 输出：(N, 6, 28, 28)
    nn.Conv2d(1, 6, kernel_size = 5, padding = 2),
    nn.Sigmoid(),       # Sigmoid激活函数，为了引入非线性，让网络能学习复杂模式
    # 平均池化层1：输入：(N, 6, 28, 28) -> 输出：(N, 6, 14, 14)
    nn.AvgPool2d(kernel_size = 2, stride = 2),
    # 卷积层2：输入：(N, 6, 14, 14) -> 输出：(N, 16, 10, 10)
    nn.Conv2d(6, 16, kernel_size = 5),
    nn.Sigmoid(),       # Sigmoid激活函数
    # 平均池化层2：输入：(N, 16, 10, 10) -> 输出：(N, 16, 5, 5)
    nn.AvgPool2d(kernel_size = 2, stride = 2)
)
```

LeNet的全连接层密集块由**3个全连接层**构成，分别是2个隐藏层和1个输出层，具体定义如下：

```python
linear_net = nn.Sequential(
    # 全连接层1：输入：(N, 400) -> 输出：(N, 120)
    nn.Linear(16 * 5 * 5, 120),
    nn.Sigmoid(),
    # 全连接层2：输入：(N, 120) -> 输出：(N, 84)
    nn.Linear(120, 84),
    nn.Sigmoid(),
    # 输出层：输入：(N, 84) -> 输出：(N, 10)，这里的10就是最后的类别数量（如数字0-9）
    nn.Linear(84, 10)
)
```

此外，由于全连接层只能处理二维数据，而卷积层的输出是四维数据，所以在卷积编码器和全连接层密集块之间，还需要添加一层**展平层**，用于**将四维数据展平成二维数据**，具体定义如下：

```python
# 展平层：输入：(N, 16, 5, 5) -> 输出：(N, 16 * 5 * 5) = (N, 400)
nn.Flatten()
```


### 1.4 总结

- **LeNet**
  - 最早用于**手写的数字识别**
  - LeNet是早期成功的神经网络
  - 先使用**卷据层**来**学习图片空间信息**
  - 然后使用**全连接层**来**转换到类别空间**

## 2 AlexNet

### 2.1 组成部分

由于AlexNet本质上是更深更大的LeNet，所以在组成部分上与LeNet相同。AlexNet也由卷积编码器和全连接层密集块两部分组成。卷积编码器主要包含**卷积层、ReLU激活函数和最大池化层**；全连接层密集块主要包含**全连接层、ReLU激活函数和Dropout随机失活层**。

### 2.2 网络结构

由于AlexNet本质上是更深更大的LeNet，所以在结构上也与LeNet相似。

AlexNet的卷积池化层部分由5个卷积层和3个最大池化层构成，其中：第3-5个卷积层连续分布，在第1、2、5个卷积层后各添加一层最大池化层，具体定义如下：

```python
conv_net = nn.Sequential(        # nn.Sequential作用：定义神经网络，将网络层按顺序打包起来，数据会按照代码顺序，一层一层流通
    # 卷积层1：卷积计算 + ReLU激活函数
    nn.Conv2d(1, 96, 11, 4, 1),
    nn.ReLU(),
    # 池化层1：最大池化
    nn.MaxPool2d(3, 2),

    # 卷积层2：卷积计算 + ReLU激活函数
    nn.Conv2d(96, 256, 5, padding = 2),
    nn.ReLU(),
    # 池化层2：最大池化
    nn.MaxPool2d(3, 2),

    # 卷积层3-5：（卷积计算 + ReLU激活函数） * 3
    nn.Conv2d(256, 384, 3, padding = 1),
    nn.ReLU(),
    nn.Conv2d(384, 384, 3, padding = 1),
    nn.ReLU(),
    nn.Conv2d(384, 256, 3, padding = 1),
    nn.ReLU(),
    # 池化层3：最大池化
    nn.MaxPool2d(3, 2)
)
```

AlexNet的全连接层部分与LeNet类似，由**3个全连接层**构成，分别是2个隐藏层和1个输出层，具体定义如下：

```python
linear_net = nn.Sequential(
    # 隐藏层（全连接层）1：4096个输出
    nn.Linear(6400, 4096),
    nn.ReLU(),
    # Dropout层1：Dropout概率为0.5
    nn.Dropout(0.5),

    # 隐藏层（全连接层）2：4096个输出
    nn.Linear(4096, 4096),
    nn.ReLU(),
    # Dropout层2：Dropout概率为0.5
    nn.Dropout(0.5),

    # 输出层（全连接层）：10个输出（因为采用Fashion-MNIST数据集）
    nn.Linear(4096, 10)
)
```

与LeNet类似，由于全连接层只能处理二维数据，而卷积层的输出是四维数据，所以在卷积编码器和全连接层密集块之间，还需要添加一层**展平层**，用于**将四维数据展平成二维数据**，具体定义如下：

```python
# 展平层：将多维的输入展平成一维 (N, 256, 5, 5) -> (N, 256 * 5 * 5)
nn.Flatten()
```

### 2.3 细节

在AlexNet中，为了**减缓梯度消失**，激活函数从Sigmoid变为**ReLU**，并且**在隐藏全连接层后加入了Dropout层**，还采用了**数据增强**，如在训练中模拟实际中可能会出现的变化，从而改善训练效果。此外，在池化层方面改用了**MaxPooling最大池化**。

## 3 VGG

### 3.1 设计思想

由于LeNet和AlexNet的框架都相对杂乱，因此VGG的设计思想就是**让整个框架更加规则**，于是出现了**VGG块**。

### 3.2 优化思路

VGG的优化思路就是**将卷积层组合成块**添加到网络中，也就是VGG块。

**VGG块**由n个3x3卷积核（填充1）（n层，m通道）和1个2x2最大池化层（步长2）组成。通过通过不断地训练总结，我们发现：卷积层设置**深但窄**效果更好。所以VGG块中的卷积核采用了3x3的大小，而AlexNet是11x11，LeNet是5x5。

### 3.3 网络结构

由于VGG块就是由卷积层和池化层组成，所以VGG的网络结构就是由VGG块和全连接层构成，在多个VGG块后接全连接层。不同次数的重复块得到不同的架构，如：VGG-16、VGG-19等。下面是VGG块的具体定义：

```python
# 定义VGG块结构
# 参1：卷积核个数；参2：输入通道数；参3：输出通道数
def vgg_block(num_convs, in_channels, out_channels):
    layers = []
    for _ in range(num_convs):
        layers.append(nn.Conv2d(
        	# 3x3卷积（填充1）（n层，m通道）
            in_channels, out_channels, kernel_size = 3, padding = 1))
        layers.append(nn.ReLU())            # ReLU激活函数
        in_channels = out_channels
    # 2x2最大池化层（步长2）
    layers.append(nn.MaxPool2d(kernel_size = 2, stride = 2))
    return nn.Sequential(*layers)
```

在多个VGG块后接全连接层就构成了VGG的基本架构，因此VGG整体定义如下：

```python
def vgg(conv_arch):
    conv_blks = []
    in_channels = 1
    for (num_convs, out_channels) in conv_arch:		# 添加len(conv_blks)个VGG块
        conv_blks.append(vgg_block(
            num_convs, in_channels, out_channels))      # 经典设计：通道数翻倍，高宽减半
        in_channels = out_channels

    return nn.Sequential(
        *conv_blks, nn.Flatten(),       # 展平层
        # 隐藏层1（输入维度：7 x 7 x out_channels，输出维度：4096）
        nn.Linear(out_channels * 7 * 7, 4096), nn.ReLU(),
        # 隐藏层2（输入维度：4096，输出维度：4096），ReLU激活函数，Dropout层（p = 0.5）
        nn.Dropout(0.5), nn.Linear(4096, 4096), nn.ReLU(),
        # 输出层（输入维度：4096，输出维度：10）
        nn.Dropout(0.5), nn.Linear(4096, 10))
```

### 3.4 不足

相比起LeNet和AlexNet，VGG的全连接层参数量大幅增加，所以VGG网络**比较占用内存**。

同时，VGG作为2013年的产物较现在已经落后了许多。所以与新网络相比，VGG在性能和精度上都不占优势。
