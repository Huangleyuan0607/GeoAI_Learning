#### 实验任务

创建 `numpy_array_demo.py` 文件。手工编写并运行以下代码，前半部分完成 NumPy 数组创建、切片与基础数据预处理练习，后半部分演示 Tensor 与 NumPy 数组之间的相互转换：  

```python
# -*- coding: utf-8 -*-
"""
程序名称：numpy_array_demo.py
作者：黄乐源
日期：2026-07-13
描述：NumPy 数组基础操作、数据预处理与 PyTorch Tensor 相互转换实战，开启第二阶段深度学习入门
"""

import numpy as np
import torch

print("================= 任务 1：NumPy 数组创建、属性查看与索引切片 =================")

# 1. 创建模拟遥感高程/像元数据的二维 ndarray
geo_data = np.array([
    [102.5, 105.0, 110.2],
    [98.0,  100.5, 104.8],
    [95.2,  97.1,  99.6]
], dtype=np.float32)

print(f"📡 遥感数组内容:\n{geo_data}")
print(f"📐 数组维度(ndim): {geo_data.ndim} | 形状(shape): {geo_data.shape} | 数据类型(dtype): {geo_data.dtype}")

# 2. 数组索引与切片练习：提取右上角 2x2 子区域
sub_region = geo_data[0:2, 1:3]
print("\n🔍 提取右上角 2x2 高程子区域切片:")
print(sub_region)

# 3. 基础数值预处理：模拟缺失值替换与标准化处理
raw_val = np.array([10.0, 20.0, np.nan, 40.0], dtype=np.float32)
print(f"\n⚠️ 原始数据包含缺失值(NaN): {raw_val}")
# 使用均值填充 NaN 缺失值
nan_mask = np.isnan(raw_val)
mean_val = np.nanmean(raw_val)
raw_val[nan_mask] = mean_val
print(f"✅ 缺失值填充后数据: {raw_val}")


print("\n================= 任务 2：PyTorch Tensor 创建与 NumPy 数组相互转换 =================")

# 1. 使用 torch.arange 与 torch.zeros 创建基础 Tensor
x_tensor = torch.arange(12, dtype=torch.float32).reshape((3, 4))
print(f"🔥 创建的 PyTorch Tensor (3x4):\n{x_tensor}")
print(f"📊 Tensor 元素总数(numel): {x_tensor.numel()} | 形状(shape): {x_tensor.shape}")

# 2. NumPy ndarray 转换为 PyTorch Tensor
np_array = np.ones((2, 3), dtype=np.float32)
converted_tensor = torch.from_numpy(np_array)
print(f"\n🔄 从 NumPy 转换为 Tensor:\n{converted_tensor}")

# 3. PyTorch Tensor 转回 NumPy ndarray
back_to_numpy = converted_tensor.numpy()
print(f"🔄 从 Tensor 转回 NumPy 数组:\n{back_to_numpy}")

# 4. 验证内存共享（修改原 NumPy 数组观察 Tensor 变化）
np_array[0, 0] = 99.0
print(f"\n🧠 修改原 NumPy 数组后，共享内存的 Tensor 相应变为:\n{converted_tensor}")

print("\n🏁 Day16 NumPy 数组基础与 Tensor 互转测试完毕，第二阶段深度学习顺利启航！")
```

## 今日收获

**Numpy入门-15 Numpy_属性介绍**：

**NumPy(NumericalPython)**：是Python数据分析必不可少的第三方库，它的出现一定程度上解决了Python运算性能不佳的问题，同时提供了更加精确的数据类型，使其具备了**构造复杂数据类型**的能力。

NumPy重在**数值计算**，主要用于**多维数组（矩阵）处理**的库。用来**存储和处理大型矩阵**，比Python自身的嵌套列表结构要高效的多。

NumPy**重要功能**如下:

1、高性能科学计算和数据分析的基础包（pandas包的底层就需要numpy）；
2、ndarray，多维数组，具有**矢量运算**能力，快速、节省空间；
3、**矩阵运算**，无需循环，可完成类似Matlab中的矢量运算；
4、用于**读写磁盘数据**的工具以及用于**操作内存映射文件**的工具。

NumPy的**数组类**被称作**ndarray**，通常被称作**数组**。

ndarray**对象属性**有:

1、ndarray. ndim 维度（几层嵌套）；
2、ndarray. shape 形状（几行几列）；
3、ndarray. size 元素数量；
4、ndarray. dtype 数据类型；
5、ndarray.itemsize 元素大小。

数组的**维度**。这是一个指示数组在每个维度上大小的整数元组。例如一个n排m列的矩阵，它的shape属性将是(2,3)，这个元组的长度显然是秩，即维度或者rdim属性。
