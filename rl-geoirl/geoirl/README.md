## 三条硬规矩

1. **不要在 `DayNN/` 里复制一份 `soft_policy`。** 一旦复制，G16 的四网络对比就是在比四个不同的算法。
2. **签名一旦定下不要改。** 要改就一次改完所有调用点（G03 定 `irl.py`，G08 会给它加一个 `mode` 参数用于归一化——这是唯一预告过的改动）。
3. **每个模块文件顶部写一行它对应论文的哪一节**，这样 G14 精读时能直接按节反查代码。
