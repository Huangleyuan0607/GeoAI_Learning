### 第二阶段：理论学习（约45分钟）

**1. 从N02的蒙特卡洛方法接到Bellman更新（约15分钟）**

从同一栋建筑出发，MC可以采样很多次，把每次的后续回报取平均来估计价值。已知转移概率和奖励时，还可以直接把各种下一状态的价值按概率加权，不必先采样大量完整序列。

固定策略π后，把动作选择的影响合并进转移矩阵P^π和期望即时奖励r^π：

$$
V^\pi(s)=r^\pi(s)+\gamma\sum_{s'}P^\pi(s,s')V^\pi(s')
$$

| 符号 | 含义 | 本日测试对应 |
| --- | --- | --- |
| s、s′ | 当前状态、下一状态 | 建筑A、建筑B |
| r^π(s) | 按固定策略行动时，当前状态的期望即时奖励 | reward=[0, 1]；本例奖励只依赖当前建筑 |
| P^π(s,s′) | 该策略下从s到s′的概率 | P=[[0, 1], [1, 0]] |
| γ | 后续奖励的折扣因子 | gamma=0.5，仅用于本日合成例子 |
| V^π(s′) | 从下一状态继续行动的期望回报 | 每一轮使用上一轮的估计 |

把所有建筑的价值写成向量，可以反复计算：

$$
v^{(k+1)}=r+\gamma Pv^{(k)}
$$

这是固定策略下的迭代评估。**反复更新价值，不等于一定在优化策略**；策略评估中的π保持不变。

| 方法 | 主要操作 | 本日需要掌握到什么程度 |
| --- | --- | --- |
| 策略评估 | 固定π，求V^π | P0：理解公式，能手算并读懂更新代码 |
| 策略提升 | 根据现有价值，选更好的动作 | P0：联系N02笔记，解释贪心选择；完整实现P1 |
| 策略迭代 | 交替评估与提升 | P0：理解循环关系，不额外重写环境 |
| 价值迭代 | 用Bellman最优更新，对动作取max | P0：能指出与固定策略评估的区别；完整环境运行P1 |

**2. 手算两栋建筑之间的价值（约15分钟）**

假设智能体在建筑A、B之间交替访问，每次领取当前建筑的状态奖励：A为0，B为1。这个合成例子没有终止状态，γ=0.5，所以无限累积回报仍然有限。它与N02有限三步、最后结束的例子不同。

```text
建筑A（奖励0） → 建筑B（奖励1） → 建筑A → 建筑B → ……
```

标准固定策略价值满足：

$$
V_A=0+0.5V_B,\qquad V_B=1+0.5V_A
$$

联立后：

$$
V_A=\frac{2}{3},\qquad V_B=\frac{4}{3}
$$

从v⁽⁰⁾=[0, 0]开始同步更新，两种算子的前三轮如下。先遮住结果手算，再核对。

| 轮次 | 标准更新 r＋γPv | 作者更新 r＋mean(γPv) |
| --- | --- | --- |
| 0，初值 | [0, 0] | [0, 0] |
| 1 | [0, 1] | [0, 1] |
| 2 | [0.5, 1] | [0.25, 1.25] |
| 3 | [0.5, 1.25] | [0.375, 1.375] |
| 各自极限 | [2/3, 4/3] | [0.5, 1.5] |

每轮都用同一份旧向量更新所有状态。停止条件是相邻两轮最大绝对变化小于eps，不是价值必须等于0，也不是标准结果必须等于作者结果。

**3. 对照论文源码中的average及调用位置（约15分钟）**

作者函数中的核心计算是：

```python
q = discount * (transition @ v)
v = reward + np.average(q, axis=0)
```

本日transition形状为(2, 2)，v和reward均为(2,)。因此q是长度为2的向量；`np.average(q, axis=0)`把两个元素平均成一个标量，再通过广播加到两栋建筑的奖励上。

令极限为v=[c, 1+c]，则：

$$
c=\frac{0.5(1+c)+0.5c}{2}=0.25+0.5c
$$

所以c=0.5，得到[0.5, 1.5]。差异来自**逐状态保留后续价值**与**平均成公共标量**这两种更新方式，不是多迭代几次就能消除。

源码里的变量`q`在本例中是每个状态的折扣后续价值向量，没有独立动作维度，不能仅凭变量名就当作完整Q(s,a)表。

#### 参考代码

```python
"""
来源：论文官方开源代码 geoirl-official
原始文件：causal_maxent.py
函数名：stochastic_value_iteration

描述：
    原样节选作者函数的计算逻辑，增加中文注释。
    用同一组两状态输入，对照标准Bellman评估和作者更新。

数学公式：
    标准评估：v_new = r + gamma * (P @ v_old)。
    作者更新：v_new = r + mean(gamma * (P @ v_old))。
    P形状为(2, 2)，r和v形状为(2,)，作者mean得到公共标量。

本日输入：
    P = [[0, 1], [1, 0]]，r = [0, 1]，gamma = 0.5。
    标准解为[2/3, 4/3]，作者固定点为[0.5, 1.5]。

注意：
    这是固定策略下的小矩阵对照，不求最优动作，不学习奖励。
    仅节选函数，不导入官方模块，不修改原文件，不读写实验数据。
"""


# 导包：本日只需要NumPy
import numpy as np


# 1.作者原函数：仅增加注释，计算语句及默认参数与官方一致
def stochastic_value_iteration(transition, reward, discount, eps=1e-5):
    n_states = transition.shape[0]
    v = np.zeros(n_states)

    delta = np.inf
    while delta > eps:
        # 1.保留本轮更新前的向量
        # 后面的 v = reward + ... 会生成新数组，因此这里不会改掉 v_old
        v_old = v

        # 2.按转移矩阵加权后续价值，再乘折扣
        # transition 是 (2, 2)，v 是 (2,)，所以 q 是 (2,)
        q = discount * (transition @ v)

        # 3.axis=0在一维q上取平均，结果是一个标量
        # 标量广播到reward的每一项，这一步与标准逐状态更新不同
        v = reward + np.average(q, axis=0)

        # 4.取各状态变化绝对值的最大值，作为停止判断
        delta = np.max(np.abs(v_old - v))

    return v


# 2.测试入口：先检查输入，再逐轮对照，最后分别验证固定点
def main():
    np.set_printoptions(precision=6, suppress=True)

    # 1.构造两栋建筑交替访问的合成例子，默认使用float64
    # reward是当前建筑的状态奖励；没有终止建筑，未来回报由gamma折扣
    transition = np.array([[0.0, 1.0], [1.0, 0.0]])
    reward = np.array([0.0, 1.0])
    gamma = 0.5
    eps = 1e-10
    max_iter = 1000

    # 2.形状和概率检查，避免(2,)与(2, 1)广播出不同计算
    assert transition.shape == (2, 2)
    assert reward.shape == (2,)
    assert np.isfinite(transition).all() and np.isfinite(reward).all()
    assert (transition >= 0).all()
    np.testing.assert_allclose(transition.sum(axis=1), [1.0, 1.0])
    assert 0 <= gamma < 1

    print("transition:\n", transition)
    print("reward:", reward, "gamma:", gamma, "eps:", eps)

    # 3.只跟踪前三轮，分别保留两种更新各自的旧向量
    # copy保证同步更新；本段用于手算对照，不代替下面的收敛检查
    standard_trace = np.zeros(2)
    author_trace = np.zeros(2)
    for step in range(1, 4):
        old_standard = standard_trace.copy()
        old_author = author_trace.copy()
        standard_trace = reward + gamma * (transition @ old_standard)
        author_q = gamma * (transition @ old_author)
        shared_term = np.average(author_q, axis=0)
        assert np.ndim(shared_term) == 0, "本例平均项应为标量"
        author_trace = reward + shared_term
        print(
            f"step {step}: standard={standard_trace}; "
            f"author={author_trace}; shared term={shared_term:.6f}"
        )

    # 4.标准Bellman迭代评估：每个状态保留自己的后续价值
    # max_iter只限制这里自写的标准对照，未改变作者函数
    standard = np.zeros(2)
    for iteration in range(1, max_iter + 1):
        old_standard = standard.copy()
        standard = reward + gamma * (transition @ old_standard)
        delta = np.max(np.abs(standard - old_standard))
        if delta <= eps:
            break
    else:
        raise RuntimeError("标准评估未在限定轮数内收敛")

    # 5.用线性方程独立检查标准结果
    # v = r + gamma*P@v → (I-gamma*P)@v = r
    # solve直接求方程解，本日不需要展开矩阵求逆推导
    exact_standard = np.linalg.solve(np.eye(2) - gamma * transition, reward)
    manual_standard = np.array([2.0 / 3.0, 4.0 / 3.0])
    np.testing.assert_allclose(standard, exact_standard, atol=1e-8, rtol=1e-8)
    np.testing.assert_allclose(standard, manual_standard, atol=1e-8, rtol=1e-8)

    # 6.调用原样节选的作者函数，不把标准公式替换进去
    # 本日固定小输入、行随机矩阵和gamma=0.5用于受控验证
    author = stochastic_value_iteration(transition, reward, gamma, eps=eps)
    manual_author = np.array([0.5, 1.5])
    np.testing.assert_allclose(author, manual_author, atol=1e-8, rtol=1e-8)
    assert standard.shape == author.shape == (2,)
    assert np.isfinite(standard).all() and np.isfinite(author).all()

    # 7.分别代回各自更新式，检查固定点残差
    # 残差小表示满足各自方程，不代表两种方程相同
    standard_residual = np.max(
        np.abs(standard - (reward + gamma * (transition @ standard)))
    )
    author_residual = np.max(
        np.abs(author - (reward + np.average(gamma * (transition @ author))))
    )
    assert standard_residual < 1e-8
    assert author_residual < 1e-8
    assert not np.allclose(standard, author, atol=1e-6, rtol=1e-6)

    # 8.打印可复查结果；不生成图表、缓存或模型文件
    print("standard iterations:", iteration)
    print("standard value:", standard)
    print("standard exact:", exact_standard)
    print("author value:", author)
    print("standard residual:", standard_residual)
    print("author residual:", author_residual)
    print("author - standard:", author - standard)
    print("All assertions passed.")


# 3.直接运行文件时执行测试；导入时不自动执行
if __name__ == "__main__":
    main()
```
