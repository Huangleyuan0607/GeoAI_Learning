#### 学习笔记

**《动手学强化学习》第 14 章 SAC算法：最大熵强化学习**：

- **熵（Entropy）**

  - **定义**：

    - 表示**对一个随机变量的随机程度的度量**。具体而言，如果 `X` 是一个随机变量，且它的概率密度函数为 `p`，那么它的熵 `H`就被定义为：
      $$
      H(X) = \mathbb{E}_{x \sim p}[-\log p(x)]
      $$
      即概率越小的事件发生，带来的“惊讶度”越高，即 `−log⁡p(x)` 越大。

    - 直觉：对一个随机变量不确定性的度量。概率分布越均匀（比如掷骰子），熵越大；概率越集中（比如硬币只有正面朝上），熵越小（趋近于0）。

    - 在强化学习中，我们可以使用 `H(π(⋅∣s))` 来表示策略 `π` 在状态 `s` 下的随机程度。

  - **策略的熵 `H(π(⋅∣s))`**：

    - 代表在状态 `s` 下，智能体选择动作的**随机程度**。
    - 如果智能体100%选向左，熵为0；如果上下左右各25%概率，熵最大。

- **最大熵强化学习（Maximum Entropy RL，即MaxERL）**

  - **传统 RL 的痛点**：

    - 容易出现“赢家通吃”，策略往往死盯住某一个局部最优解，**探索（Exploration）能力不足**。

  - **核心思想**：

    - 除了要**最大化累积奖励**，还要使得**策略更加随机**。

      - 举例：在能拿高分的几个动作里，不要只选一个，要把概率分给它们；甚至适当地给一些当前看起来没那么好的动作一点机会。因为“未知”往往意味着“潜力”，保留多样性就是保留未来的可能性。

    - 如此，强化学习的目标中就加入了一项**熵的正则项**，定义为
      $$
      \pi^* = \arg\max_{\pi} \mathbb{E}_{\pi} \left[ \sum_t r(s_t, a_t) + \alpha H(\pi(\cdot|s_t)) \right]
      $$
      其中，`α` 是一个正则化的系数，用来控制熵的重要程度。公式拆解：

      `∑t r(s_t, a_t)`：最大化奖励。

      `αH(π(⋅∣s_t))`：**新增的正则项**，最大化熵（策略的随机性）。

    - **系数 `α` 的作用**：

      - 控制“探索”与“利用”的权重。
      - `α=0`：退化为传统 RL。
      - `α` 越大：越强调探索（随机性），越不看重眼前的局部最优。

- **传统**强化学习和**最大熵**强化学习

  - 熵正则化增加了强化学习算法的探索程度，越大，探索性就越强，有助于加速后续的策略学习，并减少策略陷入较差的局部最优的可能性。传统强化学习和最大熵强化学习的区别如下图所示。

    <img src="D:\CCNU\PreLearning_Plan\GeoAI-Learning\rl-geoirl\notes\Screenshot\N04\N04_两种强化学习的区别.png" alt="N04_两种强化学习的区别" style="zoom:80%;" />

    - **左图（传统强化学习）**：
      - 红色的 π 分布，仅仅局限于最高的那个青色 Q 值峰（主峰）。它是个**“单峰”**分布。即使旁边有略微低一点点的峰，它也完全放弃（概率为0）。
        - **绝对理智，毫无随机**：一旦智能体发现“动作 A”得分最高（主峰），它就会 100% 选择动作 A（概率为 1）。这种策略的“熵”极低，因为它极度确定。
        - **致命的弱点**：它完全放弃了其他选项。如果有一天环境变了，主峰突然塌了（比如原本走得通的路突然出现障碍），这个只会一招的智能体会瞬间傻眼，因为它从来没有尝试过旁边的动作。
        - **容易陷入局部最优**：如果主峰其实不是最高的，只是个“局部最高”的坑，它也会因为这种死板而一辈子困在里面。
    - **右图（最大熵强化学习）**：
      - 黄色的 π 分布，不仅覆盖了最高的主峰，**还蔓延到了旁边次高的副峰**。它变成了一个**“多峰”**或**“宽平”**的分布。
        - **拥抱不确定性（高熵）**：智能体不再“全押”在一个动作上。它的策略分布变成多峰的、平滑的。这就是公式里 `+ αH(π)` 起的作用。
        - **超强的鲁棒性**：因为它在“次好”的动作上也保留了概率，所以即使主峰因为环境变化被毁（或者发现主峰其实是个陷阱），智能体随时可以切换到副峰策略，立刻适应新环境。
        - **更充分的探索**：这种被强行“抹平”的策略，相当于在持续不断地做探索。如果副峰底下其实藏着更大的矿（全局最优），智能体总有一天会误打误撞发现它。
    - **对比**：传统 RL 的策略是**尖峰的（低熵）**，死磕最高价值动作，容易一条道走到黑；最大熵 RL 的策略是**宽平的（高熵）**，在最高价值附近保留了次优动作的概率，增强了探索能力和抗风险能力。
    - **结论**：在最大熵强化学习中，策略不再具有唯一性。这种平滑的策略具有很强的鲁棒性，一旦主峰环境变差（比如突然走不通了），它能立刻切换到副峰策略。这就叫**“保留行动多样性”**。

- **总结**：

  - 最大熵强化学习（MaxEnt RL）就是在传统 RL 的目标里加了一个 `+ α * 熵`。它教会智能体：**“就算你现在觉得某条路最好，也记得留一点概率给其他看起来也不错的备选路”**，以防止环境变化时“一根筋”走到黑。

**《动手学强化学习》第 14 章 SAC算法：Soft策略迭代**：

- **核心差异：从“硬平均”到“软平均”**
  - **传统 V(s)**：`V = E[Q]`。哪个动作的 `Q` 值高，最终算出来的 `V` 就高。动作的概率（`π`）只是个权重。
  - **Soft V(s)**：`V = E[Q−αlog⁡π]`。
    - **物理直觉**：智能体在评估一个状态好不好时，不仅要看动作的客观得分（`Q`），还要看这个动作的**“犹豫程度”**（`−log⁡π`）。
    - 如果一个动作概率极低（`π` 很小），`−log⁡π` 就会变成一个巨大的正数，减去它，`V` 就变小了。意思是：**“如果我选了一个极小概率的偏门动作，哪怕它 `Q` 值高，我心里也会觉得不踏实（惩罚）。”**

- **策略概率选择的关系（如何改进行动？）**

  - **传统策略改进（硬贪心）**：`π_new=arg⁡max⁡Q`。除了 `Q` 值最高的那个动作，其他动作概率全给 0。

  - **Soft 策略改进（软分配）**：**策略概率与 `Q` 值呈指数成正比**。

    - 结论公式：
      $$
      πnew(a∣s)∝exp⁡(1αQ(s,a))
      $$

    - **通俗理解**：`Q` 值越高的动作，分配的概率越大；`Q` 值稍微低一点的，**依然会分到一定的概率**。这就是所谓的“保留行动多样性”。

* **`α`（温度系数）是怎么控制概率的？**
  * 把 `α` 想象成“温度”。
  * **`α` 很大（高温）**：除以 `α` 后，`Q` 值的差距被抹平了。概率分布非常**均匀**（大家概率差不多），探索性极强。
  * **`α` 很小（低温）**：除以 `α` 后，指数爆炸。`Q` 值最高的动作概率趋近于 1，其他趋近于 0。退化成传统强化学习的“死板”策略（当 `α` 很小的时候，公式就近似于传统 V(s) 的 `V = E(Q)` 了）。

- **总结**：
  - Soft 策略迭代 = **Soft 策略评估**（在算 V 的时候，把动作的不确定性/熵作为惩罚项扣掉） + **Soft 策略提升**（在选动作时，不选“唯一最大”，而是根据 Q 值大小“按比例分配概率”，Q 值越大，分到的概率越大）。

**1. 从硬选择到Soft选择（约8分钟）**

从宿舍出发，教学楼和图书馆都可能是合理目的地。只选最高分会把行为压成一种选择；Soft选择让高分行动更常见，同时保留其他行动的概率。

给两个动作打分q=[0, 1]，最简单的softmax为：（注：exp(a)求的是e^a的值）

$$
\pi_j=\frac{\exp(q_j)}{\sum_k\exp(q_k)}
$$

得到[1/(1+e), e/(1+e)]，约[0.268941, 0.731059]。这里q是用于说明概率变换的分数，不先假定它一定等于教材标准Q函数。

熵衡量分布的随机程度：

$$
H(\pi)=-\sum_j\pi_j\log\pi_j
$$

例如[1, 0]只会选一个动作，熵为0；[0.5, 0.5]更不确定，熵为ln2，约0.693。取0log0=0。最大熵思想不是要求所有行为始终均匀随机，而是在回报与多样性之间权衡；本文学习奖励，本日不训练SAC。

logsumexp是log(各分数的指数之和)，例如：

$$
v=\log(\exp(0)+\exp(1))=\log(1+e)
$$

再算exp(q_j-v)，就得到上面的两个概率。代码用logsumexp稳定地计算这一关系；不是先把所有动作简单取平均。

**2. 手算普通行动与停止选项（约10分钟）**

#### 学习笔记

**熵、softmax与logsumexp的关系**：

- **三者关系**：
  - Softmax 是用来生成概率的“执行者”；熵是用来评价概率分布好坏的“监督者”；而 logsumexp 则是连接两者、计算 Soft 状态价值的“核心计算器”。
    - **Softmax 负责“转概率”**
    - **熵负责“算多样性”**
    -  **logsumexp 负责“算 Soft 价值”**

**IRL训练内部概率与N03生成策略的区别**：

- IRL训练内部概率用于**计算模型访问量**，并通过与专家目标的差异**学习奖励**；
- 生成策略则利用学得的奖励**重新构造行动概率**，用于后续**轨迹采样**；
- 两者用途、计算公式和终止处理不同，需要分别核对。

#### 参考代码

```python
"""
来源：论文官方开源代码 geoirl-official
原始文件：causal_maxent.py
函数名：local_causal_action_probabilities

描述：
    节选IRL训练内部的行动概率计算，保留计算逻辑，增加中文注释。
    用两状态、discount = 0的例子，区分普通行动和停止选项。

数学公式：
    普通行动分数：q = reward + discount * P * v_old。
    合并停止项后：v_i = log(sum(exp(各选项分数)))。
    返回普通行动：p_ij = exp(q_ij - v_i)，不返回停止列。

本日输入：
    P = [[0, 1], [1, 0]]，reward = [0, 1]，terminal = [1]。
    非终止行分母为1+e，允许停止行分母为2+e。

注意：
    discount = 0只关闭后续项，reward始终固定，不用v_old替代。
    本例只测试部分状态允许停止；不进行IRL训练或轨迹生成。
"""


# 导包
import math
import torch as t


# 1.源代码函数：计算训练内部的局部行动概率
def local_causal_action_probabilities(p_transition, terminal, reward, discount, eps = 1e-5):
    """
        参数：
            p_transition: 转移矩阵，形状为 (状态数, 状态数)
            terminal: 允许停止的状态索引，本例为整型张量[1]
            reward: 建筑即时奖励向量，本例形状为 (2, )
            discount: 后续项的折扣，本例固定为0
            eps: 两轮v变化量的停止阈值

        返回值：
            普通行动概率矩阵，形状为 (状态数, 状态数)
            停止项参与分母，但没有作为额外一列返回
    """
    n_states, n_actions = p_transition.shape

    # 1.保留原函数的两个分支；本日只有状态1允许停止，进入else
    if len(terminal) == n_states:
        reward_terminal = t.tensor(terminal).float()
    else:
        reward_terminal = -1e20 * t.ones(n_states)       # 大负数近似屏蔽停止选项
        reward_terminal[terminal] = 0.0                # 状态1的停止分数设为0

    v = -1e20 * t.ones(n_states)                       # 初始价值向量，本例形状 (2, )
    delta = 1e20                                      # 初始误差，保证第一次进入循环

    while delta > eps:
        # 2.保留旧价值；reward始终是输入的即时奖励，不随本轮v变化
        v_old = v
        v = reward_terminal

        # 3.逐元素乘法，reward和v_old都沿列广播，不是P @ v_old
        # discount = 0时，每行q均为[0, 1]，形状为 (2, 2)
        q = reward + discount * p_transition * v_old

        # 4.停止分数变为列向量，与两个普通行动拼接
        # (2, 1)与(2, 2)拼成(2, 3)，第0列是停止选项
        v = t.cat([v.unsqueeze(1), q], 1)
        v = t.logsumexp(v, 1)                         # 沿每行三个选项计算，返回 (2, )
        delta = t.max(t.abs(v - v_old))

    # 5.q.T - v先按列广播，转置回来后相当于每行减去自己的v_i
    # 指数化得到普通行动概率，不包含之前拼接的停止列
    return t.exp((q.T - v).T)


# 2.测试主函数：观察奖励怎样影响行动概率，以及停止选项的作用
def main():
    t.set_printoptions(precision = 6, sci_mode = False)

    transition = t.tensor(
        [[0.0, 1.0],
         [1.0, 0.0]],
        dtype = t.float32
    )
    reward = t.tensor([0.0, 1.0], dtype = t.float32)
    terminal = t.tensor([1], dtype = t.long)
    discount = 0.0       # 按N04安排，先关闭后续项，观察奖励与停止选项

    # 调用原函数：每行是当前建筑，每列是候选目的建筑
    with t.no_grad():
        probabilities = local_causal_action_probabilities(
            transition, terminal, reward, discount
        )

    print("建筑奖励：", reward)
    print("允许停止的建筑：", terminal)
    print("普通行动概率：\n", probabilities)
    print("普通行动行和：", probabilities.sum(dim = 1))
    print("停止概率余量：", 1.0 - probabilities.sum(dim = 1))

    # 只交换两栋建筑的奖励，观察行动倾向是否随之改变
    changed_reward = t.tensor([1.0, 0.0], dtype = t.float32)

    with t.no_grad():
        changed_probabilities = local_causal_action_probabilities(
            transition, terminal, changed_reward, discount
        )

    print("\n交换奖励后：", changed_reward)
    print("新的普通行动概率：\n", changed_probabilities)
    print("概率变化：\n", changed_probabilities - probabilities)


# 3.测试
if __name__ == "__main__":
    main()
```
