### 第二阶段：理论学习（约25分钟）

**1. 从硬选择到Soft选择（约8分钟）**

从宿舍出发，教学楼和图书馆都可能是合理目的地。只选最高分会把行为压成一种选择；Soft选择让高分行动更常见，同时保留其他行动的概率。

给两个动作打分q=[0, 1]，最简单的softmax为：

$$
\pi_j=\frac{\exp(q_j)}{\sum_k\exp(q_k)}
$$

得到[1/(1+e), e/(1+e)]，约[0.268941, 0.731059]。这里q是用于说明概率变换的分数，不先假定它一定等于教材标准Q函数。

熵衡量分布的随机程度：

$$
H(\pi)=-\sum_j\pi_j\log\pi_j
$$

例如[1, 0]只会选一个动作，熵为0；[0.5, 0.5]更不确定，熵为ln2，约0.693。取0log0=0。最大熵思想不是要求所有行为始终均匀随机，而是在回报与多样性之间权衡；本文学习奖励，本日不训练SAC。

logsumexp是log(各分数的指数之和)，例如：

$$
v=\log(\exp(0)+\exp(1))=\log(1+e)
$$

再算exp(q_j-v)，就得到上面的两个概率。代码用logsumexp稳定地计算这一关系；不是先把所有动作简单取平均。

**2. 手算普通行动与停止选项（约10分钟）**

本日使用两栋合成建筑，P=[[0, 1], [1, 0]]，reward=[0, 1]，终止集合terminal=[1]，discount=0。状态0没有可用的停止选项，状态1有一个分数为0的停止选项。

作者的q计算为：

$$
q=reward+discount\times P\times v_{old}
$$

这里是逐元素乘法，不是N03的矩阵乘法`P @ v`。一维reward和v_old沿列广播；设discount=0后，后续项消失，两行的普通行动分数都是[0, 1]，reward本身没有变成0。

| 当前状态 | 分母中的选项 | 普通行动概率 | 停止概率 | 普通行动行和 |
| --- | --- | --- | --- | --- |
| 0，非终止状态 | exp(0)+exp(1)=1+e | [1/(1+e), e/(1+e)] | 约0 | 约1 |
| 1，允许停止 | exp(0)+exp(0)+exp(1)=2+e | [1/(2+e), e/(2+e)] | 1/(2+e) | 约0.788058 |

状态1的两个普通行动约为[0.211942, 0.576117]，停止概率约0.211942。**普通行动加停止才合计为1**。

源码用-1e20近似屏蔽非终止状态的停止项，在本例float32计算中，其指数概率为0。函数只返回普通行动矩阵，没有把停止项作为额外一列返回；因此不能把每行和小于1都判成错误，也不能直接把返回矩阵重新归一化后再做同一个测试。

还有两点需要区分：

- terminal=[1]在这个函数中给状态1增加停止选项，并不是在这里强制把该行所有普通行动置零；访问量传播阶段怎样处理终止行，留到N05核对。
- P[0, 0]和P[1, 1]虽然为0，本日输出这两个位置仍为正。源码没有在最终指数概率中显式用零边屏蔽；本例discount=0尤其容易观察。这里只验证本例，不据此推断全部出行规则。

#### 参考代码

```python
"""
来源：论文官方开源代码 geoirl-official
原始文件：causal_maxent.py
函数名：local_causal_action_probabilities

描述：
    节选IRL训练内部的行动概率计算，保留计算逻辑，增加中文注释。
    用两状态、discount = 0的例子，区分普通行动和停止选项。

数学公式：
    普通行动分数：q = reward + discount * P * v_old。
    合并停止项后：v_i = log(sum(exp(各选项分数)))。
    返回普通行动：p_ij = exp(q_ij - v_i)，不返回停止列。

本日输入：
    P = [[0, 1], [1, 0]]，reward = [0, 1]，terminal = [1]。
    非终止行分母为1+e，允许停止行分母为2+e。

注意：
    discount = 0只关闭后续项，reward始终固定，不用v_old替代。
    本例只测试部分状态允许停止；不进行IRL训练或轨迹生成。
"""


# 导包
import math
import torch as t


# 1.源代码函数：计算训练内部的局部行动概率
def local_causal_action_probabilities(p_transition, terminal, reward, discount, eps = 1e-5):
    """
        参数：
            p_transition: 转移矩阵，形状为 (状态数, 状态数)
            terminal: 允许停止的状态索引，本例为整型张量[1]
            reward: 建筑即时奖励向量，本例形状为 (2, )
            discount: 后续项的折扣，本例固定为0
            eps: 两轮v变化量的停止阈值

        返回值：
            普通行动概率矩阵，形状为 (状态数, 状态数)
            停止项参与分母，但没有作为额外一列返回
    """
    n_states, n_actions = p_transition.shape

    # 1.保留原函数的两个分支；本日只有状态1允许停止，进入else
    if len(terminal) == n_states:
        reward_terminal = t.tensor(terminal).float()
    else:
        reward_terminal = -1e20 * t.ones(n_states)       # 大负数近似屏蔽停止选项
        reward_terminal[terminal] = 0.0                # 状态1的停止分数设为0

    v = -1e20 * t.ones(n_states)                       # 初始价值向量，本例形状 (2, )
    delta = 1e20                                      # 初始误差，保证第一次进入循环

    while delta > eps:
        # 2.保留旧价值；reward始终是输入的即时奖励，不随本轮v变化
        v_old = v
        v = reward_terminal

        # 3.逐元素乘法，reward和v_old都沿列广播，不是P @ v_old
        # discount = 0时，每行q均为[0, 1]，形状为 (2, 2)
        q = reward + discount * p_transition * v_old

        # 4.停止分数变为列向量，与两个普通行动拼接
        # (2, 1)与(2, 2)拼成(2, 3)，第0列是停止选项
        v = t.cat([v.unsqueeze(1), q], 1)
        v = t.logsumexp(v, 1)                         # 沿每行三个选项计算，返回 (2, )
        delta = t.max(t.abs(v - v_old))

    # 5.q.T - v先按列广播，转置回来后相当于每行减去自己的v_i
    # 指数化得到普通行动概率，不包含之前拼接的停止列
    return t.exp((q.T - v).T)


# 2.测试主函数：先手算分母，再验证输出、停止余量和零边
def main():
    t.set_printoptions(precision = 6, sci_mode = False)    # 保留6位小数，不用科学计数法

    # 1.构造两状态合成输入，使用CPU和float32
    transition = t.tensor([[0.0, 1.0], [1.0, 0.0]], dtype = t.float32)
    reward = t.tensor([0.0, 1.0], dtype = t.float32)       # 固定即时奖励
    terminal = t.tensor([1], dtype = t.long)              # 索引必须是整数类型
    discount = 0.0
    eps = 1e-6

    # 2.检查输入；概率行和只用于输入转移，不直接套到所有输出行
    assert transition.shape == (2, 2)
    assert reward.shape == (2, ) and terminal.tolist() == [1]
    assert t.isfinite(transition).all() and t.isfinite(reward).all()
    assert (transition >= 0).all()
    t.testing.assert_close(transition.sum(dim = 1), t.ones(2))

    # 3.用数学常数e手算，不用原函数的返回值作为预期答案
    e = math.e
    manual = t.tensor([
        [1.0 / (1.0 + e), e / (1.0 + e)],
        [1.0 / (2.0 + e), e / (2.0 + e)],
    ], dtype = t.float32)
    manual_stop = t.tensor([0.0, 1.0 / (2.0 + e)], dtype = t.float32)
    print("非终止行分母1+e:", 1.0 + e)
    print("允许停止行分母2+e:", 2.0 + e)

    # 4.单独查看logsumexp怎样合并普通行动和停止分数
    scores = t.tensor([[-1e20, 0.0, 1.0], [0.0, 0.0, 1.0]])
    manual_v = t.tensor([math.log(1.0 + e), math.log(2.0 + e)])
    t.testing.assert_close(t.logsumexp(scores, dim = 1), manual_v, atol = 1e-6, rtol = 1e-6)

    # 5.调用源码函数；没有梯度训练，只验证概率计算
    with t.no_grad():
        source = local_causal_action_probabilities(transition, terminal, reward, discount, eps = eps)
    assert source.shape == (2, 2)
    assert t.isfinite(source).all() and (source >= 0).all()
    t.testing.assert_close(source, manual, atol = 1e-6, rtol = 1e-6)

    # 6.返回矩阵只有普通行动；1减去行和，得到本例停止余量
    action_sum = source.sum(dim = 1)
    stop_mass = 1.0 - action_sum
    t.testing.assert_close(stop_mass, manual_stop, atol = 1e-6, rtol = 1e-6)
    t.testing.assert_close(action_sum + manual_stop, t.ones(2), atol = 1e-6, rtol = 1e-6)
    assert action_sum[1] < 1.0

    # 7.零边位置也有正输出：本例没有在最终概率上显式屏蔽这些位置
    zero_edge_probability = source[transition == 0]
    assert (zero_edge_probability > 0).all()

    # 8.换一组非零转移，discount仍为0，因此本例结果应保持一致
    changed_transition = t.tensor([[0.25, 0.75], [0.6, 0.4]], dtype = t.float32)
    with t.no_grad():
        changed_source = local_causal_action_probabilities(changed_transition, terminal, reward, discount, eps = eps)
    t.testing.assert_close(changed_source, source, atol = 1e-6, rtol = 1e-6)

    # 9.打印手算、源码和对照，中文输出沿用N03格式
    print("状态转移矩阵：\n", transition)
    print("即时奖励:", reward, "终止索引:", terminal, "折扣因子:", discount)
    print("两行logsumexp:", t.logsumexp(scores, dim = 1))
    print("手算普通行动概率：\n", manual)
    print("源码普通行动概率：\n", source)
    print("普通行动行和:", action_sum)
    print("停止概率余量:", stop_mass)
    print("普通行动与停止概率之和:", action_sum + manual_stop)
    print("零转移位置的普通行动概率:", zero_edge_probability)
    print("替换转移后的输出：\n", changed_source)
    print("验证通过")


# 3.测试
if __name__ == "__main__":
    main()
```
