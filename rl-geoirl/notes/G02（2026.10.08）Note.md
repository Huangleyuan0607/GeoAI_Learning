### 第二阶段：理论学习（约 40 分钟）

先把两个式子抄进笔记（合上书默写得出来才算过）：

$$
G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots
$$

$$
V^\pi = R^\pi + \gamma P^\pi V^\pi
\quad\Longrightarrow\quad
V^\pi = (I - \gamma P^\pi)^{-1} R^\pi
$$

两个必须记住的事实：

1. Bellman 方程**既是线性方程组（可直接解），也是不动点迭代（可反复代）**——同一个方程的两种解法，这正是 Day04 值迭代／策略迭代两个算法的同一来源；
2. 本文的 γ **不是超参**，而是 §2.2 用 Kaplan–Meier 生存概率算出的逐停留点折扣（Day17 兑现）——"打折"在论文里有物理含义：一趟出行还在继续的概率。

再做一个 3×3 手推例（对应"笔记沉淀"，不许先开 numpy）：

> 取 P ＝ [[0, .5, .5], [.5, 0, .5], [.5, .5, 0]]、R ＝ [1, 0, −1]、γ ＝ 0.5。
> 第一步按**方程形式**给每个状态写一行 $V_i = R_i + \gamma\sum_j P_{ij}V_j$（三个等式）；
> 第二步排成**矩阵形式** $(I-\gamma P)V = R$，手解或笔算验证两次的 V 一致；
> 第三步再开 numpy 用 `solve` 对答案。

#### 实验任务

今天的代码要同时回答一个数值问题、一个判据问题：

- **数值问题**：n＝40 的随机行归一化矩阵 P 与随机奖励向量 R（均值 0、方差 1），三个 γ（0.5／0.9／0.99）下解析解与迭代解的最大误差 < 1e-6，打印迭代轮数——**看 γ→1 时轮数怎么爆炸**。
- **判据问题**：打印 `numpy.linalg.eigvals(γP)` 的模最大值（谱半径），能回答"**谱半径与收敛条件的关系**"——这是 Day08 发散的伏笔。
- **附加实验**：把行归一化撕掉（行和不为 1）再跑一次，观察 ρ(γP) 越过 1 时迭代解当场失效，解释为什么。

四个必须避开的坑：

- **`inv` 与 `solve` 不分**：`np.linalg.inv(A) @ R` 更慢且数值不稳（条件数差时误差放大），解线性方程组一律 `np.linalg.solve(A, R)`。
- **收敛判据用错量**：判据是"整轮 V 的**最大变化** < tol"（上确界范数），不是"V 的总和"也不是"相邻两轮差的平方和"——用错量会让早期轮次假装收敛、轮数少报。
- **矩阵乘方向反了**：V 是列向量，更新式是 `R + gamma * (P @ V)`；写成 `V @ P` 形状对不上或得到一个错误答案，numpy 的广播有时不报错，要盯形状。
- **行归一化没做干净**：行随机矩阵必有 ρ(P)＝1（全 1 向量就是它的右特征向量），所以理论上 ρ(γP) 应**恰好等于 γ**——打印出来若不是 0.5／0.9／0.99，先检查是不是忘了 `keepdims=True`。

#### 参考代码

**`value_bellman.py`**

```python
"""本文件用于把 Bellman 方程用两种方法解出来：解析解（线性方程组）与迭代解（不动点），并用谱半径解释收敛"""


# 导包
import numpy as np


# 1.造材料：n=40 的随机行归一化转移矩阵 P 与随机奖励向量 R（均值 0、方差 1）
def make_random_mrp(n = 40, seed = 2026):
    rng = np.random.default_rng(seed)
    P = rng.random((n, n))
    P = P / P.sum(axis = 1, keepdims = True)          # 行归一化：每行是一个"下一状态"的概率分布
    R = rng.normal(loc = 0.0, scale = 1.0, size = n)  # 状态奖励：均值 0、方差 1
    return P, R


# 2.解法一（解析）：V = R + γPV 移项成 (I - γP)V = R，直接解线性方程组
def bellman_exact(P, R, gamma):
    """陷阱一：用 np.linalg.solve 而不是 np.linalg.inv(A) @ R——
    显式求逆更慢、数值更不稳（条件数差时误差被放大）。"""
    A = np.eye(len(R)) - gamma * P
    return np.linalg.solve(A, R)


# 3.解法二（迭代）：V <- R + γPV，不动点反复代，直到整轮最大变化 < tol
def bellman_iterate(P, R, gamma, tol = 1e-12, max_iter = 20000):
    """官方 stochastic_value_iteration 就是这个结构：
    gamma 是折扣、tol 对应它的 eps、循环体那一行就是更新式。
    陷阱二：判据用"最大变化"（上确界范数），不是总和；
    陷阱三：V 是列向量，写 P @ V，不是 V @ P。"""
    V = np.zeros(len(R))
    for k in range(1, max_iter + 1):
        V_next = R + gamma * (P @ V)
        delta = np.abs(V_next - V).max()
        V = V_next
        if delta < tol:
            return V, k
    raise RuntimeError(f"{max_iter} 轮仍未收敛，最后单轮最大变化 {delta:.3e}")


# 4.谱半径：迭代解的收敛开关（G08 发散实验的伏笔）
def spectral_radius(M):
    return float(np.abs(np.linalg.eigvals(M)).max())


# 5.测试
if __name__ == '__main__':
    n = 40
    P, R = make_random_mrp(n)

    print("=" * 60)
    print("材料自检")
    print("=" * 60)
    print(f"P 形状                     {P.shape}")
    print(f"行和 min/max               {P.sum(axis = 1).min():.12f} / {P.sum(axis = 1).max():.12f}")
    print(f"R 样本均值/标准差          {R.mean():.3f} / {R.std():.3f}")
    print(f"ρ(P)                       {spectral_radius(P):.6f}   （行随机矩阵必有 ρ = 1）")

    print()
    print("=" * 60)
    print("两种解法对照（γ 越大 → 未来越重要 → 迭代越慢）")
    print("=" * 60)
    print(f"{'γ':>6}{'ρ(γP)':>10}{'迭代轮数':>10}{'两解最大误差':>16}{'‖V‖∞':>10}")
    for gamma in (0.5, 0.9, 0.99):
        V_exact = bellman_exact(P, R, gamma)
        V_iter, iters = bellman_iterate(P, R, gamma)
        err = np.abs(V_exact - V_iter).max()
        print(f"{gamma:>6.2f}{spectral_radius(gamma * P):>10.4f}{iters:>10}{err:>16.2e}{np.abs(V_iter).max():>10.3f}")

    # 5.1附加实验：把行归一化撕掉（行和 1.05~1.6），ρ(γP) 可能越过 1
    print()
    print("=" * 60)
    print("附加：行和不为 1 的'坏矩阵'")
    print("=" * 60)
    rng = np.random.default_rng(7)
    P_bad = P * rng.uniform(1.05, 1.6, size = (n, 1))
    print(f"行和 min/max               {P_bad.sum(axis = 1).min():.3f} / {P_bad.sum(axis = 1).max():.3f}")
    for gamma in (0.5, 0.99):
        rho = spectral_radius(gamma * P_bad)
        if rho >= 1.0:
            print(f"γ={gamma:.2f}  ρ(γP_bad)={rho:.4f} ≥ 1 —— 理论预言发散，硬跑 {20000} 轮：")
            try:
                bellman_iterate(P_bad, R, gamma, max_iter = 20000)
                print("   竟然收敛了？回头检查代码")
            except RuntimeError as e:
                print(f"   {e}")
        else:
            V_iter, iters = bellman_iterate(P_bad, R, gamma)
            err = np.abs(bellman_exact(P_bad, R, gamma) - V_iter).max()
            print(f"γ={gamma:.2f}  ρ(γP_bad)={rho:.4f} < 1 —— 仍收敛：{iters} 轮，误差 {err:.2e}")

    # 一句话结论（写进笔记）：决定迭代收不收敛的不是 γ 单独，而是乘积 γP 的谱半径；
    # 行随机时 ρ(P)=1，所以 ρ(γP)=γ<1 必收敛；行和一旦超过 1，γ=0.99 也能把 ρ 顶过 1，
    # 不动点直接不吸引——论文 §2.1.6 的全部焦虑就是这一个不等式。
```
