### 第二阶段：理论学习（约 35 分钟）

最优（硬）：

$$
Q^*(s,a) = r(s,a) + \gamma \max_{a'} Q^*(s',a')
$$

最大熵（软，目标 
$$
\max_\pi \mathbb{E}\big[\sum_t r_t + \alpha H(\pi(\cdot|s_t))\big]
$$
）：

$$
Q(s,a) = r(s,a) + \gamma \log \sum_{a'} e^{Q(s',a')},
\qquad
\pi(a\mid s) = \frac{e^{Q(s,a)}}{\sum_{a'} e^{Q(s,a')}}
$$

一句话抓区别：**max 让策略退化成 argmax 的确定性选择；log-sum-exp 让策略永远是一个分布。** 论文的"中间策略"是后者——所以它能生成**多样**轨迹而不是最短路，这正是论文 §1 要的"生成未见过的轨迹"。

再做一个两状态手推例（对应"笔记沉淀"，先笔算后开 numpy）：

> 某状态只有两个动作，Q = [2, 1]。软策略 
> $$
> \pi_1 = \frac{e^{2\beta}}{e^{2\beta}+e^{\beta}} = \frac{1}{1+e^{-\beta}}
> $$
> 笔算 β＝0.2／1／5／∞ 四档的 Π_1，再想一下：
> $$
> \frac{1}{1+e^{-\beta \Delta Q}}
> $$
>  是什么函数？
> ——是 **sigmoid**，β 是斜率：软策略不是"另一个答案"，而是把 argmax 的阶跃**抹平成一条随 β 变陡的 S 曲线**。

#### 实验任务

今天的代码要同时回答一个机制问题、一个纪律问题：

- **机制问题**：`soft_vs_hard_policy.py`——β 取 0.2／1／5／50，打印每档的**平均策略熵**与**每行最大概率**，并与硬策略对照。判据：熵单调下降、最大概率单调上升；β＝50 时软策略≈硬策略（肉眼验证：argmax 一致率 100%）。
- **纪律问题**：两个函数写好后**原样搬进 `geoirl/irl.py`**，Day03 脚本改为 import——验收明摆着要求"当天没有任何其它文件复制这两份实现"。签名是任务书定死的：`hard_value_iteration(P, r, gamma, iters) -> (V, pi)`、`soft_policy(P, r, gamma=0.95, beta=1.0, iters) -> (pi, V)`。**注意两个函数返回顺序是镜像的**（V 在前 vs pi 在前），照抄签名，别自创。

`soft_policy` 的实现要求（这是全项目唯一的一份）：

- 递推式：
  $$
  V(s) = \frac{1}{\beta}\log \sum_{s'} P(s'|s)\, e^{\beta[r(s') + \gamma V(s')]}
  $$

- 策略：
  $$
  \pi(s'|s) \propto P(s'|s)\, e^{\beta[r(s') + \gamma V(s')]}
  $$

- 实现技巧：把 `log P` 直接加进指数里，一次性表达"哪些边允许＋转移概率多大"；零元素的 `log` 要先 `maximum(P, 1e-30)`。

- 数值稳定：算 logsumexp 必须先减每行最大值，**不准出现 `exp(1000)` 这种溢出**。

- 收敛判据：`|V_new − V|.max() < 1e-12`（和 G02 同一个量，别换）。

四个必须避开的坑：

- **logsumexp 不减行最大值**：β＝50、V≈44 时指数是 
  $$
  \beta(r+\gamma V)\approx 2200
  $$
  ，`exp(2200)` 直接 inf，V 变 nan。症状：β 扫描表最后一行全 nan——先查 `row_logsumexp`。

- **`log(0) = -inf`**：P 的零元素取 log 是 -inf，一行里只要有一个 -inf 参与减法就可能 nan。`np.maximum(P, 1e-30)` 先垫底（-69 nats，β＝50 时也照样被 β·Q 压住，不影响决策）。今天 P 是稠密的踩不到，**G15 稀疏化之后必踩**，防护今天就要在。

- **归一化轴搞反**：π 要**按行**归一化（每行是一个"下一状态"的分布）；`axis=1` 写成 `axis=0` 形状照样对、数值全错，且不报错——最阴的一种坑。

- **复制实现不留 import**：`soft_policy` 在 `irl.py` 之外再出现一份定义，今天的验收第 5 条直接挂。跑一遍 `grep soft_policy rl-geoirl/` 自查：应该只有一处 `def`、一处 `import`。

**`geoirl/irl.py`**

```python
"""
geoirl/irl.py — 硬/软 Bellman 的唯一实现（G03 诞生）

对应论文 §2.1（MDP 定义）与 §2.1.5（中间策略是最大熵软策略）。
规矩：Day05/06/07/08/10/16 一律从这里 import，禁止复制第二份实现。
"""


# 导包
import numpy as np


# 1.数值稳定的逐行 logsumexp（每行一个状态，先减行最大值再取指数）
def row_logsumexp(M):
    """陷阱一：不减最大值，β=50 时指数 ~2200，exp 直接 inf。
    减完之后 exp(M - m) ∈ (0, 1]，永远不会溢出。"""
    m = M.max(axis = 1, keepdims = True)
    return m[:, 0] + np.log(np.exp(M - m).sum(axis = 1))


# 2.硬：V(s) = max_{s' 可达} [r(s') + γV(s')]，π 为 one-hot
def hard_value_iteration(P, r, gamma = 0.95, iters = 5000, tol = 1e-12):
    n = len(r)
    V = np.zeros(n)
    k = 0
    # 2.1值迭代主体：Q[s, s'] = r(s') + γV(s')，只沿 P>0 的边取 max
    for k in range(1, iters + 1):
        Q = r[None, :] + gamma * V[None, :]
        V_new = np.where(P > 0, Q, -np.inf).max(axis = 1)
        delta = np.abs(V_new - V).max()
        V = V_new
        if delta < tol:
            break
    # 2.2收敛后摊出 one-hot 策略：每行只有 argmax 那一列是 1
    Q = r[None, :] + gamma * V[None, :]
    best = np.where(P > 0, Q, -np.inf).argmax(axis = 1)
    pi = np.zeros((n, n))
    pi[np.arange(n), best] = 1.0
    return V, pi          # 签名是 (V, pi)，和 soft_policy 相反，别记混


# 3.软（全项目唯一实现）：
#   V(s)  = (1/β) log Σ_{s'} P(s'|s) · exp(β[r(s') + γV(s')])
#   π(s'|s) ∝ P(s'|s) · exp(β[r(s') + γV(s')])
def soft_policy(P, r, gamma = 0.95, beta = 1.0, iters = 5000, tol = 1e-12):
    # 3.1实现技巧：log P 加进指数 = 一次性表达"哪些边允许 + 转移概率多大"
    #    陷阱二：log(0) = -inf，先 maximum(P, 1e-30) 垫底
    logP = np.log(np.maximum(P, 1e-30))

    V = np.zeros(len(r))
    for k in range(1, iters + 1):
        Z = beta * (r[None, :] + gamma * V[None, :]) + logP
        V_new = row_logsumexp(Z) / beta
        delta = np.abs(V_new - V).max()
        V = V_new
        if delta < tol:
            break

    # 3.2log-softmax：减掉配分函数再取 exp，行和自动为 1
    #    陷阱三：按行归一化（axis=1）；写成 axis=0 不报错但全错
    Z = beta * (r[None, :] + gamma * V[None, :]) + logP
    pi = np.exp(Z - row_logsumexp(Z)[:, None])
    return pi, V          # 签名是 (pi, V)
```

**`rl/Day03/soft_vs_hard_policy.py`**

```python
"""本文件用于把硬策略与软策略摆在一起：看 β 怎么控制"锐→软"的连续过渡"""


# 导包
import numpy as np

# 第一次包内 import：Sources Root 没配好，报错就落在这一行
from geoirl.irl import hard_value_iteration, soft_policy


# 1.材料：与 G02 同款——n=40 行归一化 P，r ~ N(0,1)
def make_random_mrp(n = 40, seed = 2026):
    rng = np.random.default_rng(seed)
    P = rng.random((n, n))
    P = P / P.sum(axis = 1, keepdims = True)
    r = rng.normal(loc = 0.0, scale = 1.0, size = n)
    return P, r


# 2.描述"一个策略有多软"的两个数：平均行熵、平均行最大概率
def policy_stats(pi):
    logpi = np.log(np.maximum(pi, 1e-30))
    entropy = float(-(pi * logpi).sum(axis = 1).mean())    # nats；全软上限 = ln(40) = 3.689
    sharpness = float(pi.max(axis = 1).mean())             # 硬策略 = 1.0
    return entropy, sharpness


# 3.测试
if __name__ == '__main__':
    n = 40
    P, r = make_random_mrp(n)
    gamma = 0.95

    V_hard, pi_hard = hard_value_iteration(P, r, gamma = gamma)
    e_h, s_h = policy_stats(pi_hard)

    print("=" * 64)
    print("硬策略（max）")
    print("=" * 64)
    print(f"V min/max                  {V_hard.min():.3f} / {V_hard.max():.3f}")
    print(f"平均策略熵                 {e_h:.3f} nats   （ln(40) = {np.log(n):.3f} 是上限）")
    print(f"每行最大概率均值           {s_h:.3f}")
    print(f"r 最大的建筑               #{int(r.argmax())}（r = {r.max():.3f}）")
    targets, counts = np.unique(pi_hard.argmax(axis = 1), return_counts = True)
    print(f"40 行的 argmax 去向        {dict(zip(targets.tolist(), counts.tolist()))}")

    print()
    print("=" * 64)
    print("软策略 β 扫描（β→∞ 应退化成硬策略）")
    print("=" * 64)
    print(f"{'β':>6}{'V max':>10}{'平均熵(nats)':>14}{'行最大概率':>12}{'与硬argmax一致率':>16}")
    for beta in (0.2, 1.0, 5.0, 50.0):
        pi, V = soft_policy(P, r, gamma = gamma, beta = beta)
        e, s = policy_stats(pi)
        agree = float((pi.argmax(axis = 1) == pi_hard.argmax(axis = 1)).mean())
        print(f"{beta:>6.1f}{V.max():>10.2f}{e:>14.3f}{s:>12.3f}{agree:>15.0%}")

    # 一句话结论（写进笔记）：软策略 = "奖励贪心"与"转移先验"的几何混合，β 是混合权重。
    # β 小 → logP 项主导，策略≈随机游走；β 大 → β·Q 项主导，策略≈argmax。
    # 这就是 MaxEnt IRL 不塌成最短路的机制，也是论文能生成"多样轨迹"的原因。
```
